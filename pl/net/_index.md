p1: "TeX to język programowania, można go nazwać językiem znaczników danych. Jednocześnie TeX jest silnikiem interpretera, który rozumie ten język i system składu jako całość."
p2: Służy do pisania tekstów matematycznych lub technicznych. Na podstawie ΤeΧ utworzono wiele różnych pakietów. Najbardziej znanym takim pakietem jest LaTeX. Pozwala autorom skupić się na tekście i pozostawić proces typografii programowi. Dokumenty strukturalne LaTeX są łatwe do tworzenia i zarządzania.
p3: Aspose.TeX dla .NET to elastyczna i łatwa w użyciu biblioteka do składu plików TeX i LaTeX. API obsługuje wiele formatów wyjściowych, takich jak XPS, PDF, PNG, JPEG, TIFF, SVG i BMP. Oznaczało to, że dzięki funkcjonalności tej biblioteki można konwertować pliki TeX i LaTeX do dowolnego formatu wyjściowego. Dzięki rozwiązaniu możesz utworzyć niestandardowy format TeX, jeśli chcesz utworzyć i/lub złożyć zestaw dokumentów zaprojektowanych w jednolity sposób.
