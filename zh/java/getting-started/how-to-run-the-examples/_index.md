## 从Github下载

Java的Aspose.TeX的所有示例均在GitHub上托管。您可以使用您喜欢的GitHub客户端克隆存储库，也可以从此处下载zip文件。

将zip文件的内容提取到计算机上的任何文件夹。所有示例都位于示例文件夹中。该项目使用Maven构建系统。任何现代IDE都可以轻松打开或导入项目及其依赖性。在下面，我们向您展示如何使用流行的IDE构建和运行示例。

## Intellij Idea

单击“文件”菜单，然后选择“打开”。浏览到项目文件夹，然后选择pom.xml文件。

它将打开项目并自动下载依赖项。从“项目”选项卡中，浏览src/main/java文件夹中的示例。

要运行一个示例，只需右键单击文件，然后选择“运行..”，将执行该示例，并且输出将显示在内置控制台输出窗口中。

## Eclipse

单击“文件”菜单，然后选择导入。选择Maven-现有的Maven项目。浏览您从github克隆或下载的文件夹，然后选择pom.xml文件。

它将打开项目并自动下载依赖项。从“包装浏览器”选项卡中，浏览src/main/java文件夹中的示例。要运行一个示例，只需右键单击该文件，然后选择运行为-Java应用程序，将执行该示例，并将输出显示在内置控制台输出窗口中。

## Netbeans

单击“文件”菜单，然后选择“打开项目”。浏览您从Github克隆或下载的文件夹。示例文件夹的图标将表明这是一个Maven项目。选择示例并打开它。

它将打开项目并自动下载依赖项。从“项目”选项卡中，在源软件包中浏览示例。要运行一个示例，只需右键单击文件并选择运行文件，将执行示例，输出将显示在内置控制台输出窗口中。
