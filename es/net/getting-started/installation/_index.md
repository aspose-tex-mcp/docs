## Instalación de Aspose.TeX para .NET a través de NuGet

NuGet es un sistema de administración de paquetes gratuito y de código abierto centrado en desarrolladores para la plataforma .NET que intenta simplificar el proceso de incorporación de bibliotecas de terceros en una aplicación .NET durante el desarrollo. Es una extensión de Visual Studio que facilita agregar, eliminar y actualizar bibliotecas y herramientas en proyectos de Visual Studio que utilizan .NET Framework. Una biblioteca o herramienta se puede compartir fácilmente con otros desarrolladores creando un paquete NuGet y almacenándolo dentro de un repositorio NuGet. Cuando instala el paquete, NuGet copia archivos en su solución y realiza automáticamente los cambios necesarios, como agregar referencias y cambiar sus archivos app.config o web.config. Si decide eliminar la biblioteca, NuGet elimina los archivos y revierte los cambios realizados en su proyecto para que no quede desorden.

### Haciendo referencia a Aspose.TeX para .NET

Aprovechando esta maravillosa característica, hemos incluido bibliotecas [Aspose.TeX para .NET](https://www.nuget.org/packages/Aspose.TeX) en un paquete NuGet y lo hemos subido a un repositorio NuGet. Con esta opción, se beneficia del uso de Aspose.TeX para .NET sin instalar este componente en su sistema. NuGet se ejecuta en Visual Studio 2010 y versiones superiores, Visual Web Developer 2010 y Windows Phone Developer Tools 7.1. En nuestras pruebas lo hemos probado con Visual Studio 2015 Ultimate.

Para empezar:

1. Abra su solución o proyecto en Visual Studio.
2. Agregue NuGet Package Manager como una extensión de Visual Studio:

   1. Seleccione el menú **Herramientas** seguido de **Administrador de extensiones**.
   2. Seleccione **Galería en línea** para obtener una lista completa de los paquetes disponibles en línea.
   3. Seleccione **Administrador de paquetes NuGet**.
   4. Haga clic en **Descargar**.
   5. Una vez instalado el Administrador de paquetes, reinicie Visual Studio para que los cambios surtan efecto. 
   
      Cuando NuGet Package Manager está instalado, puede buscar, instalar, eliminar y actualizar paquetes desde la ventana **Administrar paquetes NuGet** o mediante los comandos de línea de comandos de PowerShell en la ventana dedicada de Visual Studio **Consola de Package Manager**. . Puede encontrar ambas opciones si selecciona **Herramientas** seguido de **Administrador de paquetes de biblioteca**.

### Instalar el paquete usando la consola del administrador de paquetes

Para hacer referencia al componente usando la consola del administrador de paquetes:

1. Abra su aplicación .NET en Visual Studio.
2. En el menú **Herramientas**, seleccione **Administrador de paquetes de biblioteca** y luego **Consola de Package Manager**.
3. Escriba el comando “Install-Package Aspose.TeX” para instalar la última versión completa, o escriba el comando “Install-Package Aspose.TeX -prerelease” para instalar la última versión, incluidas las correcciones urgentes.
4. Presione **Entrar**.

### Actualizar paquete usando la consola del administrador de paquetes

Si ya hizo referencia al componente a través de NuGet, siga estos pasos para actualizar la referencia a la última versión:

1. Abra su aplicación .NET en Visual Studio.
2. En el menú **Herramientas**, seleccione **Administrador de paquetes de biblioteca**, seguido de **Consola de Package Manager** para abrir la consola del Administrador de paquetes.
3. Escriba el comando “Update-Package Aspose.TeX” para hacer referencia a la última versión completa, o escriba el comando “Update-Package Aspose.TeX -prerelease” para instalar la última versión, incluidas las correcciones urgentes.
4. Presione **Entrar**.

### Instalar el paquete utilizando la GUI del Administrador de paquetes

Siga estos pasos para hacer referencia al componente mediante la GUI del administrador de paquetes:
1. Abra su aplicación .NET en Visual Studio.
2. En el menú **Herramientas**, seleccione **Administrador de paquetes de biblioteca** y **Administrar paquetes NuGet** de la opción **Solución**. 

   También puede obtener una opción similar desde el Explorador de soluciones:
   1. Haga clic derecho en el nombre del proyecto.
   2. Seleccione **Administrar paquetes NuGet**.

3. Seleccione **en línea** en el menú de la izquierda.
4. Escriba **Aspose.TeX** en el cuadro de búsqueda para encontrar Aspose.TeX para .NET.
5. Haga clic en **Instalar/Actualizar** junto a la última versión de Aspose.TeX para .NET
