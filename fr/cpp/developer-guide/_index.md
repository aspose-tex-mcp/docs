## Aperçu

Le guide du développeur agit comme une ressource complète pour utiliser efficacement la solution API Aspose.TeX pour C++. Son objectif principal est de fournir aux utilisateurs un aperçu des concepts de base, des fonctionnalités et des pratiques recommandées pour interagir avec la solution API Aspose.TeX pour C++. Ce guide propose des exemples pratiques essentiels pour comprendre la conversion, la lecture, la création et d'autres manipulations des formats de fichiers TeX et LaTeX, notamment :

- **[Conversion](/tex/{{lang.url-fragment}}cpp/conversion/)** - vous découvrirez ici les paires de conversion les plus requises, l'entrée et la sortie TeX, et bien d'autres.
- **[Packages LaTeX externes](/tex/{{lang.url-fragment}}java/external-latex-packages/)** - est une liste des packages externes les plus requis avec des détails sur la façon de fournir ces packages au moteur TeX de la bibliothèque.
- **[Fonctionnalités avancées](/tex/{{lang.url-fragment}}cpp/advanced-features/)** - ce chapitre vous aide à utiliser facilement les fonctionnalités avancées offertes par Aspose.TeX pour C++.
