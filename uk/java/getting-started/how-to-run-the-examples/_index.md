## Завантажити з GitHub

Усі приклади Aspose.TeX для Java розміщено на GitHub. Ви можете клонувати репозиторій за допомогою свого улюбленого клієнта GitHub або завантажити файл ZIP звідси.

Розпакуйте вміст ZIP-файлу в будь-яку папку на вашому комп’ютері. Усі приклади знаходяться в папці «Приклади». У проекті використовується система збірки Maven. Будь-яка сучасна IDE може легко відкрити або імпортувати проект і його залежності. Нижче ми покажемо вам, як використовувати популярні IDE для створення та запуску прикладів.

## IDEA IntelliJ

Натисніть меню «Файл» і виберіть «Відкрити». Перейдіть до папки проекту та виберіть файл pom.xml.

Він відкриє проект і автоматично завантажить залежності. На вкладці «Проект» перегляньте приклади в папці src/main/java.

Щоб запустити приклад, просто клацніть правою кнопкою миші на файлі та виберіть «Виконати ..». Приклад буде виконано, а результат буде показано у вбудованому вікні виведення консолі.

## Eclipse

Натисніть меню «Файл» і виберіть «Імпортувати». Виберіть Maven - існуючі проекти Maven. Перейдіть до папки, яку ви клонували або завантажили з GitHub, і виберіть файл pom.xml.

Він відкриє проект і автоматично завантажить залежності. На вкладці Package Explorer перегляньте приклади в папці src/main/java. Щоб запустити приклад, просто клацніть правою кнопкою миші на файлі та виберіть «Запустити як — Java-додаток», приклад буде виконано, а вихідні дані відображатимуться у вбудованому вікні виведення консолі.

## NetBeans

Натисніть меню «Файл» і виберіть «Відкрити проект». Перейдіть до папки, яку ви клонували або завантажили з GitHub. Піктограма папки «Приклади» покаже, що це проект Maven. Виберіть Приклади та відкрийте його.

Він відкриє проект і автоматично завантажить залежності. На вкладці «Проекти» перегляньте приклади вихідних пакетів. Щоб запустити приклад, просто клацніть файл правою кнопкою миші та виберіть «Запустити файл». Приклад буде виконано, а вихідні дані відображатимуться у вбудованому вікні виведення консолі.

## Зробити свій внесок

Якщо ви хочете додати чи покращити приклад, ми заохочуємо вас зробити внесок у проект. Усі приклади та демонстраційні проекти в цьому репозиторії є відкритими і їх можна вільно використовувати у ваших власних програмах.

Щоб зробити внесок, ви можете розгалужити репозиторій, відредагувати вихідний код і створити запит на отримання. Ми переглянемо зміни та додамо їх до репозиторію, якщо вони будуть корисними.
