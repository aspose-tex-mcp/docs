## Prerequisiti

Prima di procedere, assicurarsi che la cartella `Aspose.TeX-...` appaia nella cartella `[python_path] \ lib \ site-packages \` dopo l'installazione del pacchetto Aspose.TeX. Se hai installato Python 3.11, Aspose.TeX può essere installato nella cartella `[Python_Path] \ Site-Packages \`. In questo caso, è necessario copiare la cartella Aspose.TeX sulla cartella `[python_path] \ lib \ site-packages \`, come **pycharm** (almeno versione 23.1) cerca pacchetti installati esattamente in quella posizione.

## Scarica da GitHub

Tutti gli esempi di Aspose.TeX per Python sono disponibili su [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET). Hai due opzioni per accedere agli esempi: puoi clonare il repository utilizzando il tuo client GitHub preferito, oppure è possibile scaricare il file zip da [qui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip). Estrai il contenuto del file zip in qualsiasi cartella sul tuo computer. Troverai tutti gli esempi situati nella cartella `Aspose.TeX.examples. Di seguito, dimostreremo come costruire ed eseguire gli esempi usando IDE popolari.

Se riscontri problemi durante l'impostazione o l'esecuzione degli esempi, non esitare a contattarci attraverso i nostri forum.

## Pycharm

Vai al menu ***File*** e scegli ***Apri***. Seleziona la cartella del progetto Esempio e fai clic sul pulsante ***OK***. Il progetto sarà aperto. Quindi, vai al menu ***esegui*** e scegli ***Modifica configurazioni***. Nel pannello a sinistra, aggiungi una nuova configurazione Python. Nel pannello di destra, impostare il nome della configurazione (ad esempio, "run_examples"). Specificare il percorso assoluto di `run_examples.py` nel campo ***Script*** e il percorso assoluto della cartella del progetto nel campo ***di lavoro***.

Per eseguire un esempio, vai semplicemente al menu ***run*** e scegli ***eseguire 'run_examples'*** o utilizzare la tastiera di scelta rapida `shift+f10`. L'esempio verrà eseguito e l'uscita verrà visualizzata nella finestra della console di Pycharm. I file di output generati durante l'esecuzione di esempi sono disponibili nella cartella `output '.

## Microsoft Visual Studio

Assicurarsi che la funzione **Python Development** sia installata in Visual Studio. Apri Visual Studio e fai clic sul lato destro di ***Apri una cartella locale*** Articolo. Quindi, naviga sulla cartella del progetto Aspose.TeX Esempi. Visual Studio lo riconoscerà come un progetto Python e aprirà l'IDE Python. Una volta aperta la cartella, fare clic con il pulsante destro del mouse su "Run_Examples" nell'Explorer Solution e selezionare ***Imposta come elemento di avvio***

Per eseguire esempi, fai clic sul pulsante ***run_examples.py*** con la freccia verde nella barra degli strumenti nella finestra Visual Studio.
