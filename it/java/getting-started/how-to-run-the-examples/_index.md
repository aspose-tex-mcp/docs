## Scarica da GitHub

Tutti gli esempi di Aspose.Tex per Java sono ospitati su GitHub. Puoi clonare il repository utilizzando il tuo client GitHub preferito o scaricare il file zip da qui.

Estrai il contenuto del file zip in qualsiasi cartella sul tuo computer. Tutti gli esempi si trovano nella cartella Esempi. Il progetto utilizza il sistema di build Maven. Qualsiasi IDE moderno può facilmente aprire o importare il progetto e le sue dipendenze. Di seguito ti mostriamo come utilizzare IDE popolari per costruire ed eseguire gli esempi.

## Idea Intellij

Fai clic sul menu File e scegli Apri. Sfoglia la cartella del progetto e seleziona il file POM.xml.

Aprirà il progetto e scaricherà automaticamente le dipendenze. Dalla scheda Project, sfoglia gli esempi nella cartella SRC/Main/Java.

Per eseguire un esempio, basta fare clic con il pulsante destro del mouse sul file e scegliere "Esegui ..", l'esempio verrà eseguito e l'uscita verrà visualizzata nella finestra di output della console integrata.

## Eclissi

Fai clic sul menu File e scegli Importa. Seleziona Maven - progetti Maven esistenti. Sfoglia la cartella che hai clonato o scaricato da GitHub e seleziona il file POM.xml.

Aprirà il progetto e scaricherà automaticamente le dipendenze. Dalla scheda Explorer del pacchetto, sfoglia gli esempi nella cartella SRC/Main/Java. Per eseguire un esempio, fai clic con il tasto destro sul file e scegli Esegui come - Applicazione Java, l'esempio verrà eseguito e l'uscita verrà visualizzata nella finestra di output della console integrata.

## Netbeans

Fai clic sul menu File e scegli Apri il progetto. Sfoglia la cartella che hai clonato o scaricato da GitHub. L'icona della cartella Esempi mostrerà che è un progetto Maven. Seleziona esempi e aprili.

Aprirà il progetto e scaricherà automaticamente le dipendenze. Dalla scheda Progetti, sfoglia gli esempi in pacchetti di origine. Per eseguire un esempio, basta fare clic con il tasto destro sul file e scegliere il file Esegui, l'esempio verrà eseguito e l'uscita verrà visualizzata nella finestra di output della console integrata.

## Contribuire

Se ti piace aggiungere o migliorare un esempio, ti incoraggiamo a contribuire al progetto. Tutti gli esempi e mostrano progetti in questo repository sono open-source e possono essere utilizzati liberamente nelle proprie applicazioni.

Per contribuire, è possibile forconare il repository, modificare il codice sorgente e creare una richiesta pull. Esamineremo le modifiche e le includeremo nel repository se trovati utili.
