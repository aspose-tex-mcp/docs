## Багаті можливості

**Підтримувані операції**

- Набір тексту TeX
- Створення спеціального формату TeX

**Підтримка різних форматів вихідних файлів**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Підтримувані способи читання введення та запису виведення**

- Каталог файлової системи
- ZIP архів
- Основний файл TeX також можна передати через потік
