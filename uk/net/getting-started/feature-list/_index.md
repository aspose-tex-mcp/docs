## Багаті можливості

**Підтримувані операції**

- Набір тексту TeX
- Створення спеціального формату TeX
- Конвертація TeX/LaTeX
- Впровадження графіки у файли LaTeX
- Малювання фігур та складних математичних рівнянь у файлах LaTeX
- Перевірка, структурування та виправлення файлів LaTeX

**Підтримка різних форматів вихідних файлів**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Підтримувані способи читання введення та запису виведення**

- Каталог файлової системи
- ZIP архів
- Основний файл TeX також можна передати через потік

{{% alert color="primary" %}}

На відміну від традиційних утиліт командного рядка TeX, Aspose.TeX для .NET є повністю керованою автономною бібліотекою. Вона не вимагає локального встановлення TeX Live, MiKTeX або будь-яких базових виконуваних файлів.

{{% /alert %}}
