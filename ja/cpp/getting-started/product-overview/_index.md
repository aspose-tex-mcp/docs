**C ++のためのAspose.TeXへようこそ**

Aspose.TeXは、TEXファイルを植チ化するためのC ++ライブラリです。 XPS、PDF、PNG、JPEG、TIFF、BMPなどのさまざまなグラフィック形式でTEXファイルを表示できます。また、他のTexエンジンと同じようにトレース情報を出力します。 APIは、入力を供給して出力を取得するさまざまな方法を提供します。また、高度な機能として、均一に設計されたいくつかのドキュメントを入力したい場合は、独自のTex形式を作成できます。

{{% /alert %}}

## テクニカルサポート

Asposeは、すべての製品に無制限の無料テクニカルサポートを提供しています。サポートは、評価を含むすべてのユーザーが利用できます。

C ++のAspose.TeXのサポートが必要な場合は、[**Aspose.forums**](https://forum.aspose.com/)にアクセスしてください。 C ++フォーラムのAspose.TeXに質問を投稿すると、数時間以内に回答されます。質問は、C ++サポートチームのAspose.TeXによって直接回答されます。

フォーラムで返信を期待する場合は、タイムゾーンの違いを許可してください。

C ++のAspose.TeXに問題がある場合は、これらの簡単な手順に従って、最も効率的な方法で解決されていることを確認してください。

- 問題を報告する前に、必ず最新のAspose.TeX for C++バージョンをご使用ください。最新バージョンについては、[Aspose.TeX for C++のダウンロードページ](https://www.nuget.org/packages/Aspose.TeX.Cpp/)をご覧ください。
- 問題を報告する前に、ソリューションについては、フォーラム、このドキュメント、Wiki、および[APIリファレンス](https://reference.aspose.com/tex/cpp/)をご覧ください。あなたの質問にはすでに答えがあるかもしれません。
- 問題を報告するときは、元のドキュメントと、問題を引き起こすコードの断片を含めてください。複数のファイルを添付する必要がある場合は、それらを1つにzipします。お客様とAspose開発者のみが添付ファイルにアクセスできるため、ドキュメントをAsopsion.Forumsに添付することは安全です。
- スレッドごとに1つの問題を報告してみてください。別の問題がある場合は、別のスレッドに報告してください。
