## Встановлення Aspose.TeX для C++

### Ручне встановлення

Ви можете завантажити [Aspose.TeX для C++](https://www.nuget.org/packages/Aspose.TeX.Cpp) із NuGet Gallery, натиснувши посилання «Завантажити пакет» у розділі інформації. Офлайн-документацію API також можна знайти в завантаженому ZIP-пакеті.

Будь ласка, виконайте наступні дії, щоб використовувати Aspose.TeX для C++ у своїх програмах:

1. [Завантажити](https://www.nuget.org/packages/Aspose.TeX.Cpp) останні файли.
2. Розархівуйте папку до робочого середовища.
3. Щоб використовувати Aspose.TeX для C++, зверніться до папок Include і lib у вашому проекті.

### Використання диспетчера пакетів Nuget

Щоб посилатися на компонент за допомогою консолі менеджера пакетів:

1. У диспетчері пакетів NuGet знайдіть Aspose.TeX
2. Виберіть пакет Aspose.TeX.Cpp у результатах пошуку
3. Виберіть потрібні проекти зі списку проектів рішень і натисніть кнопку **Встановити**, щоб інсталювати пакет
