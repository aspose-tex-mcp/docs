## Installation d'Aspose.TeX pour Python à partir de PyPi

**PyPI** (Python Package Index) est le référentiel officiel des packages logiciels tiers dans *Python*. Il est géré par la *Python Software Foundation*, qui est une organisation caritative. Les gestionnaires de packages comme `pip` utilisent souvent **PyPI** comme source par défaut pour les packages Python et leurs dépendances. **PyPI** héberge principalement des packages Python sous forme d'archives appelées `sdists` (distributions sources) ou *wheels* précompilées.

### Référencement d'Aspose.TeX pour Python

Profitant de ce référentiel, nous avons regroupé la bibliothèque [Aspose.TeX for Python](https://pypi.org/project/aspose-tex-net/) dans un package Wheel et l'avons téléchargée sur **PyPI**. Pour référencer le package dans votre projet, vous pouvez le télécharger à partir de la page qui vient d'être mentionnée, puis l'installer localement en tapant la commande suivante dans votre terminal Python.


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

Ou, vous pouvez l'installer directement depuis **PyPI** à l'aide de la commande ci-dessous.


```
pip install aspose-tex-net
```

Pour mettre à niveau vers la dernière version, utilisez la touche « --upgrade ».
