p1: "TeX är känt som ett av datamarkeringsspråken. Det är huvudkärnan i publikationsuppsättningssystemet (datortypsättning). Det är tveksamt att betrakta [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) som ett filformat, eftersom det är ett programmeringsspråk. Och å andra sidan är det en tolkmotor som förstår detta språk. Hur som helst, kort sagt, dess huvudsakliga syfte är att hjälpa till med skapandet av matematisk eller teknisk textskrivning."
p2: "Använd Aspose.TeX API i ditt eget projekt, glöm inte att ladda upp licensen för att inte bryta mot upphovsrätten. Här hittar du kodsnuttar som förklarar hur man laddar det från en stream och från en fil. För att köra exemplen behöver vi:"
p3: "Aspose.TeX för .NET API som är ett funktionsrikt, kraftfullt och lättanvänt API för dokumentmanipulation och konvertering för C#-plattformen."
p4: "Öppna NuGet-pakethanteraren och sök efter Aspose.TeX och installera. Du kan också använda följande kommando från Package Manager Console."
