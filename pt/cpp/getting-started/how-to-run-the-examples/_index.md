## Requisitos de software

Certifique -se de atender aos seguintes requisitos antes de baixar e executar os exemplos.

1. Visual Studio 2015 ou superior

## Download do github

Todos os exemplos de Aspose.TeX para C ++ são hospedados no [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP).

- Você pode clonar o repositório usando seu cliente Github favorito ou baixar o arquivo zip de [aqui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP/archive/master.zip).
- Extraia o conteúdo do arquivo zip para qualquer pasta do seu computador. Todos os exemplos estão localizados na pasta **** **.
- Existe um arquivo de solução do Visual Studio para C ++ em **Exemplo** Pasta.
- Abra o arquivo de solução no Visual Studio e crie o projeto.
- Instale o pacote da biblioteca para solução. [Como instalar.](/tex/{{lang.url-fragment}}cpp/installation/) A biblioteca de codeporting dependente será instalada automaticamente.
- Verifique **Versão do Windows SDK** nas propriedades do projeto para conceder as verões SDK do Windows SDK instaladas.
- **Exemplo/entrada** contém arquivos de entrada que os exemplos usam.
- **Exemplo/saída** Pasta deve apresentar. Está usando por exemplos.
- Aberto **fonte/runExample.cpp**; Todos os exemplos são chamados daqui.
- Descubra os exemplos que você deseja executar dentro do projeto.

Sinta -se à vontade para entrar em contato com nossos fóruns se tiver algum problema de configurar ou executar os exemplos.
