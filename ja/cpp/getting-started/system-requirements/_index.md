## オペレーティングシステム

サポートされているオペレーティングシステムは次のとおりです。

* MicrosoftWindowsデスクトップ(7、8、10)
* サーバーオペレーティングシステム(2008、2012)など。
* Linux Systems(ubuntu-16.04以降)

C ++のAspose.TeXは、32ビットオペレーティングシステムもサポートしています。  

サポートされていないオペレーティングシステム：

* OSの古いバージョン(XP、VistaおよびServer 2003)

## 開発環境

C ++のAsopse.texを使用して、C ++をサポートする任意の開発環境でアプリケーションを開発できますが、次の環境が明示的にサポートされています。

* Microsoft Visual Studio 2015以降
