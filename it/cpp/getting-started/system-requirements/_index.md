## Sistemi operativi

I sistemi operativi supportati includono:

* Microsoft Windows Desktop (7, 8, 10)
* Server Operating Systems (2008, 2012), ecc.
* Sistemi Linux (Ubuntu-16.04 o successivo)

Aspose.Tex per C ++ supporta anche sistemi operativi a 32 bit.  

Sistemi operativi che non sono supportati:

* Vecchie versioni di OS (XP, Vista e Server 2003)

## Ambienti di sviluppo

È possibile utilizzare Aspose.Tex per C ++ per sviluppare applicazioni in qualsiasi ambiente di sviluppo che supporti C ++, ma i seguenti ambienti sono esplicitamente supportati:

* Microsoft Visual Studio 2015 o successivo
