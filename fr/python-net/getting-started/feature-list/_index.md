## Fonctionnalités riches

**Opérations prises en charge**

- Composition d'entrée TeX
- Création de format TeX personnalisé
- Rendre les figures en LaTeX
- Rendre des formules et des équations mathématiques
- Polices de sous-ensemble
- Geler les formules mathématiques et les graphiques

**Prise en charge de divers formats de fichiers de sortie**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Modes pris en charge pour lire l'entrée et écrire la sortie**

- Répertoire du système de fichiers
- Archives ZIP
- Le fichier TeX principal peut également être transmis via un flux
