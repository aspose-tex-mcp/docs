## Githubからダウンロードしてください

JavaのAspose.TeXのすべての例は、GitHubでホストされています。お気に入りのGitHubクライアントを使用してリポジトリをクローンするか、ここからzipファイルをダウンロードできます。

zipファイルの内容をコンピューター上の任意のフォルダーに抽出します。すべての例は、例フォルダーにあります。このプロジェクトでは、Mavenビルドシステムを使用しています。最新のIDEは、プロジェクトとその依存関係を簡単に開設またはインポートできます。以下に、人気のあるIDEを使用して例を構築および実行する方法を示します。

## Intellijのアイデア

[ファイル]メニューをクリックして、[開く]を選択します。プロジェクトフォルダーを参照して、pom.xmlファイルを選択します。

プロジェクトを開き、依存関係を自動的にダウンロードします。 [プロジェクト]タブから、SRC/Main/Javaフォルダーの例を参照します。

例を実行するには、ファイルを右クリックして「実行..」を選択するだけで、例が実行され、ビルトインコンソール出力ウィンドウに出力が表示されます。

## 日食

[ファイル]メニューをクリックして、[インポート]を選択します。 Maven-既存のMavenプロジェクトを選択します。 githubからクローンまたはダウンロードしたフォルダーを参照し、pom.xmlファイルを選択します。

プロジェクトを開き、依存関係を自動的にダウンロードします。 [パッケージエクスプローラー]タブから、SRC/Main/Javaフォルダーの例を閲覧します。例を実行するには、ファイルを右クリックして[Javaアプリケーションとして実行]を選択するだけで、例が実行され、ビルトインコンソール出力ウィンドウに出力が表示されます。

## NetBeans

[ファイル]メニューをクリックして、[オープンプロジェクト]を選択します。 GitHubからクローニングまたはダウンロードしたフォルダーを参照します。例フォルダーのアイコンは、それがMavenプロジェクトであることを示します。例を選択して開きます。

プロジェクトを開き、依存関係を自動的にダウンロードします。 [プロジェクト]タブから、ソースパッケージの例を参照してください。例を実行するには、ファイルを右クリックして実行ファイルを選択するだけで、例が実行されると、ビルトインコンソール出力ウィンドウに出力が表示されます。

## 貢献する

例を追加または改善したい場合は、プロジェクトに貢献することをお勧めします。このリポジトリのすべての例とショーケースプロジェクトはオープンソースであり、独自のアプリケーションで自由に使用できます。

貢献するには、リポジトリをフォークし、ソースコードを編集し、プルリクエストを作成できます。変更を確認し、役立つ場合はリポジトリに含めます。
