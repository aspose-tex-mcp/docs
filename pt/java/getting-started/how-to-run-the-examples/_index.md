## Download do github

Todos os exemplos de Aspose.TeX para Java estão hospedados no Github. Você pode clonar o repositório usando seu cliente Github favorito ou fazer o download do arquivo zip aqui.

Extraia o conteúdo do arquivo zip para qualquer pasta do seu computador. Todos os exemplos estão localizados na pasta Exemplos. O projeto usa o sistema de construção do Maven. Qualquer IDE moderno pode abrir ou importar facilmente o projeto e suas dependências. Abaixo, mostramos como usar IDEs populares para construir e executar os exemplos.

## Intellij Idea

Clique no menu Arquivo e escolha Abrir. Navegue até a pasta do projeto e selecione o arquivo pom.xml.

Ele abrirá o projeto e baixará as dependências automaticamente. Na guia Projeto, procure os exemplos na pasta SRC/Main/Java.

Para executar um exemplo, basta clicar com o botão direito do mouse no arquivo e escolher "Executar ...", o exemplo será executado e a saída será mostrada na janela de saída do console interno.

## Eclipse

Clique no menu Arquivo e escolha Importar. Selecione Maven - Projetos Maven existentes. Navegue até a pasta que você clonou ou baixou do GitHub e selecione o arquivo pom.xml.

Ele abrirá o projeto e baixará as dependências automaticamente. Na guia Package Explorer, navegue pelos exemplos na pasta SRC/Main/Java. Para executar um exemplo, basta clicar com o botão direito do mouse no arquivo e escolher executar como aplicativo Java, o exemplo será executado e a saída será mostrada na janela de saída do console interno.

## Netbeans

Clique no menu Arquivo e escolha Open Project. Navegue até a pasta que você clonou ou baixou do GitHub. O ícone da pasta Exemplos mostrará que é um projeto MAVEN. Selecione exemplos e abra -o.

Ele abrirá o projeto e baixará as dependências automaticamente. Na guia Projetos, navegue pelos exemplos em pacotes de origem. Para executar um exemplo, basta clicar com o botão direito do mouse no arquivo e escolher o arquivo executado, o exemplo será executado e a saída será mostrada na janela de saída do console interno.
