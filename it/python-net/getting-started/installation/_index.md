## Installazione Aspose.TeX per Python da PyPI

**Pypi** (INDICE PYTHON PACKE) è il repository ufficiale per pacchetti software di terze parti in*Python*. È gestito dalla *Python Software Foundation*, che è un'organizzazione di beneficenza. I responsabili dei pacchetti come `Pip` usano spesso **pypi** come fonte predefinita per i pacchetti Python e le loro dipendenze. **Pypi** Ospita principalmente pacchetti Python sotto forma di archivi chiamati "Sdists" (Distribuzioni di fonte) o Precompilate *Wheels*.

### Riferimento a aspose.tex per python

Sfruttando questo repository, abbiamo bundle [Aspose.TeX per Python](https://pypi.org/project/aspose-tex-net/) Libreria in un pacchetto di ruote e lo abbiamo caricato su **Pypi**. Per fare riferimento al pacchetto nel progetto, puoi scaricarlo dalla pagina appena menzionata e quindi installarlo localmente digitando il seguente comando nel tuo terminale Python.


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

Oppure, puoi installarlo direttamente da **pypi** usando il comando sotto.


```
pip install aspose-tex-net
```

Per aggiornare all'ultima versione, utilizzare la chiave `-upgrade`.
