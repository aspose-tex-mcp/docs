## Installazione Aspose.TeX per C ++

### Installazione manuale

È possibile scaricare [Aspose.Tex per C ++](https://www.nuget.org/packages/Aspose.TeX.Cpp) dalla Nuget Gallery, facendo clic sul link "Scarica pacchetto" nella sezione Info. La documentazione API offline è disponibile anche nel pacchetto ZIP scaricato.

Si prega di eseguire i seguenti passaggi per utilizzare Aspose.TeX per C ++ nelle applicazioni:

1. [Download](https://www.nuget.org/packages/Aspose.TeX.Cpp) I file più recenti.
2. Decomprimere la cartella per l'ambiente di produzione.
3. Per utilizzare Aspose.TeX per C ++, le cartelle di riferimento e Lib nel progetto.

### Utilizzo del gestore dei pacchetti NuGet

Per fare riferimento al componente utilizzando la console di pacchetti:

1. In Nuget Package Manager, cerca Aspose.TeX
2. Seleziona il pacchetto ASPOSE.TEX.CPP nei risultati di ricerca
3. Seleziona i progetti necessari dall'elenco dei progetti di soluzione e premi **Installa** pulsante per installare il pacchetto
