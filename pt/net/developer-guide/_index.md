## Visão geral

O Guia do desenvolvedor serve como um recurso abrangente para a utilização efetiva do Aspose.TeX para a solução da API .NET. Seu objetivo principal é fornecer aos usuários insights sobre os conceitos, funcionalidades e práticas recomendadas para interagir com a solução API Aspose.TeX para C# .NET. Este guia oferece exemplos práticos essenciais para a compreensão da conversão, leitura, criação e outras manipulações dos formatos de arquivos TeX e LaTeX, incluindo:

- **[Conversão](/tex/{{lang.url-fragment}}net/conversion/)** - é o capítulo que informará sobre os pares de conversão mais necessários, entrada TeX e saída e muito mais.
- **[Pacotes de LaTeX externos](/tex/{{lang.url-fragment}}net/external-latex-packages/)** - é uma lista dos pacotes externos mais necessários com os detalhes sobre como fornecer esses pacotes ao mecanismo TeX da biblioteca.
