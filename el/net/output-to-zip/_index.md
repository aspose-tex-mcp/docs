title: Βήματα για τη χρήση καταλόγων ZIP για την έξοδο του αρχείου TeX C#.
h3: "Κωδικός C# για χρήση καταλόγων ZIP για έξοδο"
item1: "Δημιουργήστε την παρουσία της [*TeXOptions Class*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/)."
item2: "Καθορίστε έναν κατάλογο εργασίας αρχείου ZIP για την έξοδο χρησιμοποιώντας την ιδιότητα [*OutputWorkingDirectory*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/outputworkingdirectory/)."
item3: "Καθορίστε την κονσόλα ως τερματικό εξόδου χρησιμοποιώντας την κλάση [*OutputConsoleTerminal*](https://reference.aspose.com/tex/net/aspose.tex.io/outputconsoleterminal/)."
item4: "Καθορίστε τις επιλογές για αποθήκευση χρησιμοποιώντας την κλάση [*PdfSaveOptions*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfsaveoptions/)."
item5: "Εκτέλεση μετατροπής χρησιμοποιώντας τη μέθοδο [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) για [*PdfDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfdevice/)"
item6: Βελτιώστε την έξοδο.
item7: "Για να οριστικοποιήσετε το αρχείο ZIP εξόδου, χρησιμοποιήστε την κλάση [*OutputZipDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputzipdirectory/)."
