## Lista de paquetes LaTeX integrados

A menudo, los desarrolladores se preguntan qué paquetes de macros vienen integrados directamente en el entorno del motor Aspose.TeX y cuáles requieren una inclusión manual. La biblioteca Aspose.TeX incluye varios paquetes LaTeX. Aquí están:


| **Paquete** | **Versión** |
| :- | :- |
| `amsmath` | v2.17j 2021/04/20. |
| `colortbl` | v1.0f 2022/06/20. |
| `eurosym` | v1.1 1998/08/06. |
| `geometry` | Versión adaptada equivalente a la v5.9 2020/01/02. |
| `graphics` | Versión adaptada equivalente a la v1.4d 2021/03/04 (graphicx v1.2c 2020/12/05, color v1.0j 2005/11/14). |
| `hyperref` | Versión adaptada equivalente a la v6.83m 2012/11/06. |
| `lipsum` | v2.7 2021/09/20. |
| `multirow` | v2.8 2021/03/15. |
| `pgf` | v3.1.9a 2021/05/15. |
| `pict2e` | Versión adaptada equivalente a la v0.4b 2020/09/30. |
| `setspace` | v6.7b 2022/12/04. |
| `url` | v3.4 2013/09/16. |
| `wasysym` | v2.0 30/10/2003. |
| `xcolor` | v2.12 11/05/2016. |

### Paquete `latex-tools`:

`afterpage`, `array`, `bm`, `calc`, `dcolumn`, `delarray`, `enumerate`, `fileerr`, `fontsmpl`, `ftnright`, `hhline`, `indentfirst`, `layout`, `longtable`, `multicol`, `rawfonts`, `showkeys`, `somedefs`, `tabularx`, `theorem`, `trace`, `varioref`, `verbatim`, `xr` y `xspace`.

**Más información:**

- [Entrada/Salida de TeX (tex-io)](/tex/{{lang.url-fragment}}net/tex-io/): Descubra cómo `IInputWorkingDirectory` e `IOutputWorkingDirectory` gestionan los recursos de flujo (stream) y de disco.
- [¿Qué es LaTeX?](/tex/{{lang.url-fragment}}net/what-is-latex/)
- [Aspose.TeX y Object TeX](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/): Comprenda el modelo de objetos gestionado subyacente.

Inevitablemente, los documentos empresariales requieren archivos `.sty` o `.cls` especializados, o bien proporcionados por terceros, que no vienen integrados de forma predeterminada en el motor. Aspose también permite [trabajar con paquetes LaTeX externos](/tex/{{lang.url-fragment}}net/external-latex-packages/).
