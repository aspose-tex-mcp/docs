## Betriebssysteme

Zu den unterstützten Betriebssystemen gehören:

* Microsoft Windows-Desktop (7, 8, 10)
* Server-Betriebssysteme (2008, 2012) usw.
* Linux-Systeme (Ubuntu-16.04 oder höher)

Aspose.TeX für C++ unterstützt auch 32-Bit-Betriebssysteme.  

Nicht unterstützte Betriebssysteme:

* Alte Betriebssystemversionen (XP, Vista und Server 2003)

## Entwicklungsumgebungen

Sie können Aspose.TeX für C++ verwenden, um Anwendungen in jeder Entwicklungsumgebung zu entwickeln, die C++ unterstützt. Die folgenden Umgebungen werden jedoch ausdrücklich unterstützt:

* Microsoft Visual Studio 2015 oder höher
