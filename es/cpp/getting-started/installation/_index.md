## Instalación de Aspose.TeX para C++

### Instalación manual

Puede descargar [Aspose.TeX para C++](https://www.nuget.org/packages/Aspose.TeX.Cpp) desde la Galería NuGet, haciendo clic en el enlace "Descargar paquete" en la sección Información. La documentación de la API sin conexión también se puede encontrar en el paquete ZIP descargado.

Realice los siguientes pasos para utilizar Aspose.TeX para C++ en sus aplicaciones:

1. [Descargar](https://www.nuget.org/packages/Aspose.TeX.Cpp) los archivos más recientes.
2. Descomprima la carpeta en el entorno de producción.
3. Para usar Aspose.TeX para C++, haga referencia a las carpetas Incluir y lib en su proyecto.

### Usando el Administrador de paquetes Nuget

Para hacer referencia al componente usando la consola del administrador de paquetes:

1. En el Administrador de paquetes NuGet, busque Aspose.TeX
2. Seleccione el paquete Aspose.TeX.Cpp en los resultados de búsqueda
3. Seleccione los proyectos necesarios de la lista de proyectos de solución y presione el botón **Instalar** para instalar el paquete.
