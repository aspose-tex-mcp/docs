## ¿Qué es *AMS*-LÁTEX?

Basic LaTeX tiene una gama bastante amplia de capacidades para componer material matemático en documentos sencillos. Pero es posible que necesites algo más cuando a menudo se utilizan ecuaciones mostradas complejas o estructuras matemáticas más avanzadas. Puede definir nuevas construcciones de control LaTeX (comandos y entornos) para facilitar la escritura de fórmulas, pero, básicamente, no debería hacerlo. El paquete `amsmath` proporcionado por la Sociedad Estadounidense de Matemáticas **(AMS)** hace que el proceso sea más fácil y consistente para usted. En realidad, es el paquete principal de la colección, ***AMS*-LATEX**. El material de este capítulo está dedicado principalmente a este paquete.

El capítulo analiza brevemente y proporciona ejemplos de muchas de las características de estos paquetes, así como también algunas relacionadas. También proporcionamos aquí algunos conceptos básicos de composición tipográfica matemática con TeX, lo que significa que expone algunas de las características estándar de LaTeX para composición tipográfica y diseño matemático.
