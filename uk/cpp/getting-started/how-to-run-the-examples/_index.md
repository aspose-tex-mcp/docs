## Вимоги до програмного забезпечення

Перш ніж завантажувати та запускати приклади, переконайтеся, що ви відповідаєте наведеним нижче вимогам.

1. Visual Studio 2015 або вище

## Завантажити з GitHub

Усі приклади Aspose.TeX для C++ розміщено на [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP).

- Ви можете клонувати репозиторій за допомогою свого улюбленого клієнта GitHub або завантажити ZIP-файл [тут](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP/archive/master.zip).
- Розпакуйте вміст ZIP-файлу в будь-яку папку на вашому комп’ютері. Усі приклади знаходяться в папці **Приклади**.
- Є один файл рішення Visual Studio для C++ у папці **example**.
- Відкрийте файл рішення у Visual Studio та побудуйте проект.
- Встановіть пакет бібліотеки для рішення. [Як встановити.](/tex/{{lang.url-fragment}}cpp/installation/) Залежна бібліотека CodePorting буде встановлена ​​автоматично.
- Перевірте **версію Windows SDK** у властивостях проекту відповідно до встановлених версій Windows SDK.
- **example/input** містить вхідні файли, які використовують приклади.
- Повинна бути папка **example/output**. Це використання на прикладах.
- Відкрийте **source/RunExamples.cpp**; усі приклади викликаються звідси.
- Розкоментуйте приклади, які ви хочете запустити в рамках проекту.

Будь ласка, не соромтеся зв’язатися з нашими форумами, якщо у вас виникли проблеми з налаштуванням або запуском прикладів.

## Зробити свій внесок

Якщо ви хочете додати чи покращити приклад, ми заохочуємо вас зробити внесок у проект. Усі приклади та демонстраційні проекти в цьому репозиторії є відкритими і їх можна вільно використовувати у ваших власних програмах.

Щоб зробити внесок, ви можете розгалужити репозиторій, відредагувати вихідний код і створити запит на отримання. Ми переглянемо зміни та додамо їх до репозиторію, якщо вони будуть корисними.
