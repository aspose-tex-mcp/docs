## 丰富的功能

**支持的操作**

- TEX输入排版
- 定制Tex格式创建
- 在乳胶中渲染数字
- 渲染数学公式和方程式
- 子集字体
- 冻结数学公式和图形

**支持各种输出文件格式**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**支持阅读输入和写入输出的方式**

- 文件系统目录
- 拉链档案
- 主Tex文件也可以通过流传递
