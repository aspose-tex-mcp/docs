## Caratteristiche ricche

**Operazioni supportate**

- Composizione input TeX
- Creazione del formato TeX personalizzato
- Conversione TeX/LaTeX
- Incorporamento di elementi grafici nei file LaTeX
- Disegno di figure e formule matematiche complesse nei file LaTeX
- Convalida, strutturazione e ripristino dei file LaTeX

**Supporto per vari formati di file di output**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Modi supportati per leggere l'input e scrivere l'output**

- Directory del file system
- Archivio ZIP
- Il file TeX principale può anche essere passato attraverso un flusso

{{% alert color="primary" %}}

A differenza delle tradizionali utilità TeX da riga di comando, Aspose.TeX per .NET è una libreria standalone gestita al 100%. Non richiede un'installazione locale di TeX Live, MiKTeX o alcun eseguibile nativo sottostante.
