## Elenco dei pacchetti LaTeX integrati

Gli sviluppatori si chiedono spesso quali pacchetti di macro siano inclusi direttamente nell'ambiente del motore Aspose.TeX e quali, invece, richiedano un'aggiunta manuale. La libreria Aspose.TeX contiene diversi pacchetti LaTeX integrati. Eccoli di seguito:


| **Pacchetto**| **Versione**|
| :- | :- |
| `amsmath` | v2.17j 2021/04/20. |
| `colortbl` | v1.0f 2022/06/20. |
| `eurosym` | v1.1 1998/08/06. |
| `geometry` | Versione adattata equivalente alla v5.9 2020/01/02 |
| `graphics` | Versione adattata equivalente alla v1.4d 2021/03/04 (graphicx v1.2c 2020/12/05, color v1.0j 2005/11/14). |
| `hyperref` | Versione adattata equivalente alla v6.83m 2012/11/06. |
| `lipsum` | v2.7 2021/09/20. |
| `multirow` | v2.8 2021/03/15. |
| `pgf` | v3.1.9a 2021/05/15. |
| `pict2e` | Versione adattata equivalente alla v0.4b 2020/09/30. |
| `setspace` | v6.7b 2022/12/04. |
| `url` | v3.4 2013/09/16. |
| `wasysym` | v2.0 30/10/2003. |
| `xcolor` | v2.12 11/05/2016. |

### Pacchetto `latex-tools`:

`afterpage`, `array`, `bm`, `calc`, `dcolumn`, `delarray`, `enumerate`, `fileerr`, `fontsmpl`, `ftnright`, `hhline`, `indentfirst`, `layout`, `longtable`, `multicol`, `rawfonts`, `showkeys`, `somedefs`, `tabularx`, `theorem`, `trace`, `varioref`, `verbatim`, `xr` e `xspace`.

**Per saperne di più:**

- [Input/Output in TeX (tex-io)](/tex/{{lang.url-fragment}}net/tex-io/): scopri come `IInputWorkingDirectory` e `IOutputWorkingDirectory` gestiscono le risorse su disco e i flussi (stream).
- [Cos'è LaTeX](/tex/{{lang.url-fragment}}net/what-is-latex/)
- [Aspose.TeX e Object TeX](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/): per comprendere il modello a oggetti gestito sottostante.

Spesso, i documenti aziendali richiedono file `.sty` o `.cls` specifici o di terze parti che non sono pre-integrati nel motore. Aspose supporta anche l'utilizzo di [pacchetti LaTeX esterni](/tex/{{lang.url-fragment}}net/external-latex-packages/).
