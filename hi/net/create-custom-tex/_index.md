p1: "TeX को डेटा मार्कअप भाषाओं में से एक के रूप में जाना जाता है। यह प्रकाशन सेट सिस्टम (कंप्यूटर टाइपसेटिंग) का मुख्य केंद्र है। [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) को एक फ़ाइल प्रारूप के रूप में मानना ​​संदिग्ध है, क्योंकि यह एक प्रोग्रामिंग भाषा है। और दूसरी ओर, यह एक दुभाषिया इंजन है जो इस भाषा को समझता है। वैसे भी, संक्षेप में, इसका मुख्य उद्देश्य गणितीय या तकनीकी पाठ लेखन के निर्माण में मदद करना है। eΧ के आधार पर कई अलग-अलग पैकेट बनाए गए हैं। उनका उद्देश्य दस्तावेजों को संसाधित करना आसान बनाना है, खासकर जब उनके पास सूत्र या गणित के समीकरण हों।"
p2: "विभिन्न अन्य सुविधाओं के बीच Aspose.TeX API समाधान आपकी खुद की विशेष रुप से प्रदर्शित TeX फ़ाइलें बनाने की अनुमति देता है। यहां आपको ऐसी जानकारी मिलेगी जो बताती है कि इस तरह के एक अनुकूलित प्रारूप की फाइलें कैसे बनाई जाती हैं। ऐसी फ़ाइल में अनुकूलित इंजन विकल्प होंगे। इसके लिए हमें चाहिए:"
p3: ".NET API के लिए Aspose.TeX जो C# प्लेटफॉर्म के लिए एक सुविधा संपन्न, शक्तिशाली और उपयोग में आसान दस्तावेज़ हेरफेर और रूपांतरण API है।"
p4: "NuGet पैकेज मैनेजर खोलें, और Aspose.TeX खोजें और इंस्टॉल करें। आप पैकेज मैनेजर कंसोल से निम्न कमांड का भी उपयोग कर सकते हैं।"

item2: "[*InputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/inputfilesystemdirectory/) क्लास का उपयोग करके, इनपुट के लिए एक फाइल सिस्टम वर्किंग डायरेक्टरी निर्दिष्ट करें।"

item4: "[*TeXJob.CreateFormat()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/createformat/) विधि का उपयोग करके प्रारूप बनाएं।"
