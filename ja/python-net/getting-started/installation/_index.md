## PypiからPython用のAspose.TeXをインストールします

**pypi**(pythonパッケージインデックス)は、*python*のサードパーティソフトウェアパッケージの公式リポジトリです。慈善団体である *Python Software Foundation *によって管理されています。 「PIP」のようなパッケージマネージャーは、**Pypi**をPythonパッケージとその依存関係のデフォルトソースとして使用することがよくあります。 **pypi**主に「sdists」(ソース分布)またはプリコンパイルされた*ホイール*と呼ばれるアーカイブの形でPythonパッケージをホストしています。

### PythonのAspose.TeXを参照します

このリポジトリを活用して、[Python用のAspose.TeX](https://pypi.org/project/aspose-tex-net/)ライブラリをホイールパッケージにバンドルし、**pypi**にアップロードしました。プロジェクトのパッケージを参照するには、上記のページからダウンロードしてから、Python端子に次のコマンドを入力してローカルにインストールできます。


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

または、コマンドBellowを使用して**pypi**からDireclyをインストールすることができます。


```
pip install aspose-tex-net
```

最新バージョンにアップグレードするには、 `--upgrade`キーを使用します。
