У цьому розділі розглядається встановлення та базове налаштування розширення TikZ для TeX та LaTeX. Ми надамо чіткі покрокові інструкції, які допоможуть вам швидко розпочати створення графіки за допомогою TikZ.

## Встановлення TikZ

TikZ постачається з попередньо встановленими популярними дистрибутивами TeX, такими як **TeX Live** та **MiKTeX**. Якщо ви використовуєте ці дистрибутиви, у вас, ймовірно, вже встановлено TikZ. Якщо ні, виконайте ці інструкції:

### Користувачі TeX Live

1. Відкрийте менеджер TeX Live (`tlmgr`).
2. Оновіть список пакетів:

   ```bash
   tlmgr update --self --all
   ```

3. Встановіть TikZ (частина пакета `pgf`):

   ```bash
   tlmgr install pgf
   ```

### Користувачі MiKTeX

1. Відкрийте консоль MiKTeX.
2. Перейдіть на вкладку **Пакети**.
3. Введіть `pgf` у рядок пошуку.
4. Виберіть та встановіть пакет `pgf`, якщо він ще не встановлений.

## Перевірка встановлення

Ви можете перевірити успішне встановлення TikZ за допомогою цього простого тестового документа:

```tex
\documentclass{article}
\usepackage{tikz}

\begin{document}

Тестування TikZ:

\begin{tikzpicture}
  \draw (0,0) rectangle (2,1);
\end{tikzpicture}

\end{document}
```

Скомпілюйте цей документ за допомогою `pdflatex` або будь-якого редактора, сумісного з LaTeX (наприклад, TeXworks або Overleaf). У результуючому PDF-файлі ви повинні побачити невеликий прямокутник.

## Базова конфігурація TikZ

TikZ вимагає мінімальної конфігурації. Однак ви можете встановити глобальні параметри для керування поведінкою графіки:

- **Масштабувати графіку глобально**:

  ```tex
  \tikzset{every picture/.style={scale=1.5}}
  ```

- **Встановлення кольорів та стилів ліній за замовчуванням**:

  ```tex
  \tikzset{
    every path/.style={thick, blue},
    every node/.style={font=\small}
  }
  ```

Включіть ці команди у преамбулу вашого документа, щоб застосувати узгоджене стилізування.

## Рекомендовані редактори для TikZ

Для комфортного редагування та компіляції в реальному часі ми рекомендуємо такі редактори LaTeX:

- **TeXstudio** – Безкоштовний, багатофункціональний редактор з інтегрованим попереднім переглядом TikZ.

- **Overleaf** – Хмарний редактор для спільної роботи з чудовою підтримкою TikZ.

- **Visual Studio Code** з розширенням **LaTeX Workshop** – Сучасний, легкий редактор з підтримкою TikZ.

Виберіть редактор на основі ваших уподобань та вимог до робочого процесу.
