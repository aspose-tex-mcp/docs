## Требования к программному обеспечению

Прежде чем загружать и запускать примеры, убедитесь, что вы соответствуете следующим требованиям.

1. Visual Studio 2015 или новее.

## Скачать с GitHub

Все примеры Aspose.TeX для C++ размещены на [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP).

- Вы можете либо клонировать репозиторий, используя свой любимый клиент GitHub, либо загрузить ZIP-файл отсюда (2).
- Извлеките содержимое ZIP-файла в любую папку на вашем компьютере. Все примеры находятся в папке **Examples**.
- В папке **example** находится один файл решения Visual Studio для C++.
- Откройте файл решения в Visual Studio и создайте проект.
- Установите пакет библиотеки для решения. [Как установить.](/tex/{{lang.url-fragment}}cpp/installation/) Зависимая библиотека CodePorting будет установлена ​​автоматически.
- Установите флажок **Версия Windows SDK** в свойствах проекта, чтобы соответствовать установленным версиям Windows SDK.
- **example/input** содержит входные файлы, которые используются в примерах.
- Должна присутствовать папка **example/output**. Это использование примеров.
- Откройте **source/RunExamples.cpp**; все примеры вызываются отсюда.
- Раскомментируйте примеры, которые хотите запустить из проекта.

Если у вас возникнут проблемы с настройкой или запуском примеров, обращайтесь на наши форумы.

## Способствовать

Если вы хотите добавить или улучшить пример, мы рекомендуем вам внести свой вклад в проект. Все примеры и демонстрационные проекты в этом репозитории имеют открытый исходный код и могут свободно использоваться в ваших собственных приложениях.

Чтобы внести свой вклад, вы можете разветвить репозиторий, отредактировать исходный код и создать запрос на включение. Мы рассмотрим изменения и включим их в репозиторий, если они окажутся полезными.
