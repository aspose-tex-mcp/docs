## 操作系统

支持的操作系统包括：

* Microsoft Windows桌面(7，8，10)
* 服务器操作系统(2008，2012)，等。
* Linux系统(Ubuntu-16.04或更高版本)

C ++的Aspose.TeX也支持32位操作系统。  

不支持的操作系统：

* OS的旧版本(XP，Vista和Server 2003)

## 开发环境

您可以在任何支持C ++的开发环境中使用aspose.tex来开发应用程序，但是明确支持以下环境：

* Microsoft Visual Studio 2015或以后
