{{<section overview>}}
---
p1: "TeX dikenal sebagai salah satu bahasa markup data dan/atau bahasa pengaturan huruf pada saat yang bersamaan. Ini berarti bahwa Anda tidak memformat teks Anda dalam dokumen, tetapi memasukkan teks biasa bersama dengan perintah. Sebagai output, Anda akan mendapatkan file yang diformat dengan format yang dibutuhkan (ditentukan). [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) adalah inti utama dari sistem set publikasi (pengaturan huruf komputer)."
p2: "Untuk lebih memahami pengaturan huruf TeX, pelajari [*TeX I/O*](https://docs.aspose.com/tex/net/tex-io/) dari Dokumentasi. Dan di halaman ini Anda akan menemukan cuplikan kode yang menjelaskan cara mengeset file TeX menggunakan format TeX khusus."
p3: "Untuk menjalankan contoh yang kita butuhkan:"
p4: "Aspose.TeX untuk .NET API yang merupakan API konversi dan manipulasi dokumen yang kaya fitur, kuat, dan mudah digunakan untuk platform C#."
p5: "Buka manajer paket NuGet, dan cari Aspose.TeX dan instal. Anda juga dapat menggunakan perintah berikut dari Package Manager Console."

title: Langkah-langkah mengeset TeX menggunakan C#.
h3: "Kode C# untuk pengaturan huruf TeX"
item1: "Buat penyedia format menggunakan Kelas [*InputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/inputfilesystemdirectory/)."
item2: "Buat opsi konversi untuk format khusus pada ekstensi mesin ObjectTeX menggunakan [*ConsoleAppOptions()*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/consoleappoptions) Metode [*TeXOptions*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/) Kelas."
item3: "Tentukan direktori kerja input jika input utama tidak disediakan sebagai aliran. Gunakan Kelas [*InputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/inputfilesystemdirectory/) untuk ini."
item4: "Tentukan direktori kerja sistem file untuk output. Gunakan Kelas [*OutputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputfilesystemdirectory/) untuk ini."
item5: "Jalankan pekerjaan [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) Metode untuk [*XpsDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.xps/xpsdevice/)."
item6: Perbaiki outputnya.
