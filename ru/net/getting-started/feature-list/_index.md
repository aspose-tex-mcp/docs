## Богатые возможности

**Поддерживаемые операции**

- Набор текста ввода TeX
- Создание собственного формата TeX
- Конвертация TeX/LaTeX
- Внедрение графики в файлы LaTeX
- Рисование фигур и сложных математических уравнений в файлах LaTeX
- Проверка, структурирование и восстановление файлов LaTeX

**Поддержка различных форматов выходных файлов**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Поддерживаемые способы чтения ввода и записи вывода**

- Каталог файловой системы
- ZIP-архив
- Основной файл TeX также можно передать через поток.

{{% alert color="primary" %}}

В отличие от традиционных консольных утилит TeX, Aspose.TeX для .NET является полностью управляемой независимой библиотекой. Она не требует локальной установки TeX Live, MiKTeX или каких-либо базовых исполняемых файлов платформы.

{{% /alert %}}
