## Requisitos previos

Antes de continuar, asegúrese de que la carpeta `Aspose.TeX-...` aparezca en la carpeta `[PYTHON_PATH]\Lib\site-packages\` después de la [instalación del paquete Aspose.TeX](). Si tiene Python 3.11 instalado, Aspose.TeX se puede instalar en la carpeta `[PYTHON_PATH]\site-packages\`. En este caso, debe copiar la carpeta Aspose.TeX a la carpeta `[PYTHON_PATH]\Lib\site-packages\`, ya que **PyCharm** (al menos la versión 23.1) busca paquetes instalados exactamente en esa ubicación.

## Descargar desde GitHub

Todos los ejemplos de Aspose.TeX para Python están disponibles en [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET). Tiene dos opciones para acceder a los ejemplos: puede clonar el repositorio usando su cliente GitHub preferido o puede descargar el archivo ZIP desde [aquí](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip). Extraiga el contenido del archivo ZIP a cualquier carpeta de su computadora. Encontrará todos los ejemplos ubicados en la carpeta `Aspose.TeX.Examples`. A continuación, demostraremos cómo crear y ejecutar los ejemplos utilizando IDE populares.

Si encuentra algún problema al configurar o ejecutar los ejemplos, no dude en comunicarse con nosotros a través de nuestros foros.

## PyCharm

Vaya al menú ***Archivo*** y elija ***Abrir***. Seleccione la carpeta del proyecto de ejemplo y haga clic en el botón ***Aceptar***. El proyecto será abierto. Luego, vaya al menú ***Ejecutar*** y elija ***Editar configuraciones***. En el panel izquierdo, agregue una nueva configuración de Python. En el panel derecho, establezca el nombre de la configuración (por ejemplo, "run_examples"). Especifique la ruta absoluta a `run_examples.py` en el campo ***Ruta del script*** y la ruta absoluta a la carpeta del proyecto en el campo ***Directorio de trabajo***.

Para ejecutar un ejemplo, simplemente vaya al menú ***Ejecutar*** y elija ***Ejecutar 'run_examples'***, o use el método abreviado de teclado `Shift+F10`. El ejemplo se ejecutará y el resultado se mostrará en la ventana de la consola de PyCharm. Los archivos de salida generados durante la ejecución de los ejemplos se pueden encontrar en la carpeta "salida".

## Microsoft Visual Studio

Asegúrese de que la característica **Desarrollo de Python** esté instalada en Visual Studio. Abra Visual Studio y haga clic en el lado derecho del elemento ***Abrir una carpeta local***. Luego, busque la carpeta del proyecto de ejemplos de Aspose.TeX. Visual Studio lo reconocerá como un proyecto de Python y abrirá el IDE de Python. Una vez abierta la carpeta, haga clic derecho en "run_examples" en el Explorador de soluciones y seleccione ***Establecer como elemento de inicio***

Para ejecutar ejemplos, simplemente haga clic en el botón ***run_examples.py*** con la flecha verde en la barra de herramientas de la ventana de Visual Studio.
