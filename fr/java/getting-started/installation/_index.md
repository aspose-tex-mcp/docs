## Installation d'Aspose.TeX pour Java à partir du référentiel Aspose

Aspose héberge toutes les API Java sur Aspose Repository. Vous pouvez facilement utiliser l'API Aspose.TeX pour Java directement dans vos projets Maven avec des configurations simples.

## Spécifier la configuration du référentiel Aspose

Tout d’abord, vous devez spécifier la configuration/l’emplacement du référentiel Aspose dans votre pom.xml Maven comme suit :


```
<repositories>
     <repository>
         <id>snapshots</id>
         <name>repo</name>
         <url>https://releases.aspose.com/java/repo/</url>
     </repository>
</repositories>
```

## Définir Aspose.TeX pour la dépendance de l'API Java

Définissez ensuite la dépendance de l'API Aspose.TeX pour Java dans votre pom.xml comme suit :

```
<dependencies>
    <dependency>
        <groupId>com.aspose</groupId>
        <artifactId>aspose-tex</artifactId>
        <version>21.4</version>
    </dependency>
</dependencies>
```

Après avoir effectué les étapes ci-dessus, la dépendance Aspose.TeX pour Java sera enfin définie dans votre projet Maven.
