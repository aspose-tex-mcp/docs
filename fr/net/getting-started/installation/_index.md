## Installation d'Aspose.TeX pour .NET via NuGet

NuGet est un système de gestion de packages gratuit et open source destiné aux développeurs pour la plate-forme .NET, destiné à simplifier le processus d'incorporation de bibliothèques tierces dans une application .NET pendant le développement. Il s'agit d'une extension Visual Studio qui facilite l'ajout, la suppression et la mise à jour de bibliothèques et d'outils dans les projets Visual Studio qui utilisent le .NET Framework. Une bibliothèque ou un outil peut facilement être partagé avec d'autres développeurs en créant un package NuGet et en le stockant dans un référentiel NuGet. Lorsque vous installez le package, NuGet copie les fichiers dans votre solution et apporte automatiquement les modifications nécessaires, telles que l'ajout de références et la modification de vos fichiers app.config ou web.config. Si vous décidez de supprimer la bibliothèque, NuGet supprime les fichiers et annule les modifications apportées à votre projet afin de ne laisser aucun encombrement.

### Référencement d'Aspose.TeX pour .NET

Profitant de cette merveilleuse fonctionnalité, nous avons regroupé les bibliothèques [Aspose.TeX for .NET](https://www.nuget.org/packages/Aspose.TeX) dans un package NuGet et l'avons téléchargé dans un référentiel NuGet. Avec cette option, vous bénéficiez de l'utilisation d'Aspose.TeX pour .NET sans installer ce composant sur votre système. NuGet s'exécute dans Visual Studio 2010 et versions supérieures, Visual Web Developer 2010 et Windows Phone Developer Tools 7.1. Lors de nos tests, nous l'avons testé avec Visual Studio 2015 Ultimate.

Pour commencer :

1. Ouvrez votre solution ou projet dans Visual Studio.
2. Ajoutez NuGet Package Manager en tant qu'extension Visual Studio :

   1. Sélectionnez le menu **Outils** suivi de **Extension Manager**.
   2. Sélectionnez **Galerie en ligne** pour obtenir une liste complète des packages disponibles en ligne.
   3. Sélectionnez **Gestionnaire de packages NuGet**.
   4. Cliquez sur **Télécharger**.
   5. Une fois le gestionnaire de packages installé, redémarrez Visual Studio pour appliquer les modifications. 
   
      Lorsque NuGet Package Manager est installé, vous pouvez rechercher, installer, supprimer et mettre à jour des packages à partir de la fenêtre **Gérer les packages NuGet** ou à l'aide des commandes de ligne de commande PowerShell dans la fenêtre Visual Studio dédiée à la **Package Manager Console**. . Vous pouvez trouver les deux options si vous sélectionnez **Outils** suivi de **Library Package Manager**.

### Installer le package à l'aide de la console du gestionnaire de packages

Pour référencer le composant à l'aide de la console du gestionnaire de packages :

1. Ouvrez votre application .NET dans Visual Studio.
2. Dans le menu **Outils**, sélectionnez **Library Package Manager**, puis **Package Manager Console**.
3. Tapez la commande « Install-Package Aspose.TeX » pour installer la dernière version complète, ou tapez la commande « Install-Package Aspose.TeX -prerelease » pour installer la dernière version, y compris les correctifs.
4. Appuyez sur **Entrée**.

### Mettre à jour le package à l'aide de la console du gestionnaire de packages

Si vous avez déjà référencé le composant via NuGet, suivez ces étapes pour mettre à jour la référence vers la dernière version :

1. Ouvrez votre application .NET dans Visual Studio.
2. Dans le menu **Outils**, sélectionnez **Library Package Manager**, suivi de **Package Manager Console** pour ouvrir la console Package Manager.
3. Tapez la commande « Update-Package Aspose.TeX » pour référencer la dernière version complète, ou tapez la commande « Update-Package Aspose.TeX -prerelease » pour installer la dernière version, y compris les correctifs.
4. Appuyez sur **Entrée**.

### Installer le package à l'aide de l'interface graphique du gestionnaire de packages

Suivez ces étapes pour référencer le composant à l'aide de l'interface graphique du gestionnaire de packages :

1. Ouvrez votre application .NET dans Visual Studio.
2. Dans le menu **Outils**, sélectionnez **Library Package Manager** et **Gérer les packages NuGet** dans l'option **Solution**. 

   Vous pouvez également obtenir une option similaire à partir de l'Explorateur de solutions :
   1. Cliquez avec le bouton droit sur le nom du projet.
   2. Sélectionnez **Gérer les packages NuGet**.

3. Sélectionnez **en ligne** dans le menu de gauche.
4. Tapez **Aspose.TeX** dans la zone de recherche pour trouver Aspose.TeX pour .NET.
5. Cliquez sur **Installer/Mettre à jour** à côté de la dernière version d'Aspose.TeX pour .NET.
