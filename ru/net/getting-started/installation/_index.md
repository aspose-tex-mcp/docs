## Выбор пакета

Aspose.TeX для .NET выпускается в виде двух пакетов NuGet с одинаковым API:

- [Aspose.TeX](https://www.nuget.org/packages/Aspose.TeX) использует `System.Drawing.Common` и работает в Windows.
- [Aspose.TeX.Drawing](https://www.nuget.org/packages/Aspose.TeX.Drawing) использует встроенную графическую подсистему Aspose.Drawing и работает в Windows, Linux и macOS, включая Docker-контейнеры.

Подключайте только один из них. Чтобы установить пакет с помощью .NET CLI, выполните одну из следующих команд в папке проекта:

```bash
dotnet add package Aspose.TeX
```

```bash
dotnet add package Aspose.TeX.Drawing
```

Подробнее об `Aspose.TeX.Drawing` см. [Linux, macOS и Docker](/tex/{{lang.url-fragment}}net/linux-and-containers/). Дальше на этой странице описана установка в Visual Studio; она одинакова для обоих пакетов.

## Установка Aspose.TeX для .NET через NuGet

NuGet — это бесплатная система управления пакетами с открытым исходным кодом, ориентированная на разработчиков, для платформы .NET, призванная упростить процесс включения сторонних библиотек в приложение .NET во время разработки. Это расширение Visual Studio, которое позволяет легко добавлять, удалять и обновлять библиотеки и инструменты в проектах Visual Studio, использующих .NET Framework. Библиотекой или инструментом можно легко поделиться с другими разработчиками, создав пакет NuGet и сохранив его в репозитории NuGet. Когда вы устанавливаете пакет, NuGet копирует файлы в ваше решение и автоматически вносит необходимые изменения, например добавляет ссылки и изменяет файлы app.config или web.config. Если вы решите удалить библиотеку, NuGet удалит файлы и отменит все изменения, внесенные в ваш проект, чтобы не осталось беспорядка.

### Ссылка на Aspose.TeX для .NET

Воспользовавшись этой замечательной функцией, мы объединили библиотеки [Aspose.TeX for .NET](https://www.nuget.org/packages/Aspose.TeX) в пакет NuGet и загрузили его в репозиторий NuGet. Благодаря этому варианту вы получаете выгоду от использования Aspose.TeX для .NET без установки этого компонента в вашей системе. NuGet работает в Visual Studio 2010 и более поздних версиях, Visual Web Developer 2010 и инструментах разработчика Windows Phone 7.1. В наших тестах мы тестировали его с помощью Visual Studio 2015 Ultimate.

Чтобы начать:

1. Откройте свое решение или проект в Visual Studio.
2. Добавьте диспетчер пакетов NuGet в качестве расширения Visual Studio:

   1. Выберите меню **Инструменты**, а затем **Диспетчер расширений**.
   2. Выберите **Интернет-галерея**, чтобы просмотреть полный список пакетов, доступных в Интернете.
   3. Выберите **Диспетчер пакетов NuGet**.
   4. Нажмите **Загрузить**.
   5. После установки диспетчера пакетов перезапустите Visual Studio, чтобы изменения вступили в силу. 
   
      Если установлен диспетчер пакетов NuGet, вы можете находить, устанавливать, удалять и обновлять пакеты из окна **Управление пакетами NuGet** или с помощью команд командной строки PowerShell в специальном окне **Консоль диспетчера пакетов** Visual Studio. . Вы можете найти оба варианта, если выберете **Инструменты**, а затем **Диспетчер пакетов библиотек**.

### Установите пакет с помощью консоли диспетчера пакетов.

Чтобы обратиться к компоненту с помощью консоли менеджера пакетов:

1. Откройте приложение .NET в Visual Studio.
2. В меню **Инструменты** выберите **Диспетчер пакетов библиотеки**, а затем **Консоль диспетчера пакетов**.
3. Введите команду «Install-Package Aspose.TeX», чтобы установить последнюю полную версию, или введите команду «Install-Package Aspose.TeX -prerelease», чтобы установить последнюю версию, включая исправления.
4. Нажмите **Ввод**.

### Обновить пакет с помощью консоли диспетчера пакетов

Если вы уже ссылались на компонент через NuGet, выполните следующие действия, чтобы обновить ссылку до последней версии:

1. Откройте приложение .NET в Visual Studio.
2. В меню **Инструменты** выберите **Диспетчер пакетов библиотеки**, а затем **Консоль диспетчера пакетов**, чтобы открыть консоль диспетчера пакетов.
3. Введите команду «Update-Package Aspose.TeX», чтобы получить ссылку на последнюю полную версию, или введите команду «Update-Package Aspose.TeX -prerelease», чтобы установить последнюю версию, включая исправления.
4. Нажмите **Ввод**.

### Установите пакет с помощью графического интерфейса диспетчера пакетов.

Выполните следующие действия, чтобы сослаться на компонент с помощью графического интерфейса менеджера пакетов:1. Откройте приложение .NET в Visual Studio.
2. В меню **Инструменты** выберите **Диспетчер пакетов библиотек** и **Управление пакетами NuGet** в разделе **Решение**. 

   Вы также можете получить аналогичную опцию в обозревателе решений:
   1. Щелкните правой кнопкой мыши имя проекта.
   2. Выберите **Управление пакетами NuGet**.

3. Выберите **онлайн** в меню слева.
4. Введите **Aspose.TeX** в поле поиска, чтобы найти Aspose.TeX для .NET.
5. Нажмите **Установить/Обновить** рядом с последней версией Aspose.TeX для .NET.
