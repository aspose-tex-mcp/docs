Με απλά λόγια, είναι μια μετατροπή με την εγγραφή της εξόδου στο δίσκο. Για να εκτελέσουμε μια τέτοια λειτουργία χρειαζόμαστε:"
p4: "Το Aspose.TeX για .NET API το οποίο είναι ένα πλούσιο σε χαρακτηριστικά, ισχυρό και εύχρηστο API χειρισμού και μετατροπής εγγράφων για πλατφόρμα C#."
p5: "Ανοίξτε τη διαχείριση πακέτων NuGet και αναζητήστε Aspose.TeX και εγκαταστήστε. Μπορείτε επίσης να χρησιμοποιήσετε την ακόλουθη εντολή από την Κονσόλα Package Manager."

h3: "Κωδικός C# για μετατροπή TeX και εγγραφή της εξόδου στο δίσκο"
item1: "Δημιουργήστε επιλογές μετατροπής στην επέκταση του κινητήρα ObjectTeX χρησιμοποιώντας [*ConsoleAppOptions()*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/consoleappoptions) Μέθοδο του [*TeXOptions*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/) Τάξη."
item2: "Καθορίστε ένα όνομα εργασίας εάν δεν θέλετε το πρώτο όρισμα του κατασκευαστή TeXJob να λαμβάνεται ως όνομα εργασίας."
item3: "Καθορίστε έναν κατάλογο εργασίας συστήματος αρχείων για την είσοδο. Χρησιμοποιήστε την κλάση [*InputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/inputfilesystemdirectory/) για αυτό."
item4: "Καθορίστε έναν κατάλογο εργασίας συστήματος αρχείων για την έξοδο με τη βοήθεια των οντοτήτων της κλάσης [*OutputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputfilesystemdirectory/)."
item5: "Καθορίστε ότι η έξοδος τερματικού πρέπει να εγγραφεί σε ένα αρχείο στον κατάλογο εργασίας εξόδου."
item6: "Εκτελέστε τη μέθοδο εργασίας [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) για [*XpsDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.xps/xpsdevice/)."
