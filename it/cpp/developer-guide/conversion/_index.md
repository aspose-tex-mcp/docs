Se hai già letto ["Introduzione a Texs"](/tex/{{lang.url-fragment}}net/introduction-to-tex/), probabilmente ritieni che l'uso delle parole *"converti"* e *"conversione"* non è del tutto appropriato nel contesto di Tex, poiché la composizione di un file Tex non è realmente una mappatura da un formato all'altro. Tuttavia, seguendo la tradizione e i gusti del cliente, consentiamo l'uso di queste parole e, in questa parte, le useremo quando è più appropriato. Inoltre, di tanto in tanto possiamo anche usare (omg) le parole *"trasformazione"* e *"trasformazione"*.

I capitoli di questa parte ti guideranno attraverso le caratteristiche di conversione di **Aspose.TeX per C ++**, a partire dai casi d'uso più semplici per i formati target più popolari e terminando con opzioni di messa a punto avanzate. Tenendo conto del fatto che [i file in LaTeX](/tex/{{lang.url-fragment}}net/latex-io/#latex-file) sono più comuni al giorno d'oggi rispetto ai file tex in qualsiasi altro formato, non perderemo il tempo a raccontarti della conversione di quest'ultimo. Invece, ci menzioneremo solo più tardi.

A questo punto, dobbiamo notare che il supporto in LaTeX di Aspose.Tex include tutti i file del sistema di LaTeX di base e i file di un numero di pacchetti più comuni, come *amsmath*, *geometria*, *grafica* e altri. In generale, se si ottiene un errore per quanto riguarda un pacchetto mancante, il tuo caso è un po 'più complicato di quello più semplice. [Qui](/tex/{{lang.url-fragment}}cpp/latex-to-png/#about-input-options) Offriamo un indizio sulla soluzione.
