## Скачать с GitHub

Все примеры Aspose.TeX для Java размещены на GitHub. Вы можете либо клонировать репозиторий, используя свой любимый клиент GitHub, либо загрузить ZIP-файл отсюда.

Извлеките содержимое ZIP-файла в любую папку на вашем компьютере. Все примеры находятся в папке «Примеры». В проекте используется система сборки Maven. Любая современная IDE может легко открыть или импортировать проект и его зависимости. Ниже мы покажем вам, как использовать популярные IDE для создания и запуска примеров.

## IntelliJ IDea

Нажмите меню «Файл» и выберите «Открыть». Перейдите в папку проекта и выберите файл pom.xml.

Он откроет проект и автоматически загрузит зависимости. На вкладке «Проект» просмотрите примеры в папке src/main/java.

Чтобы запустить пример, просто щелкните файл правой кнопкой мыши и выберите «Выполнить..», пример будет выполнен, а выходные данные будут показаны во встроенном окне вывода консоли.

## Eclipce

Нажмите меню «Файл» и выберите «Импорт». Выберите Maven — Существующие проекты Maven. Перейдите к папке, которую вы клонировали или скачали с GitHub, и выберите файл pom.xml.

Он откроет проект и автоматически загрузит зависимости. На вкладке Package Explorer просмотрите примеры в папке src/main/java. Чтобы запустить пример, просто щелкните файл правой кнопкой мыши и выберите «Запустить как — Java-приложение», пример будет выполнен, а выходные данные отобразятся во встроенном окне вывода консоли.

## NetBeans

Нажмите меню «Файл» и выберите «Открыть проект». Перейдите к папке, которую вы клонировали или скачали с GitHub. Значок папки «Примеры» покажет, что это проект Maven. Выберите «Примеры» и откройте его.

Он откроет проект и автоматически загрузит зависимости. На вкладке «Проекты» просмотрите примеры в исходных пакетах. Чтобы запустить пример, просто щелкните файл правой кнопкой мыши и выберите «Выполнить файл», пример будет выполнен, а выходные данные будут показаны во встроенном окне вывода консоли.

## Способствовать

Если вы хотите добавить или улучшить пример, мы рекомендуем вам внести свой вклад в проект. Все примеры и демонстрационные проекты в этом репозитории имеют открытый исходный код и могут свободно использоваться в ваших собственных приложениях.

Чтобы внести свой вклад, вы можете разветвить репозиторий, отредактировать исходный код и создать запрос на включение. Мы рассмотрим изменения и включим их в репозиторий, если они окажутся полезными.
