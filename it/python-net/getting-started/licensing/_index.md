## Valuta Aspose.TeX

Per valutare Aspose.Tex per Python, è possibile scaricare facilmente il prodotto dalla pagina di download [Aspose.TeX per Python](https://pypi.org/project/aspose-tex-net/). La versione di valutazione è la stessa della versione acquistata. Aggiungendo alcune righe di codice per applicare la licenza, la versione di valutazione viene concessa in licenza. Fare riferimento alla pagina di download per l'ultima versione.

### Limitazioni della versione di valutazione

La versione di valutazione di Aspose.Tex fornisce funzionalità complete del prodotto, con l'eccezione che solo le prime quattro pagine possono essere ottenute nel documento di output. Inoltre, queste pagine saranno timbrate con una filigrana della modalità di valutazione.

Se desideri provare Aspose.Tex senza queste limitazioni di valutazione, è possibile [richiedere una licenza temporanea di 30 giorni](https://purchase.aspose.com/temporary-license/) che testerà ogni aspetto di un prodotto prima di acquistarlo.

## Applicazione di una licenza

Dopo aver completato la valutazione di Aspose.TeX per Python e sei soddisfatto delle sue prestazioni, puoi acquistare una licenza tramite il sito Web Aspose presso il [Portale di acquisto](http://www.aspose.com/purchase/default.aspx). Si consiglia di familiarizzare con i diversi tipi di licenza disponibili prima di effettuare un acquisto. Se hai domande o hai bisogno di assistenza, non esitare a [contattare il team di vendita aspirato](http://www.aspose.com/corporate/contact/default.aspx), poiché saranno più che felici di aiutarti.

Ogni licenza aspirante include un abbonamento di un anno che dà diritto a aggiornare gratuitamente qualsiasi nuova versioni o correzioni rilasciate durante quel periodo. Offriamo anche supporto tecnico gratuito e illimitato sia agli utenti autorizzati che alla valutazione.

La licenza per Asposa è un file XML di testo semplice che include informazioni come il nome del prodotto, il numero di sviluppatori autorizzati e la data di scadenza dell'abbonamento. È importante non modificare il file in quanto è firmato digitalmente e persino l'aggiunta di una rottura di linea extra lo invaliderà.

### Quando applicare una licenza

Segui queste linee guida:

- La licenza deve essere impostata solo una volta per dominio dell'applicazione.
- Impostare la licenza prima di utilizzare qualsiasi altra classe Aspose.TeX.
- Chiamare "setLicense" più volte non è dannoso ma spreca il tempo del processore.

### Licenza misurata

Aspose.Tex offre un meccanismo di licenza alternativo chiamato *Misurate Licensing*, che consente ai clienti di essere fatturati in base al loro utilizzo delle funzionalità API. L'applicazione di una *licenza misurata* è semplice come applicare una coppia di chiavi crittografiche. Per ulteriori informazioni, consultare la sezione [FAQ di licenza misurata](https://purchase.aspose.com/faqs/licensing/metered/).
