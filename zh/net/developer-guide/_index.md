## 概述

开发人员指南是有效利用 .NET API 解决方案的 Aspose.TeX 的综合资源。它的主要目的是为用户提供有关核心概念，功能和推荐实践的见解，以与 Aspose.TeX API 解决方案进行 C# .NET。本指南提供了了解 TeX 和 LaTeX 文件格式的转换，阅读，创建以及其他操纵至关重要的实例示例，包括：

- **[转换](/tex/{{lang.url-fragment}}net/conversion/)**  - 是一章，它将告诉您最需要的转换对，TeX 输入和输出等等。
- **[外部 LaTeX 软件包](/tex/{{lang.url-fragment}}net/external-latex-packages/)**  - 是最需要的外部软件包的列表，其中详细介绍了如何将这些软件包提供给图书馆的 TeX 发动机。
