## Богатые возможности

**Поддерживаемые операции**

- Набор текста ввода TeX
- Создание собственного формата TeX

**Поддержка различных форматов выходных файлов**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Поддерживаемые способы чтения ввода и записи вывода**

- Каталог файловой системы
- ZIP-архив
- Основной файл TeX также можно передать через поток.
