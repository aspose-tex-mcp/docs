## Liste des paquets LaTeX intégrés

Les développeurs se demandent souvent quels paquets de macros sont directement intégrés à l'environnement du moteur Aspose.TeX, et lesquels nécessitent une inclusion manuelle. Un certain nombre de paquets LaTeX sont intégrés à la bibliothèque Aspose.TeX. Les voici :


| **Paquet** | **Version** |
| :- | :- |
| `amsmath` | v2.17j 2021/04/20. |
| `colortbl` | v1.0f 2022/06/20. |
| `eurosym` | v1.1 1998/08/06. |
| `geometry` | Version adaptée équivalente à la v5.9 2020/01/02. |
| `graphics` | Version adaptée équivalente à la v1.4d 2021/03/04 (graphicx v1.2c 2020/12/05, color v1.0j 2005/11/14). |
| `hyperref` | Version adaptée équivalente à la v6.83m 2012/11/06. |
| `lipsum` | v2.7 2021/09/20. |
| `multirow` | v2.8 2021/03/15. |
| `pgf` | v3.1.9a 2021/05/15. |
| `pict2e` | Version adaptée équivalente à la v0.4b 2020/09/30. |
| `setspace` | v6.7b 2022/12/04. |
| `url` | v3.4 2013/09/16. |
| `wasysym` | v2.0 30/10/2003. |
| `xcolor` | v2.12 11/05/2016. |

### Ensemble `latex-tools` :

`afterpage`, `array`, `bm`, `calc`, `dcolumn`, `delarray`, `enumerate`, `fileerr`, `fontsmpl`, `ftnright`, `hhline`, `indentfirst`, `layout`, `longtable`, `multicol`, `rawfonts`, `showkeys`, `somedefs`, `tabularx`, `theorem`, `trace`, `varioref`, `verbatim`, `xr` et `xspace`.

**En savoir plus :**

- [Entrées/Sorties TeX (tex-io)](/tex/{{lang.url-fragment}}net/tex-io/) : découvrez comment `IInputWorkingDirectory` et `IOutputWorkingDirectory` gèrent les flux et les ressources sur disque.
- [Qu'est-ce que LaTeX ?](/tex/{{lang.url-fragment}}net/what-is-latex/)
- [Aspose.TeX et Object TeX](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/) : pour comprendre le modèle d'objets gérés sous-jacent.

Les documents professionnels nécessitent inévitablement des fichiers `.sty` ou `.cls` spécialisés, ou fournis par des tiers, qui ne sont pas intégrés par défaut dans le moteur. Aspose prend également en charge l'utilisation de [paquets LaTeX externes](/tex/{{lang.url-fragment}}net/external-latex-packages/).
