## 前提条件

続行する前に、[Aspose.TeX パッケージのインストール]() 後、`[PYTHON_PATH]\Lib\site-packages\` フォルダーに `Aspose.TeX-...` フォルダーが表示されていることを確認してください。Python 3.11 がインストールされている場合は、Aspose.TeX を `[PYTHON_PATH]\site-packages\` フォルダーにインストールできます。この場合、**PyCharm** (バージョン 23.1 以降) はインストール済みパッケージをまさにその場所で探すため、Aspose.TeX フォルダーを `[PYTHON_PATH]\Lib\site-packages\` フォルダーにコピーする必要があります。

## Githubからダウンロードしてください

Python用のAspose.TeXのすべての例は、[github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET)で利用できます。例にアクセスするには2つのオプションがあります。優先Githubクライアントを使用してリポジトリをクローンするか、[こちら](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip)からzipファイルをダウンロードできます。 zipファイルの内容をコンピューター上の任意のフォルダーに抽出します。 `Aspose.TeX.examples`フォルダーにあるすべての例があります。以下に、人気のあるIDEを使用して例を構築および実行する方法を示します。

例のセットアップまたは実行中に問題が発生した場合は、フォーラムを通じてお気軽にお問い合わせください。

## Pycharm

***ファイル*** メニューから ***開く*** を選択します。サンプルプロジェクトフォルダを選択し、***OK*** ボタンをクリックします。プロジェクトが開きます。次に、***実行*** メニューから ***構成の編集*** を選択します。左側のパネルで、新しい Python 構成を追加します。右側のパネルで、構成の名前（例："run_examples"）を設定します。***スクリプトパス*** フィールドに `run_examples.py` への絶対パスを指定し、***作業ディレクトリ*** フィールドにプロジェクトフォルダへの絶対パスを指定します。

例を実行するには、*** run***メニューに移動して[run_examples '***を実行する]を選択するか、キーボードショートカット `shift+f10`を使用します。例は実行され、出力はPycharmのコンソールウィンドウに表示されます。例の実行中に生成された出力ファイルは、「出力」フォルダーに記載されています。

## Microsoft Visual Studio

Visual Studio に **Python 開発** 機能がインストールされていることを確認してください。Visual Studio を開き、「***ローカル フォルダーを開く***」項目の右側をクリックします。次に、Aspose.TeX のサンプル プロジェクト フォルダーを参照します。Visual Studio はこれを Python プロジェクトとして認識し、Python IDE を起動します。フォルダーが開いたら、ソリューション エクスプローラーで「run_examples」を右クリックし、「***スタートアップ項目として設定***」を選択します。

例を実行するには、Visual Studioウィンドウのツールバーに緑色の矢印が付いた*** run_examples.py***ボタンをクリックしてください。

## PythonのAspose.TeXに貢献します

例を追加または改善してプロジェクトに貢献したい場合は、そうすることを強くお勧めします。このリポジトリのすべての例とショーケースプロジェクトはオープンソースであり、アプリケーションで自由に使用できます。

貢献したい場合は、リポジトリをフォークし、ソースコードを変更し、プルリクエストを作成できます。変更を確認し、それらが役立つとみなされる場合は、リポジトリにそれらを含めます。
