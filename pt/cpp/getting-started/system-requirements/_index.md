## Sistemas operacionais

Os sistemas operacionais suportados incluem:

* Microsoft Windows Desktop (7, 8, 10)
* Sistemas operacionais de servidor (2008, 2012), etc.
* Sistemas Linux (Ubuntu-16.04 ou mais tarde)

Aspose.TeX para C ++ também suporta sistemas operacionais de 32 bits.  

Sistemas operacionais que não são suportados:

* Versões antigas do sistema operacional (XP, Vista e servidor 2003)

## Ambientes de desenvolvimento

Você pode usar o Aspose.TeX para C ++ para desenvolver aplicativos em qualquer ambiente de desenvolvimento que suporte C ++, mas os seguintes ambientes são suportados explicitamente:

* Microsoft Visual Studio 2015 ou mais tarde
