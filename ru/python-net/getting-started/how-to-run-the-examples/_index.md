## Предварительные условия

Прежде чем продолжить, убедитесь, что папка `Aspose.TeX-...` появилась в папке `[PYTHON_PATH]\Lib\site-packages\` после установки пакета Aspose.TeX-.... Если у вас установлен Python 3.11, Aspose.TeX можно установить в папку `[PYTHON_PATH]\site-packages\`. В этом случае вам следует скопировать папку Aspose.TeX в папку `[PYTHON_PATH]\Lib\site-packages\`, поскольку **PyCharm** (по крайней мере версия 23.1) ищет установленные пакеты именно в этом месте.

## Скачать с GitHub

Все примеры Aspose.TeX для Python доступны на [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET). У вас есть два варианта доступа к примерам: вы можете клонировать репозиторий с помощью предпочитаемого вами клиента GitHub или загрузить ZIP-файл отсюда [здесь](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip). Извлеките содержимое ZIP-файла в любую папку на вашем компьютере. Вы найдете все примеры, расположенные в папке Aspose.TeX.Examples. Ниже мы покажем, как создавать и запускать примеры с использованием популярных IDE.

Если у вас возникнут какие-либо проблемы при настройке или запуске примеров, свяжитесь с нами через наши форумы.

## PyCharm

Перейдите в меню ***Файл*** и выберите ***Открыть***. Выберите папку примера проекта и нажмите кнопку ***ОК***. Проект будет открыт. Затем перейдите в меню ***Выполнить*** и выберите ***Редактировать конфигурации***. На левой панели добавьте новую конфигурацию Python. На правой панели задайте имя конфигурации (например, «run_examples»). Укажите абсолютный путь к `run_examples.py` в поле ***Путь к скрипту*** и абсолютный путь к папке проекта в поле ***Рабочий каталог***.

Чтобы запустить пример, просто перейдите в меню ***Выполнить*** и выберите ***Выполнить «run_examples»*** или используйте сочетание клавиш `Shift+F10`. Пример будет выполнен, и выходные данные отобразятся в окне консоли PyCharm. Выходные файлы, созданные во время выполнения примеров, можно найти в папке «output».

## Майкрософт Визуал Студия

Убедитесь, что в Visual Studio установлена ​​функция **Разработка на Python**. Откройте Visual Studio и щелкните справа от элемента ***Открыть локальную папку***. Затем перейдите в папку проекта примеров Aspose.TeX. Visual Studio распознает его как проект Python и откроет среду разработки Python. Как только папка откроется, щелкните правой кнопкой мыши «run_examples» в обозревателе решений и выберите ***Установить как элемент запуска***.

Чтобы запустить примеры, просто нажмите кнопку ***run_examples.py*** с зеленой стрелкой на панели инструментов в окне Visual Studio.

## Внесите свой вклад в Aspose.TeX для Python

Если вы хотите внести свой вклад в проект, добавив или улучшив пример, мы настоятельно рекомендуем вам это сделать. Все примеры и демонстрационные проекты в этом репозитории имеют открытый исходный код и могут свободно использоваться в ваших приложениях.

Если вы хотите внести свой вклад, вы можете разветвить репозиторий, внести изменения в исходный код и создать запрос на включение. Мы рассмотрим изменения и включим их в репозиторий, если они будут сочтены полезными.
