## Rich Features

**Supported Operations**

- TeX input typesetting
- Custom TeX format creation
- TeX/LaTeX conversion
- Embedding graphics into LaTeX files
- Drawing figures and complex math equations within LaTeX files
- Latex files validating, structuring, and fixing

**Support for Various Output File Formats**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Supported ways of reading input and writing output**

- File system directory
- ZIP archive
- Main TeX file can also be passed through a stream

{{% alert color="primary" %}}

Unlike traditional command-line TeX utilities, Aspose.TeX for .NET is a 100% managed, standalone library. It does not require a local installation of TeX Live, MiKTeX, or any underlying native executable.
