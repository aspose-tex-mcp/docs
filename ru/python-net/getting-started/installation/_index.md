## Установка Aspose.TeX для Python из PyPi

**PyPI** (Индекс пакетов Python) — это официальный репозиторий пакетов стороннего программного обеспечения в *Python*. Им управляет *Python Software Foundation*, благотворительная организация. Менеджеры пакетов, такие как pip, часто используют **PyPI** в качестве источника по умолчанию для пакетов Python и их зависимостей. **PyPI** в основном содержит пакеты Python в виде архивов, называемых `sdists` (дистрибутивы исходного кода) или предварительно скомпилированных *wheels*.

### Ссылка на Aspose.TeX для Python

Воспользовавшись этим репозиторием, мы включили библиотеку [Aspose.TeX for Python](https://pypi.org/project/aspose-tex-net/) в пакет Wheel и загрузили ее в **PyPI**. Чтобы использовать пакет в своем проекте, вы можете загрузить его с только что упомянутой страницы, а затем установить локально, введя следующую команду в терминале Python.

```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

Или вы можете установить его напрямую из **PyPI**, используя команду ниже.

```
pip install aspose-tex-net
```

Чтобы обновиться до последней версии, используйте ключ `--upgrade`.
