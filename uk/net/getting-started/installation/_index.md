## Встановлення Aspose.TeX для .NET через NuGet

NuGet — це безкоштовна система керування пакетами з відкритим кодом, орієнтована на розробників, для платформи .NET, спрямована на спрощення процесу включення сторонніх бібліотек у програму .NET під час розробки. Це розширення Visual Studio, яке спрощує додавання, видалення та оновлення бібліотек і інструментів у проектах Visual Studio, які використовують .NET Framework. Бібліотекою або інструментом можна легко поділитися з іншими розробниками, створивши пакет NuGet і зберігши його в сховищі NuGet. Коли ви інсталюєте пакет, NuGet копіює файли у ваше рішення та автоматично вносить необхідні зміни, як-от додавання посилань і змінення файлів app.config або web.config. Якщо ви вирішите видалити бібліотеку, NuGet видаляє файли та скасовує будь-які зміни, внесені до вашого проекту, щоб не залишилося безладу.

### Посилання на Aspose.TeX для .NET

Скориставшись перевагами цієї чудової функції, ми об’єднали бібліотеки [Aspose.TeX для .NET](https://www.nuget.org/packages/Aspose.TeX) у пакет NuGet і завантажили його в репозиторій NuGet. За допомогою цього параметра ви отримуєте переваги від використання Aspose.TeX для .NET без встановлення цього компонента у вашій системі. NuGet працює у Visual Studio 2010 і новіших версіях, Visual Web Developer 2010 та Windows Phone Developer Tools 7.1. У наших тестах ми протестували його з Visual Studio 2015 Ultimate.

Щоб почати:

1. Відкрийте своє рішення або проект у Visual Studio.
2. Додайте NuGet Package Manager як розширення Visual Studio:

   1. Виберіть меню **Інструменти**, а потім **Менеджер розширень**.
   2. Виберіть **Онлайн-галерею**, щоб отримати повний список пакетів, доступних онлайн.
   3. Виберіть **Менеджер пакетів NuGet**.
   4. Натисніть **Завантажити**.
   5. Після встановлення диспетчера пакетів перезапустіть Visual Studio, щоб зміни вступили в силу. 
   
      Коли інстальовано диспетчер пакетів NuGet, ви можете знаходити, інсталювати, видаляти та оновлювати пакети у вікні **Керування пакетами NuGet** або за допомогою команд командного рядка PowerShell у спеціальному вікні Visual Studio **Консолі диспетчера пакетів** . Ви можете знайти обидва варіанти, якщо вибрати **Інструменти**, а потім **Менеджер пакетів бібліотеки**.

### Встановіть пакет за допомогою консолі менеджера пакетів

Щоб посилатися на компонент за допомогою консолі менеджера пакетів:

1. Відкрийте програму .NET у Visual Studio.
2. У меню **Інструменти** виберіть **Менеджер пакетів бібліотеки**, а потім **Консоль менеджера пакетів**.
3. Введіть команду «Install-Package Aspose.TeX», щоб інсталювати останній повний випуск, або введіть команду «Install-Package Aspose.TeX -prerelease», щоб інсталювати останній випуск разом із гарячими виправленнями.
4. Натисніть **Enter**.

### Оновіть пакет за допомогою консолі менеджера пакетів

Якщо ви вже посилалися на компонент через NuGet, виконайте такі дії, щоб оновити посилання до останньої версії:

1. Відкрийте програму .NET у Visual Studio.
2. У меню **Інструменти** виберіть **Менеджер пакетів бібліотеки**, а потім **Консоль менеджера пакетів**, щоб відкрити консоль менеджера пакетів.
3. Введіть команду «Update-Package Aspose.TeX», щоб посилатися на останній повний випуск, або введіть команду «Update-Package Aspose.TeX -prerelease», щоб інсталювати останній випуск, включаючи гарячі виправлення.
4. Натисніть **Enter**.

### Встановіть пакет за допомогою графічного інтерфейсу менеджера пакетів

Виконайте такі дії, щоб посилатися на компонент за допомогою графічного інтерфейсу менеджера пакетів:

1. Відкрийте програму .NET у Visual Studio.
2. У меню **Інструменти** виберіть **Менеджер пакетів бібліотеки** та **Керування пакетами NuGet** із параметра **Рішення**. 

   Ви також можете отримати подібну опцію в Solution Explorer:
   1. Клацніть правою кнопкою миші назву проекту.
   2. Виберіть **Керувати пакетами NuGet**.

3. Виберіть **онлайн** у меню ліворуч.
4. Введіть **Aspose.TeX** у поле пошуку, щоб знайти Aspose.TeX для .NET.
5. Натисніть **Встановити/Оновити** біля останньої версії Aspose.TeX для .NET
