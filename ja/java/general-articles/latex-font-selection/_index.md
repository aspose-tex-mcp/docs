LaTeX 組版システムは、ソース文書を処理する際に、使用するフォントについてあまり知識を持ちません。文字の形状を知る必要はなく、文字の位置を計算するだけです。最も重要な情報は、文字の幅、高さ、深さで定義される文字の*ブラックボックス*です。これらの寸法は、フォントごとに TeX フォントメトリック (`.tfm`) ファイルと呼ばれる別の外部ファイルに保存されます。

文字の形状は後で使用されます。LaTeX システムが `.dvi` ファイルを生成する場合、*ドライバ* プログラムは `.dvi` ファイルの文字配置データと `.pk` ファイルまたはアウトライン記述 (PostScript など) からの文字形状情報を組み合わせて、出力媒体上に文字画像を生成します。ただし、**PDF TeX** や **VTEX** などの他の LaTeX システムは、`.dvi` ファイルの生成を省略し、代わりに直接 **PDF** または **PostScript** 出力を生成します。その場合、対応するフォーマッタが最終出力を生成するときに、文字の形状が埋め込まれます。
