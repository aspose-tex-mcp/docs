**Bienvenido a Aspose.TeX para .NET**

Aspose.TeX es una biblioteca .NET para la composición tipográfica de archivos TeX. Puede presentar archivos TeX en varios formatos gráficos como XPS, PDF, PNG, JPEG, TIFF y BMP. También genera información de rastreo como lo hace cualquier otro motor TeX. La API proporciona varias formas de alimentar entradas y obtener resultados. Y, como característica avanzada, le permite crear su propio formato TeX si desea componer una serie de documentos diseñados de manera uniforme.

{{% /alert %}}

## Apoyo técnico

Aspose ofrece soporte técnico gratuito ilimitado para todos sus productos. El soporte está disponible para todos los usuarios, incluida la evaluación.

Si necesita ayuda con Aspose.TeX para .NET, [**visite Aspose.Forums**](https://forum.aspose.com/). Publique su pregunta en el foro Aspose.TeX para .NET y será respondida en unas pocas horas. Las preguntas son respondidas directamente por el equipo de soporte de Aspose.TeX para .NET.

Cuando espere una respuesta en los foros, tenga en cuenta las diferencias de zona horaria.

Si tiene un problema con Aspose.TeX para .NET, siga estos sencillos pasos para asegurarse de que se resuelva de la manera más eficiente:

- Asegúrese de utilizar la última versión de Aspose.TeX para .NET antes de informar el problema. Consulte la [página de descarga de Aspose.TeX para .NET](https://www.nuget.org/packages/Aspose.TeX/) para conocer la última versión.
- Eche un vistazo a los foros, esta documentación, Wiki y la [Referencia de API](https://reference.aspose.com/tex/net/) para encontrar soluciones antes de informar el problema. Es posible que tu pregunta ya tenga respuesta.
- Al informar un problema, incluya el documento original y posiblemente un fragmento del código que causa el problema. Si necesita adjuntar varios archivos, comprímalos en uno. Es seguro adjuntar sus documentos en Aspose.Forums ya que solo usted y los desarrolladores de Aspose tendrán acceso a los archivos adjuntos.
- Intente informar un problema por hilo. Si tienes otro problema, infórmalo en un hilo separado.
