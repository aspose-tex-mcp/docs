## 软件要求

在下载和运行示例之前，请确保您符合以下要求。

1. Visual Studio 2010或更高

## 从Github下载

.NET的所有Aspose.TeX的示例均在[GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET)上托管。

- 您可以使用您喜欢的GitHub客户端克隆存储库，也可以从[此处](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET/archive/master.zip)下载zip文件。
- 将zip文件的内容提取到计算机上的任何文件夹。所有示例都位于**aspose.tex.examples**文件夹中。
- C＃有一个Visual Studio解决方案文件。
- 该项目是在Visual Studio 2019中创建的，但是解决方案文件与Visual Studio 2010 SP1及更高版本兼容。
- 在Visual Studio中打开解决方案文件并构建项目。
- 从[Aspose.TeX for .NET下载页面]下载库(3)。
- 将apose.tex.dll放入**aspose.tex.examples/libs**文件夹中。
- **aspose.tex.examples/Input**包含示例使用的输入文件。有必要下载**输入**文件夹以及示例项目。
- 打开**runexamples.cs**;所有示例都是从这里调用的。
- 取消注册您想从项目中运行的示例。

如果您有任何设置或运行示例的问题，请随时使用我们的论坛联系。
