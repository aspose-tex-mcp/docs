**Bem-vindo ao Aspose.TeX para .NET**

Aspose.TeX é uma biblioteca .NET para arquivos TEX Tipsetting. Ele pode apresentar a entrada Tex em vários formatos gráficos, como XPS, PDF, PNG, JPEG, TIFF e BMP. Ele também gera informações sobre rastreamento como qualquer outro mecanismo Tex. A API fornece várias maneiras de passar a entrada Tex e obter a saída. E, como um recurso avançado, ele permite criar seu próprio formato Tex se desejar compensar vários documentos projetados de maneira uniforme.

**Bem-vindo ao Aspose.TeX para Java**

Aspose.TeX é uma biblioteca Java projetada para gerenciar arquivos TEX. Inclui funcionalidade como renderizar a entrada Tex em uma variedade de formatos gráficos, como XPS, PDF, PNG, JPEG, TIFF e BMP. Além disso, fornece informações de rastreamento semelhantes a outros mecanismos TEX. A solução da API oferece vários métodos para inserir conteúdo Tex e recuperar a saída. Ele também permite criar formatos Tex personalizados para digitar consistentes em vários documentos.
