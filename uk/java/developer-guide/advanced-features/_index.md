Ласкаво просимо до посібника з розширеного проектування для Aspose.TeX для Java. Окрім стандартної компіляції документів, движок Aspose.TeX надає низькорівневі перехоплювачі для абстракції файлової системи, користувацьких пакетів макросів, відстеження потоків пам'яті та оптимізації безголового сервера. У цій частині обговорюються функції Aspose.TeX, створені на основі реалізації Object TeX/LaTeX.

Сторінка документації **Рендеринг фігур LaTeX** в Aspose.TeX для Java пояснює, як витягувати та візуалізувати ізольовані фрагменти LaTeX (такі як малюнки, графіки або структурні схеми) як окремі зображення, повністю незалежні від макета сторінки всього документа. API містить цю функцію як структурне узагальнення движка рендерингу математичних формул.

Сторінка **Впровадження графіки LaTeX** пояснює, як імпортувати та впроваджувати зовнішні графічні ресурси (такі як діаграми, схеми або фотографії) у документ TeX під час компіляції за допомогою API Aspose.TeX для Java.

На сторінці виділено два способи обробки цього через інтерфейс `IInputWorkingDirectory`:

- Підхід на основі файлової системи: використання `PhysicalFileSystemInputWorkingDirectory` для вказівки движку на фізичний каталог на локальному диску, де знаходяться зображення.

- Підхід на основі потоків/пам'яті: реалізація користувацького постачальника потоків для отримання зображень безпосередньо з пам'яті, хмарного сховища або баз даних з використанням імені файлу як ключа пошуку.

Сторінка **Рендеринг математичних формул LaTeX** пояснює, як візуалізувати ізольовані математичні формули LaTeX у вигляді окремої графіки (PNG або SVG), повністю незалежної від повного документа, що ідеально підходить для впровадження формул у веб-додатки, інтерфейси настільних ПК або сховища баз даних.

Сторінка **Відновлення файлів LaTeX** представляє функцію `LaTeXRepairer`, яка програмно перевіряє, структурує та виправляє пошкоджені або неповні текстові файли, у яких відсутні обов'язкові компоненти LaTeX. Це дозволяє успішно компілювати пошкоджені або погано структуровані файли TeX без ручного втручання.
