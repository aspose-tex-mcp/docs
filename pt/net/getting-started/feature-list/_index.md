## Características ricas

**Operações suportadas**

- Composição de entrada TeX
- Criação de formato TeX personalizada
- Conversão TeX/LaTeX
- Incorporação de gráficos em arquivos LaTeX
- Desenho de figuras e equações matemáticas complexas dentro de arquivos LaTeX
- Validação, estruturação e correção de arquivos LaTeX

**Suporte para vários formatos de arquivo de saída**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Formas suportadas de ler a entrada e gravar a saída**

- Diretório do sistema de arquivos
- Arquivo ZIP
- O arquivo TeX principal também pode ser passado através de um fluxo

{{% alert color="primary" %}}

Ao contrário dos utilitários TeX de linha de comando tradicionais, o Aspose.TeX para .NET é uma biblioteca independente 100% gerenciada. Não requer uma instalação local do TeX Live, MiKTeX ou qualquer executável nativo subjacente.
