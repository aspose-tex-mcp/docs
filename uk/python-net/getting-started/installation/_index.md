## Встановлення Aspose.TeX для Python з PyPi

**PyPI** (Python Package Index) є офіційним репозиторієм програмних пакетів сторонніх розробників на *Python*. Ним керує *Python Software Foundation*, яка є благодійною організацією. Менеджери пакетів, такі як `pip`, часто використовують **PyPI** як джерело за умовчанням для пакетів Python та їхніх залежностей. **PyPI** здебільшого розміщує пакети Python у формі архівів, які називаються `sdists` (дистрибутиви вихідного коду) або попередньо скомпільовані *wheels*.

### Посилання на Aspose.TeX для Python

Використовуючи переваги цього репозиторію, ми об’єднали бібліотеку [Aspose.TeX для Python](https://pypi.org/project/aspose-tex-net/) у пакет Wheel і завантажили її до **PyPI**. Щоб посилатися на пакет у вашому проекті, ви можете завантажити його з щойно згаданої сторінки, а потім інсталювати локально, ввівши наступну команду в терміналі Python.


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

Або ви можете встановити його безпосередньо з **PyPI** за допомогою наведеної нижче команди.


```
pip install aspose-tex-net
```

Щоб оновити до останньої версії, використовуйте ключ `--upgrade`.
