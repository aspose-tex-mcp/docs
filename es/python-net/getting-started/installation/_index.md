## Instalación de Aspose.TeX para Python desde PyPi

**PyPI** (Índice de paquetes de Python) es el repositorio oficial de paquetes de software de terceros en *Python*. Está gestionado por la *Python Software Foundation*, que es una organización benéfica. Los administradores de paquetes como `pip` a menudo usan **PyPI** como fuente predeterminada para los paquetes de Python y sus dependencias. **PyPI** aloja principalmente paquetes de Python en forma de archivos llamados `sdists` (distribuciones de origen) o *ruedas* precompiladas.

### Haciendo referencia a Aspose.TeX para Python

Aprovechando este repositorio, hemos incluido la biblioteca [Aspose.TeX para Python](https://pypi.org/project/aspose-tex-net/) en un paquete Wheel y lo hemos subido a **PyPI**. Para hacer referencia al paquete en su proyecto, puede descargarlo desde la página que acabamos de mencionar y luego instalarlo localmente escribiendo el siguiente comando en su terminal Python.


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

O puede instalarlo directamente desde **PyPI** usando el siguiente comando.


```
pip install aspose-tex-net
```

Para actualizar a la última versión, use la tecla `--upgrade`.
