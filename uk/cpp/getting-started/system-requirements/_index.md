## Операційні системи

Серед підтримуваних операційних систем:

* Робочий стіл Microsoft Windows (7, 8, 10)
* Серверні операційні системи (2008, 2012) та ін.
* Системи Linux (Ubuntu-16.04 або новішої версії)



Aspose.TeX для C++ також підтримує 32-розрядні операційні системи.  

Операційні системи, які не підтримуються:

* Старі версії ОС (XP, Vista і Server 2003)

## Середовища розробки

Ви можете використовувати Aspose.TeX для C++ для розробки програм у будь-якому середовищі розробки, яке підтримує C++, але явно підтримуються такі середовища:

* Microsoft Visual Studio 2015 або новішої версії
