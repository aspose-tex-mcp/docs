## 乳胶上标和下标介绍

**上标**是一个小字符或符号，位于文本的基线上方。  例如，在“x²”表达式中，`2`是一个上标。

**下标**是一个小字符或符号，位于文本的基线下方。例如，在水的化学公式“h₂o”中，“ 2”是下标。

## 如何在乳胶中写下下标/上标

现在让我们尝试从简单的公式构建更复杂的公式。首先，你可以使用 `^` 和 `_` 获取上标和下标，如下例所示：

![单字符下标和上标](/tex/images/java/tutorial/latex-math-2-1.png)

请注意，`^` 和 `_` 仅适用于下一个字符。如果您想要更复杂的下标或上标，只需将其括在括号中即可：

![多字符下标和上标](/tex/images/java/tutorial/latex-math-2-2.png)

这些示例中的牙套指定了“ subformulas”  - 较大公式的简单部分。 Tex为每个子形式制作一个盒子，并将该盒子对待，就好像它是一个符号一样。牙套还达到了他们通常的分组目的。

输入 `$x^y^z$` 或 `$x_y_z$` 是非法的。TeX 会报错“双下标”或“双上标”。您必须通过输入 `$x^{y^z}$`、`$x^{yz}$`、`$x_{y_z}$` 或 `$x_{yz}$` 来更清楚地表达您的意图。

角色之后的上标或下标仅适用于该字符；但是，在遵循子形式时，它适用于整个子形式，并将相应地提出或降低。

![单个符号和子形式上的下标和上标](/tex/images/java/tutorial/latex-math-2-3.png)

在第一个公式中，`^3`和`^4`是紧接它们之前的右括号上的上标，但是在第二个公式中，它们是括号中包围的子形式上的上标。第一个版本是可取的，因为它易于键入，并且易于阅读。

## 在空的子图上写下下标或上标

有时，您可能需要在空的子公式上添加下标或上标，以生成一些较为少见的符号，例如 *<sub>2</sub>F<sub>3</sub>*。最好的方法是输入 `${}_2F_3$` 或 `${_2}F_3$` 或 `${_2F_3}$`。

您也可以同时拥有“ subuperscripts”，并且可以按任何顺序指定：

![同时次数](/tex/images/java/tutorial/latex-math-2-4.png)

这些同时的“ subuperscripts”相互定位。但是，对于某些字母，下标将转移到左边。对于其中一些字母而言，很明显。比较以下两个公式：

![同时次数对齐](/tex/images/java/tutorial/latex-math-2-5.png)

因此，如果您要对准下标和上标，则可以使用第二版中显示的技巧。再次，它利用一个空的子形式。

## 在乳胶上写Prime

数学公式中经常出现的下一个符号是素数符号。LaTeX 提供了 `\prime` 命令，它本身会生成一个与普通字母大小相同的素数符号。所以，除了上标或下标之外，你通常不会用到它。不过，你可以简单地输入 `'` 代替 `^\prime`，用 `''` 代替 `^\prime\prime`，等等。

![素数](/tex/images/java/tutorial/latex-math-2-6.png)

## 双上标乳胶

在乳胶中，您可以通过将整个Superscript表达式包装在卷曲括号{}中来编写双上文。这是一个示例：`x^{a^b}`

## 双下标乳胶

在乳胶中，您可以通过将整个下标表达式包含在卷曲括号{}中的整个下标表达式来类似地编写。这是一个示例：`x_ {i_ {j}}`
