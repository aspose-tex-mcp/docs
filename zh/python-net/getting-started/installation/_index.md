## 从PYPI安装python的Aspose.TeX

**PYPI**(Python软件包索引)是*Python*中第三方软件包的官方存储库。它由 *Python Software Foundation *管理，该组织是一个慈善组织。像“ PIP”这样的软件包经理经常使用**PYPI**作为Python软件包及其依赖项的默认来源。 **PYPI**主要托管Python软件包的形式，称为“ SDISTS”(源分布)或预编译*Wheels*。

### 引用Aspose.TeX for Python

利用此存储库，我们将[Aspose.TeX for Python](https://pypi.org/project/aspose-tex-net/)捆绑到了轮套中，并将其上传到**PYPI**。要在项目中引用软件包，您可以从恰好提到的页面下载它，然后在本地通过在Python终端中键入以下命令来将其下载。


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

或者，您可以使用命令波纹管从**PYPI**进行直接安装。


```
pip install aspose-tex-net
```

要升级到最新版本，请使用`` -  upgrade``键。
