## Sistemas operativos

Los sistemas operativos compatibles incluyen:

* Escritorio de Microsoft Windows (7, 8, 10)
* Sistemas operativos de servidor (2008, 2012), etc.
* Sistemas Linux (Ubuntu-16.04 o posterior)

Aspose.TeX para C++ también admite sistemas operativos de 32 bits.  

Sistemas operativos que no son compatibles:

* Versiones antiguas de SO (XP, Vista y Server 2003)

## Entornos de desarrollo

Puede utilizar Aspose.TeX para C++ para desarrollar aplicaciones en cualquier entorno de desarrollo que admita C++, pero los siguientes entornos son explícitamente compatibles:

* Microsoft Visual Studio 2015 o posterior
