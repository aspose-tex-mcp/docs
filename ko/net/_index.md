p1: "TeX는 프로그래밍 언어이며 데이터 마크업 언어라고 합니다. 동시에 TeX는 이 언어와 조판 시스템을 전체적으로 이해하는 인터프리터 엔진입니다."
p2: 수학적 또는 기술적인 텍스트 작성에 사용됩니다. ΤeΧ를 기반으로 많은 다른 패킷이 생성되었습니다. 가장 유명한 패키지는 LaTeX입니다. 이를 통해 작성자는 텍스트에 집중하고 타이포그래피 프로세스는 프로그램에 맡길 수 있습니다. LaTeX를 사용하면 구조화된 문서를 쉽게 만들고 관리할 수 있습니다.
p3: Aspose.TeX for .NET은 TeX 및 LaTeX 파일을 조판하는 유연하고 사용하기 쉬운 라이브러리입니다. API는 XPS, PDF, PNG, JPEG, TIFF, SVG 및 BMP와 같은 여러 출력 형식을 지원합니다. 즉, 이 라이브러리의 기능을 사용하면 TeX 및 LaTeX 파일을 모든 출력 형식으로 변환할 수 있습니다. 이 솔루션을 사용하면 균일하게 디자인된 여러 문서를 생성 및/또는 조판하려는 경우 사용자 정의 TeX 형식을 생성할 수 있습니다.
