## Обзор

Инструмент [Aspose.TeX Convert](https://www.nuget.org/packages/Aspose.TeX.Convert) — это мощное приложение CLI, которое облегчает преобразование документов TeX и LaTeX в различные форматы. Этот инструмент позволяет разработчикам и дизайнерам создавать документы, которые без проблем работают на разных платформах и устройствах.

## Ключевые особенности

- **Поддерживаемые форматы ввода**: TeX, LaTeX.
- **Поддерживаемые форматы вывода**: PDF, XPS, PNG, JPEG, BMP, TIFF, SVG.
- **Гибкое использование**: можно использовать как с помощью простых команд командной строки, так и программно в коде C#, совместимом с .NET 6.0/7.0.

## Преимущества

Использование инструмента Aspose.TeX Convert дает несколько преимуществ:

- **Эффективность**: быстро конвертируйте документы TeX/LaTeX в различные форматы без необходимости использования сложного программного обеспечения.
- **Автоматизация**: интегрируйте преобразование документов в свои автоматизированные рабочие процессы и сценарии.
- **Гибкость**: работа с документами различных форматов для обеспечения совместимости с различными системами и приложениями.

## Лицензирование

Хотя само приложение Aspose.TeX Convert можно использовать бесплатно, для преобразования документов требуется действующая [лицензия] Aspose.TeX(2). Вы можете приобрести лицензию или использовать Aspose.TeX в пробном режиме в ознакомительных целях.

## Как установить конвертер командной строки TeX?

Инструмент Aspose.TeX Convert можно установить глобально или локально, в зависимости от потребностей вашего проекта. Рекомендуется использовать локальную установку для конкретного проекта, чтобы избежать конфликтов версий.

### Глобальная установка

Чтобы установить Aspose.TeX Convert глобально на ваш компьютер, используйте следующую команду:


```bash
dotnet tool install --global Aspose.TeX.Convert
```

Укажите опцию `--version`, если вам нужна конкретная версия инструмента.

### Локальная установка

Для локальной установки в конкретном проекте сначала перейдите в корневой каталог вашего проекта. Затем выполните следующие команды:

1. Создайте манифест инструмента, если он еще не создан:

   ``` баш
   новый манифест инструмента dotnet
   ```

2. Установите Aspose.TeX Convert локально:

   ``` баш
   установка инструмента dotnet Aspose.TeX.Convert --local
   ```


Опять же, вы можете указать опцию --version для конкретной версии.

### Обновление конвертера TeX CLI

Чтобы обновить инструмент Aspose.TeX Convert до последней версии, используйте команду dotnettool update с параметром --global или --local, в зависимости от вашего типа установки.

### Удаление конвертера TeX CLI

Если вам нужно удалить инструмент, используйте команду dotnettool uninstall с параметром --global или --local, в зависимости от того, как был установлен инструмент.

## Использование

### Командная строка

Преобразуйте документы, используя аргументы командной строки. Вот доступные параметры:

- `-i, --input [Обязательно]`: Путь к входному документу TeX или LaTeX.
  - Пример: `--input input.tex`
- `-o, --output [Обязательно]`: Путь к преобразованному документу.
  - Пример: `--output output.pdf`
- `-f, --format [Необязательно]`: формат выходного документа.
  - Поддерживаемые форматы: PDF, XPS, PNG, JPEG, BMP, TIFF, SVG.
  - Пример: `--format pdf`
- `-l, --license [Необязательно]`: Путь к файлу лицензии Aspose.TeX .NET.
  - Пример: `--license path_to_license.lic`
- `-v, --verbose [Необязательно]`: включить подробный вывод.
  - Пример: `--verbose`


Пример использования командной строки:


```bash
Aspose.TeX.Convert --input input.tex --output output.pdf --format pdf
```

### Как интегрировать CLI LaTeX Converter в проекты C#?

Приложение Aspose.TeX Convert также можно интегрировать непосредственно в ваши проекты .NET с помощью командной строки, обеспечивая программный доступ к возможностям преобразования TeX в вашем коде C#.

**Добавление конвертера командной строки LaTeX в ваш проект:**

Чтобы добавить инструмент преобразования Aspose.TeX в проект Visual Studio, перейдите в корневой каталог вашего проекта и выполните следующую команду:


```bash
dotnet Aspose.TeX.Convert add
```

Эта команда добавляет функциональность Aspose.TeX Convert непосредственно в ваш проект, позволяя вам использовать методы и свойства библиотеки в вашем коде. Это особенно полезно для разработчиков, желающих реализовать настраиваемые процессы преобразования TeX непосредственно в своих приложениях.

### Использование из кода

Вот пример программного использования инструментов CLI Aspose.TeX в вашем коде C#:


```csharp
using Aspose.TeX.MicroApps.Convert;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // Initialize convert options
        var options = new ConvertOptions
        {
            // Required: Specify the input document path
            InputDocument = "input.tex",
            
            // Required: Specify the output document path
            OutputFilePath = "output.pdf",
            
            // Optional: Specify the output format
            ToFormat = "pdf"
        };

        // Conditional: Apply license if you have one
        if (isLicensed)
        {
            options.LicenseFile = "path_to_license.lic";
        }

        // Execute the conversion task
        await ConvertTasks.Create(options).Execute();
    }
}
```
