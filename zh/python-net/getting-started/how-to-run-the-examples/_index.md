## 先决条件

在继续操作之前，请确保在 Aspose.TeX 软件包安装 之后，`Aspose.TeX-...` 文件夹出现在 `[PYTHON_PATH]\Lib\site-packages\` 文件夹中。如果您已安装 Python 3.11，则可以将 Aspose.TeX 安装在 `[PYTHON_PATH]\site-packages\` 文件夹中。在这种情况下，您应该将 Aspose.TeX 文件夹复制到 `[PYTHON_PATH]\Lib\site-packages\` 文件夹，因为 **PyCharm**（至少 23.1 版本）会在该位置查找已安装的软件包。

## 从Github下载

python的Aspose.TeX的所有示例都在[Github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET)上获得。您有两个选项可以访问示例：您可以使用首选的GitHub客户端克隆存储库，也可以从[此处](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip)下载zip文件。将zip文件的内容提取到计算机上的任何文件夹。您会在`aspose.tex.examples'文件夹中找到所有示例。下面，我们将演示如何使用流行的IDE构建和运行示例。

如果在设置或运行示例时遇到任何问题，请随时通过我们的论坛与我们联系。

## Pycharm

前往***文件***菜单并选择***打开***。选择示例项目文件夹，然后点击***确定***按钮。项目将会打开。然后，前往***运行***菜单并选择***编辑配置***。在左侧面板中，添加一个新的 Python 配置。在右侧面板中，设置配置的名称（例如“run_examples”）。在***脚本路径***字段中指定 `run_examples.py` 的绝对路径，并在***工作目录***字段中指定项目文件夹的绝对路径。

要运行示例，只需转到“运行”菜单并选择“运行‘run_examples’”，或使用键盘快捷键“Shift+F10”。示例将被执行，输出将显示在 PyCharm 的控制台窗口中。示例执行过程中生成的输出文件位于“output”文件夹中。

## Microsoft Visual Studio

确保 Visual Studio 中已安装 **Python 开发** 功能。打开 Visual Studio，点击右侧的 ***打开本地文件夹*** 选项。然后，浏览到 Aspose.TeX 示例项目文件夹。Visual Studio 会将其识别为 Python 项目并打开 Python IDE。打开文件夹后，在解决方案资源管理器中右键单击“run_examples”，然后选择 ***设置为启动项***。

要运行示例，只需点击 Visual Studio 窗口工具栏中带有绿色箭头的 ***run_examples.py*** 按钮即可。
