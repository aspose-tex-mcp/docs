**Добро пожаловать в Aspose.TeX для Java**

Aspose.TeX — это Java-библиотека для верстки файлов TeX. Он может представлять входные данные TeX в различных графических форматах, таких как XPS, PDF, PNG, JPEG, TIFF и BMP. Он также выводит информацию трассировки, как и любой другой движок TeX. API предоставляет различные способы передачи входных данных TeX и получения выходных данных. И, в качестве расширенной функции, он позволяет вам создать свой собственный формат TeX, если вы хотите набрать несколько документов, оформленных единообразно.
