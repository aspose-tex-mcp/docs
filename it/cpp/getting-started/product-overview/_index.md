**Benvenuti in Aspose.TeX per C ++**

Aspose.Tex è una libreria C ++ per la composizione dei file tex. Può presentare file TEX in vari formati grafici come XPS, PDF, PNG, JPEG, TIFF e BMP. Output anche le informazioni di tracciamento come fa qualsiasi altro motore Tex. L'API fornisce vari modi per alimentare l'input e l'output. E, come caratteristica avanzata, ti consente di creare il tuo formato tex se si desidera scrivere una serie di documenti progettati in modo uniforme.

{{% /alert %}}

## Supporto tecnico

Aspone fornisce supporto tecnico gratuito illimitato per tutti i suoi prodotti. Il supporto è disponibile per tutti gli utenti, inclusa la valutazione.

Se hai bisogno di aiuto con Aspose.Tex per C ++, [**Visita l'Aspose.Forums**](https://forum.aspose.com/). Pubblica la tua domanda in Aspose.Tex per il forum C ++ e verrà data risposta entro poche ore. Le domande vengono risposte direttamente da Aspose.Tex per il team di supporto C ++.

Quando si aspetta una risposta nei forum, si prega di consentire le differenze di fuso orario.

Se hai un problema con Aspose.Tex per C ++, segui questi semplici passaggi per assicurarti che sia risolto nel modo più efficiente:

- Assicurati di utilizzare l'ultima versione Aspose.TeX per C ++ prima di segnalare il problema. Fare riferimento alla pagina di download [Aspose.Tex per C ++](https://www.nuget.org/packages/Aspose.TeX.Cpp/) per scoprire l'ultima versione.
- Dai un'occhiata ai forum, questa documentazione, wiki e [riferimento API](https://reference.aspose.com/tex/cpp/) per le soluzioni prima di segnalare il problema. La tua domanda potrebbe già avere una risposta.
- Quando si segna un problema, si prega di includere il documento originale e possibilmente un frammento del codice che causa il problema. Se è necessario allegare più file, comprimerli in uno. È sicuro allegare i tuoi documenti in Aspose.Forums poiché solo tu e gli sviluppatori aspirano avranno accesso ai file allegati.
- Prova a segnalare un problema per thread. Se hai un altro problema, segnalalo in un thread separato.
