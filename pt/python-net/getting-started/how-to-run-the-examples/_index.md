## Pré -requisitos

Antes de prosseguir, verifique se a pasta `asposit.tex -...`aparece na pasta `[python_path] \lib \site-packages \`após a instalação do pacote Aspose.TeX. Se você tiver o Python 3.11 instalado, Aspose.TeX pode ser instalado na pasta `[python_path] \site-packages \`. Nesse caso, você deve copiar a pasta Aspose.TeX para a pasta `[python_path] \lib \site-packages \`, como **PyCharm** (pelo menos a versão 23.1) procura pacotes instalados exatamente nesse local.

## Download do github

Todos os exemplos de Aspose.TeX for python estão disponíveis no [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET). Você tem duas opções para acessar os exemplos: você pode clonar o repositório usando seu cliente Github preferido ou baixar o arquivo zip de [aqui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip). Extraia o conteúdo do arquivo zip para qualquer pasta do seu computador. Você encontrará todos os exemplos localizados na pasta `Aspose.TeX.examples`. Abaixo, demonstraremos como construir e executar os exemplos usando IDEs populares.

Se você encontrar algum problema ao configurar ou executar os exemplos, sinta -se à vontade para nos alcançar através de nossos fóruns.

## Pycharm

Vá para o menu ****** e escolha ***Abra***. Selecione a pasta do projeto de exemplo e clique no botão ***OK***. O projeto será aberto. Em seguida, vá para o menu ***Run*** e escolha ***Editar configurações***. No painel esquerdo, adicione uma nova configuração do Python. No painel direito, defina o nome da configuração (por exemplo, "run_examples"). Especifique o caminho absoluto para `run_examples.py` no campo de script ****** e o caminho absoluto para a pasta do projeto no campo ***do diretório de trabalho***.

Para executar um exemplo, basta acessar o menu ***run*** e escolher ***run 'run_examples'*** ou use o atalho do teclado `shift+f10`. O exemplo será executado e a saída será exibida na janela do console do Pycharm. Os arquivos de saída gerados durante a execução de exemplos podem ser encontrados na pasta `output`.

## Microsoft Visual Studio

Certifique -se de que o recurso **Python Development** esteja instalado no Visual Studio. Abra o Visual Studio e clique no lado direito do ***Abra um item de*** da pasta local. Em seguida, navegue para a pasta do projeto Aspose.TeX Exemplos. O Visual Studio o reconhecerá como um projeto Python e abrirá o Python IDE. Depois que a pasta for aberta, clique com o botão direito do mouse em "run_examples" no explorador de soluções e selecione ***definido como item de inicialização***

Para executar exemplos, basta clicar no botão ***run_examples.py*** com a seta verde na barra de ferramentas na janela do Visual Studio.
