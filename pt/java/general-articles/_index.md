Os artigos desta secção abordam conceitos fundamentais, fluxos de trabalho e manipulação avançada da linguagem de composição tipográfica LaTeX. Ao contrário dos ambientes TeX tradicionais de linha de comandos, o Aspose.TeX fornece um mecanismo isolado e com utilização eficiente de memória que processa a sintaxe LaTeX nativamente.

Seja para gerir modelos de documentos ou renderizar equações matemáticas independentes, estes guias fornecem o contexto arquitetónico necessário para aproveitar todo o poder da API. Aqui aprenderá como:

- As diferenças fundamentais entre os formatos TeX, a anatomia dos ambientes macro e a forma como os modelos de documentos se comportam em sistemas sem interface gráfico.

- Trabalhar com modos matemáticos ($ ... $ e $$...$$), configurar preâmbulos personalizados para notação avançada e lidar com o alinhamento vertical da linha de base durante a exportação de imagens.

- Incorporar imagens raster/vetoriais externas, gerir o pipeline `package` e isolar figuras dinâmicas.
