p1: "O TeX é conhecido como uma das linguagens de marcação de dados. É o núcleo principal do sistema de conjunto de publicações (composição de computador). É questionável considerar o [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) como um formato de arquivo, porque é uma linguagem de programação. E, por outro lado, é um mecanismo interpretador que entende essa linguagem. Enfim, em suma, seu principal objetivo é ajudar na criação de textos matemáticos ou técnicos. Mas quando o arquivo já está criado e você não deseja mais nenhuma manipulação, você pode querer convertê-lo para um formato diferente e mais popular."
p2: "A solução de API Aspose.TeX entre os diferentes outros recursos permite a conversão de arquivos TeX e, em seguida, salvar o resultado como um arquivo ZIP. Aqui você encontrará um trecho de código sobre como converter TeX para PDF e salvar a saída do resultado em zip. O conversor de API transforma o TeX usando qualquer linguagem suportada pelo C#. A API que você vê aqui também pode ser usada para criar seu próprio aplicativo multiplataforma ou ser integrada ao seu projeto .NET. Esses [*conversores de plataforma cruzada*](https://products.aspose.app/tex/conversion/tex) também estão presentes no ecossistema Aspose. Mas para executar os exemplos, precisamos:"
p3: "Aspose.TeX for .NET API, que é uma API de conversão e manipulação de documentos rica em recursos, poderosa e fácil de usar para a plataforma C#."
p4: "Abra o gerenciador de pacotes NuGet, procure por Aspose.TeX e instale. Você também pode usar o seguinte comando do Console do Gerenciador de Pacotes."

title: Etapas para usar diretórios ZIP para o arquivo TeX de saída C#.
h3: "Código C# para usar diretórios ZIP para saída"
item1: "Crie a instância da [*TeXOptions Class*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/)."
item2: "Especifique um diretório de trabalho do arquivo ZIP para a saída usando a propriedade [*OutputWorkingDirectory*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/outputworkingdirectory/)."
item3: "Especifique o console como o terminal de saída usando a classe [*OutputConsoleTerminal*](https://reference.aspose.com/tex/net/aspose.tex.io/outputconsoleterminal/)."
item4: "Defina as opções para salvar usando a classe [*PdfSaveOptions*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfsaveoptions/)."
item5: "Execute a conversão usando o método [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) para [*PdfDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfdevice/)"
item6: Refine a saída.
item7: "Para finalizar o arquivo ZIP de saída, use a classe [*OutputZipDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputzipdirectory/)."
