**Ласкаво просимо до Aspose.TeX для C++**

Aspose.TeX — це бібліотека C++ для набору файлів TeX. Він може представляти вхідні дані TeX у різних графічних форматах, таких як XPS, PDF, PNG, JPEG, TIFF і BMP. Він також виводить інформацію про трасування, як і будь-який інший двигун TeX. API надає різні способи передачі вхідних даних TeX і отримання вихідних даних. І, як розширена функція, це дозволяє створити власний формат TeX, якщо ви бажаєте набрати кілька документів, оформлених однаково.
