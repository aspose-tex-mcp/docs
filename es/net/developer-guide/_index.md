## Descripción general

La Guía para desarrolladores sirve como un recurso integral para utilizar eficazmente la solución API Aspose.TeX para .NET. Su objetivo principal es proporcionar a los usuarios información sobre los conceptos básicos, las funcionalidades y las prácticas recomendadas para interactuar con la solución API Aspose.TeX para C# .NET. Esta guía ofrece ejemplos prácticos esenciales para comprender la conversión, lectura, creación y otras manipulaciones de formatos de archivos TeX y LaTeX, que incluyen:

- **[Conversión](/tex/{{lang.url-fragment}}net/conversion/)** - es un capítulo que le informará sobre los pares de conversión más necesarios, entrada y salida TeX, y mucho más.
- **[Paquetes LaTeX externos](/tex/{{lang.url-fragment}}net/external-latex-packages/)** - es una lista de los paquetes externos más necesarios con detalles sobre cómo proporcionar estos paquetes al motor TeX de la biblioteca.
