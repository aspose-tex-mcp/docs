## Requisitos de software

Certifique -se de atender aos seguintes requisitos antes de baixar e executar os exemplos.

1. Visual Studio 2010 ou superior

## Download do github

Todos os exemplos de Aspose.TeX para .NET são hospedados no [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET).

- Você pode clonar o repositório usando seu cliente Github favorito ou baixar o arquivo zip de [aqui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET/archive/master.zip).
- Extraia o conteúdo do arquivo zip para qualquer pasta do seu computador. Todos os exemplos estão localizados na pasta **aspose.tex.example**.
- Há um arquivo de solução do Visual Studio para C#.
- O projeto é criado no Visual Studio 2019, mas o arquivo de solução é compatível com o Visual Studio 2010 SP1 e superior.
- Abra o arquivo de solução no Visual Studio e crie o projeto.
- Faça o download da biblioteca de [Aspose.TeX para .NET Download Page](https://releases.aspose.com/tex/net).
- Coloque a pasta APOSE.TEX.DLL em **Aspose.TeX.examples/libs**.
- **Aspose.TeX.examples/input** contém arquivos de entrada que os exemplos usam. É necessário baixar a pasta **de entrada** junto com o projeto Exemplos.
- Aberto **runExamples.cs**; Todos os exemplos são chamados daqui.
- Descubra os exemplos que você deseja executar dentro do projeto.

Sinta -se à vontade para entrar em contato com nossos fóruns se tiver algum problema de configurar ou executar os exemplos.
