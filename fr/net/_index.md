**Bienvenue sur Aspose.TeX pour .NET**

Aspose.TeX est une bibliothèque .NET pour la composition de fichiers TeX. Il peut présenter l'entrée TeX dans divers formats graphiques tels que XPS, PDF, PNG, JPEG, TIFF et BMP. Il génère également des informations de traçage comme n’importe quel autre moteur TeX. L'API propose différentes manières de transmettre les entrées TeX et d'obtenir la sortie. Et, en tant que fonctionnalité avancée, il vous permet de créer votre propre format TeX si vous souhaitez composer un certain nombre de documents conçus de manière uniforme.
