## Instalando Aspose.TeX para C ++

### Instalação manual

Você pode baixar [Aspose.TeX para C ++](https://www.nuget.org/packages/Aspose.TeX.Cpp) da Nuget Gallery, clicando no link "Download Package" na seção de informações. A documentação da API offline também pode ser encontrada no pacote ZIP baixado.

Execute as seguintes etapas para usar aspose.tex para C ++ em seus aplicativos:

1. [Download](https://www.nuget.org/packages/Aspose.TeX.Cpp) Os arquivos mais recentes.
2. Descompactar a pasta para o ambiente de produção.
3. Para usar aspose.tex para C ++, referência incluir e pastas Lib em seu projeto.

### Usando o Nuget Package Manager

Para fazer referência ao componente usando o console do gerenciador de pacotes:

1. No Nuget Package Manager, pesquise asppose.tex
2. Selecione o pacote Aspose.TeX.cpp nos resultados de pesquisa
3. Selecione os projetos necessitados na lista de projetos de soluções e pressione **Instale o botão** para instalar o pacote
