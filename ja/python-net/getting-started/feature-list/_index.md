## 豊富な機能

**サポートされている操作**

- TEX入力タイプセット
- カスタムTEX形式の作成
- ラテックスで数値をレンダリングします
- 数式と方程式をレンダリングします
- サブセットフォント
- 数式とグラフィックスフリーズ

**さまざまな出力ファイル形式のサポート**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**入力と書き込みの出力を読む方法をサポートしています**

- ファイルシステムディレクトリ
- zipアーカイブ
- メインのTexファイルはストリームに渡すこともできます
