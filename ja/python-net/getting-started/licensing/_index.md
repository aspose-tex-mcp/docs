## Aspose.TeXを評価します

Aspose.TeX for Python を評価するには、[Aspose.TeX for Python ダウンロードページ](https://pypi.org/project/aspose-tex-net/) から簡単にダウンロードできます。評価版は製品版と同じです。ライセンスを適用するためのコードを数行追加するだけで、評価版がライセンス付きになります。最新版については、ダウンロードページをご覧ください。

### 評価バージョンの制限

Aspose.TeXの評価バージョンは、最初の4ページのみが出力ドキュメントで取得できることを除いて、完全な製品機能を提供します。さらに、これらのページには、評価モードの透かしが刻印されます。

これらの評価制限なしでAspose.TeXを試してみたい場合は、[30日間の一時ライセンスを要求](https://purchase.aspose.com/temporary-license/)購入する前に製品のあらゆる側面をテストすることができます。

## ライセンスの適用

Python用のAspose.TeXの評価を完了し、そのパフォーマンスに満足した後、[Purchase Portal](http://www.aspose.com/purchase/default.aspx)のAspose Webサイトからライセンスを購入できます。購入する前に利用可能なさまざまなライセンスタイプに精通することをお勧めします。ご質問がある場合や支援が必要な場合は、お気軽にお気軽にお問い合わせください。お気軽にお問い合わせください。喜んでお手伝いしてください。

各Asposeライセンスには、その期間中にリリースされた新しいバージョンまたは修正を無料でアップグレードする権利を与える1年間のサブスクリプションが含まれています。また、ライセンスユーザーと評価ユーザーの両方に無料で無制限のテクニカルサポートを提供しています。

Asposeのライセンスは、製品名、ライセンスされた開発者の数、サブスクリプションの有効期限などの情報を含むプレーンテキストXMLファイルです。ファイルがデジタル署名されているため、ファイルを変更しないことが重要であり、追加のラインブレークを追加することでさえ無効になります。

### ライセンスを適用するタイミング

これらのガイドラインに従ってください：

- ライセンスは、アプリケーションドメインごとに1回設定する必要があります。
- 他のAsops.texクラスを使用する前に、ライセンスを設定します。
- 「setlicense」を複数回呼び出すことは有害ではなく、プロセッサ時間を無駄にします。
