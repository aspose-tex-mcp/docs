## Umfangreiche Funktionen

**Unterstützte Vorgänge**

- TeX-Eingabesatz
- Erstellung eines benutzerdefinierten TeX-Formats

**Unterstützung für verschiedene Ausgabedateiformate**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Unterstützte Möglichkeiten zum Lesen von Eingaben und Schreiben von Ausgaben**

- Dateisystemverzeichnis
- ZIP-Archiv
- Die Haupt-TeX-Datei kann auch über einen Stream weitergeleitet werden
