本章节文章涵盖 LaTeX 排版语言的基础概念、工作流程和高级操作。与传统的命令行 TeX 环境不同，Aspose.TeX 提供了一个隔离的、内存高效的引擎，可以原生处理 LaTeX 语法。

无论您是管理文档模板还是渲染独立的数学公式，这些指南都能提供必要的架构背景，帮助您充分利用 API 的强大功能。您将学习如何：

- TeX 格式之间的根本区别、宏环境的结构以及文档模板在无头系统中的行为。

- 如何使用数学模式 ($ ... $ 和 $$...$$)、为高级符号配置自定义导言以及在图像导出期间处理垂直基线对齐。

- 嵌入外部栅格/矢量图像，处理“包”管道，并隔离动态图形。
