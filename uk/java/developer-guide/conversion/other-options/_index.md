Кожен приклад створює `TeXOptions` для LaTeX і задає один параметр. Передайте ці налаштування в `TeXJob`, надайте відповідні вхідні дані LaTeX і задайте робочу папку виведення перед запуском завдання. Імпортуйте `com.aspose.tex.TeXOptions`, `TeXConfig` і класи з вибраного прикладу: `Interaction`, `com.aspose.tex.rendering.XpsSaveOptions` або `PdfSaveOptions`, а для прикладу дати — `java.util.Calendar`/`GregorianCalendar`. Обробляйте або оголошуйте винятки в методі виклику. Приклади растеризації та підмножин шрифтів використовують `PdfSaveOptions`; виконуйте виведення через сумісний `PdfDevice`. Застосуйте ліцензію згідно з [посібником із ліцензування](/tex/{{lang.url-fragment}}java/licensing/).

## Як встановити назву роботи

Коли ми передаємо основний вхідний файл як ім’я файлу, ми отримуємо вихідні файли з такою ж назвою, але з іншими розширеннями. Механізм TeX називає ім'я вхідного файлу *ім'ям завдання* і використовує його для вихідних файлів, за винятком випадків, коли записуються допоміжні файли з явно вказаними іншими іменами. Коли ми передаємо основний вхідний файл як [stream](/tex/{{lang.url-fragment}}java/other-ways-of-main-input/#providing-the-main-input-file-to-the-tex-engine-as-a-stream), механізм TeX використовує назву завдання за замовчуванням, яка є *texput*.
В обох випадках ми можемо змінити назву завдання, призначивши відповідний параметр перетворення.

## Як ігнорувати відсутні пакети

Файл LaTeX може посилатися на пакети, недоступні в бібліотеці Aspose.TeX для Java. Зазвичай механізм зупиняється з помилкою під час спроби завантажити такий пакет. Використайте `ignoreMissingPackages(true)`, щоб пропускати недоступні пакети. Це не надає команди, які ці пакети визначають; вхідні дані не мають залежати від таких команд.
