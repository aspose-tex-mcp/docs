p1: "TeX is known as one of the data markup languages. It is the main core of the publication set system (computer typesetting). It is questionable to consider [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) as a file format, because it is a programming language. And on the other hand, it is an interpreter engine that understands this language. Anyway, in short, its main purpose is to help with the creation of mathematical or technical text writing. But when the file is already created and you do not want any further manipulations on it, you may want to convert it to a different, more popular, format."
p2: "Aspose.TeX API solution among the different other features allows conversion of TeX files and then saving the result as ZIP archive. Here you will find a code snippet on how to convert TeX to PDF and save the output of the result to zip. The API converter transforms TeX using of any language supported by C#. The API you see here can also be used to create your own cross-platform application or be integrated into your .NET project. Such [*cross-platform converters*](https://products.aspose.app/tex/conversion/tex) are also present in the Aspose ecosystem. But to run the examples we need:"
