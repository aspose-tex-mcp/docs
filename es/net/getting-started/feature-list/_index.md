## Funciones ricas

**Operaciones admitidas**

- Composición tipográfica de entrada TeX
- Creación de formato TeX personalizado
- Conversión de TeX/LaTeX
- Incrustación de gráficos en archivos LaTeX
- Dibujo de figuras y ecuaciones matemáticas complejas dentro de archivos LaTeX
- Validación, estructuración y reparación de archivos LaTeX

**Soporte para varios formatos de archivos de salida**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Formas admitidas de leer entradas y escribir salidas**

- Directorio del sistema de archivos
- archivo ZIP
- El archivo TeX principal también se puede pasar a través de una secuencia

{{% alert color="primary" %}}

A diferencia de las utilidades TeX tradicionales de línea de comandos, Aspose.TeX para .NET es una biblioteca independiente 100% administrada. No requiere una instalación local de TeX Live, MiKTeX ni ningún ejecutable nativo subyacente.

{{% /alert %}}
