## передумови

Перш ніж продовжити, переконайтеся, що папка `Aspose.TeX-...` з’являється в папці `[PYTHON_PATH]\Lib\site-packages\` після [встановлення пакета Aspose.TeX](). Якщо у вас встановлено Python 3.11, Aspose.TeX можна встановити в папку `[PYTHON_PATH]\site-packages\`. У цьому випадку вам слід скопіювати папку Aspose.TeX до папки `[PYTHON_PATH]\Lib\site-packages\`, оскільки **PyCharm** (принаймні версія 23.1) шукає встановлені Пакети саме в цьому місці.

## Завантажити з GitHub

Усі приклади Aspose.TeX для Python доступні на [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET). У вас є два варіанти доступу до прикладів: ви можете або клонувати репозиторій за допомогою бажаного клієнта GitHub, або ви можете завантажити файл ZIP з [тут](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip). Розпакуйте вміст ZIP-файлу в будь-яку папку на вашому комп’ютері. Ви знайдете всі приклади в папці `Aspose.TeX.Examples`. Нижче ми продемонструємо, як створити та запустити приклади за допомогою популярних IDE.

Якщо у вас виникнуть проблеми під час налаштування чи запуску прикладів, будь ласка, зв’яжіться з нами через наші форуми.

## PyCharm

Перейдіть до меню ***Файл*** і виберіть ***Відкрити***. Виберіть папку прикладу проекту та натисніть кнопку ***OK***. Проект буде відкрито. Потім перейдіть до меню ***Виконати*** і виберіть ***Редагувати конфігурації***. На лівій панелі додайте нову конфігурацію Python. На правій панелі встановіть назву конфігурації (наприклад, «run_examples»). Укажіть абсолютний шлях до `run_examples.py` у полі ***Шлях сценарію*** та абсолютний шлях до папки проекту в полі ***Робочий каталог***.

Щоб запустити приклад, просто перейдіть до меню ***Виконати*** і виберіть ***Виконати 'run_examples'*** або скористайтеся комбінацією клавіш `Shift+F10`. Приклад буде виконано, а результат буде відображено у вікні консолі PyCharm. Вихідні файли, створені під час виконання прикладів, можна знайти в папці `output`.

## Microsoft Visual Studio

Переконайтеся, що функцію **Python development** встановлено у Visual Studio. Відкрийте Visual Studio та клацніть праворуч від елемента ***Відкрити локальну папку***. Потім перейдіть до папки проекту Aspose.TeX examples. Visual Studio розпізнає його як проект Python і відкриє Python IDE. Відкривши папку, клацніть правою кнопкою миші «run_examples» у провіднику рішень і виберіть ***Установити як елемент запуску***

Щоб запустити приклади, просто натисніть кнопку ***run_examples.py*** із зеленою стрілкою на панелі інструментів у вікні Visual Studio.

## Зробіть внесок у Aspose.TeX для Python

Якщо ви бажаєте зробити внесок у проект, додавши чи покращивши приклад, ми наполегливо рекомендуємо вам це зробити. Усі приклади та демонстраційні проекти в цьому репозиторії є відкритими і їх можна вільно використовувати у своїх програмах.

Якщо ви бажаєте зробити внесок, ви можете розгалужити репозиторій, внести зміни у вихідний код і створити запит на отримання. Ми переглянемо зміни та додамо їх до репозиторію, якщо вони будуть вважатися корисними.
