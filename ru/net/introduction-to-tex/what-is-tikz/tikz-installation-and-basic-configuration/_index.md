В этой главе описывается установка и базовая настройка расширения TikZ для TeX и LaTeX. Мы предоставим понятные пошаговые инструкции, которые помогут вам быстро начать создавать графику с помощью TikZ.

## Установка TikZ

TikZ предустановлен в популярных дистрибутивах TeX, таких как **TeX Live** и **MiKTeX**. Если вы используете эти дистрибутивы, TikZ, вероятно, у вас уже установлен. Если нет, следуйте этим инструкциям:

### Пользователи TeX Live

1. Откройте менеджер TeX Live (`tlmgr`).
2. Обновите список пакетов:

   ```bash
   tlmgr update --self --all
   ```

3. Установите TikZ (часть пакета `pgf`):

   ```bash
   tlmgr install pgf
   ```

### Пользователи MiKTeX

1. Откройте консоль MiKTeX.
2. Перейдите на вкладку **Пакеты**.
3. Введите `pgf` в строку поиска.
4. Выберите и установите пакет `pgf`, если он ещё не установлен.

## Проверка установки

Вы можете проверить успешность установки TikZ с помощью этого простого тестового документа:

```tex
\documentclass{article}
\usepackage{tikz}

\begin{document}

Тестирование TikZ:

\begin{tikzpicture}
  \draw (0,0) rectangle (2,1);
\end{tikzpicture}

\end{document}
```

Скомпилируйте этот документ с помощью `pdflatex` или любого редактора, совместимого с LaTeX (например, TeXworks или Overleaf). В полученном PDF-файле вы увидите небольшой прямоугольник.

## Базовая настройка TikZ

TikZ требует минимальной настройки. Однако вы можете задать глобальные параметры для управления поведением графики:

- **Глобальное масштабирование графики**:

  ```tex
  \tikzset{every picture/.style={scale=1.5}}
  ```

- **Установить цвета и стили линий по умолчанию**:

  ```tex
  \tikzset{
    every path/.style={thick, blue},
    every node/.style={font=\small}
  }
  ```

Включите эти команды в преамбулу документа, чтобы применить единообразный стиль.

## Рекомендуемые редакторы для TikZ

Для комфортного редактирования и компиляции в реальном времени мы рекомендуем следующие редакторы LaTeX:

- **TeXstudio** – бесплатный многофункциональный редактор со встроенным предварительным просмотром TikZ.
- **Overleaf** – облачный редактор для совместной работы с отличной поддержкой TikZ.
- **Visual Studio Code** с расширением **LaTeX Workshop** – современный, лёгкий редактор с поддержкой TikZ.

Выберите редактор в соответствии со своими предпочтениями и требованиями к рабочему процессу.
