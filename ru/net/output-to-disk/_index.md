item1: "Создайте параметры преобразования при расширении движка ObjectTeX, используя метод [*ConsoleAppOptions()*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/consoleappoptions) [*TeXOptions*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/) Класс."

item4: "Укажите рабочий каталог файловой системы для вывода с помощью сущностей класса [*OutputFileSystemDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputfilesystemdirectory/)."

item6: "Запустите метод задания [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) для [*XpsDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.xps/xpsdevice/)."
