## Instalando Aspose.TeX para Python de Pypi

**Pypi** (Python Package Index) é o repositório oficial para pacotes de software de terceiros em*Python*. É gerenciado pela *Python Software Foundation*, que é uma organização de caridade. Gerentes de pacotes como `pip` costumam usar **Pypi** como a fonte padrão para pacotes Python e suas dependências. **O Pypi** hospeda principalmente pacotes Python na forma de arquivos chamados `sdists` (distribuições de origem) ou rodas*pré -compiladas*.

### Referenciando aspose.tex para python

Aproveitando esse repositório, nós incluímos a biblioteca [Aspose.TeX para python](https://pypi.org/project/aspose-tex-net/) em um pacote de rodas e o carregamos para **Pypi**. Para fazer referência ao pacote em seu projeto, você pode baixá -lo na página recém -mencionada e instalá -lo localmente digitando o seguinte comando no seu terminal Python.


```
pip install <path to package>\aspose-tex-net-<version>-py3-none-<platform>.whl
```

Ou você pode instalar -o de maneira diretamente a partir de **Pypi** usando o comando abaixo.


```
pip install aspose-tex-net
```

Para atualizar para a versão mais recente, use a tecla `-Upgrade`.
