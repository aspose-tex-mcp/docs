## Вимоги до програмного забезпечення

Перш ніж завантажувати та запускати приклади, переконайтеся, що ви відповідаєте наведеним нижче вимогам.

1. Visual Studio 2010 або вище

## Завантажити з GitHub

Усі приклади Aspose.TeX для .NET розміщено на [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET).
- Ви можете клонувати репозиторій за допомогою свого улюбленого клієнта GitHub або завантажити ZIP-файл [тут](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET/archive/master.zip).
- Розпакуйте вміст ZIP-файлу в будь-яку папку на вашому комп’ютері. Усі приклади знаходяться в папці **Aspose.TeX.Examples**.
- Існує один файл рішення Visual Studio для C#.
- Проект створено у Visual Studio 2019, але файл рішення сумісний із Visual Studio 2010 SP1 і вище.
- Відкрийте файл рішення у Visual Studio та побудуйте проект.
- Завантажте бібліотеку зі [сторінки завантаження Aspose.TeX для .NET](https://releases.aspose.com/tex/net).
- Розмістіть Aspose.TeX.dll у папці **Aspose.TeX.Examples/libs**.
- **Aspose.TeX.Examples/input** містить вхідні файли, які використовують приклади. Необхідно завантажити папку **input** разом із прикладами проекту.
- Відкрийте **RunExamples.cs**; усі приклади викликаються звідси.
- Розкоментуйте приклади, які ви хочете запустити в рамках проекту.

Будь ласка, не соромтеся зв’язатися з нашими форумами, якщо у вас виникли проблеми з налаштуванням або запуском прикладів.

## Зробити свій внесок

Якщо ви хочете додати чи покращити приклад, ми заохочуємо вас зробити внесок у проект. Усі приклади та демонстраційні проекти в цьому репозиторії є відкритими і їх можна вільно використовувати у ваших власних програмах.

Щоб зробити внесок, ви можете розгалужити репозиторій, відредагувати вихідний код і створити запит на отримання. Ми переглянемо зміни та додамо їх до репозиторію, якщо вони будуть корисними.
