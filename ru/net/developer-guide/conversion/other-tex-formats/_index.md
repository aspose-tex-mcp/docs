Крайне маловероятно, что вы сейчас захотите конвертировать файл TeX, написанный в любом другом формате, кроме LaTeX. Но это возможно, если вы по какой-то причине изучаете язык TeX и/или его внутренности. В любом случае, **Aspose.TeX for .NET** позволяет конвертировать файлы, написанные в формате Plain TeX. Он также позволяет создавать собственные форматы и верстать документы, разработанные в этих форматах.

Начнем с создания пользовательского формата.

## Создание пользовательского формата

Напомним, что файл формата представляет собой двоичный дамп внутреннего состояния движка TeX.

{{< gist "aspose-com-gists" "deadfd7c29ffe40024a9b6d12f0ed18a" "Example-CreateCustomFormat.cs" >}}

Как видите, код аналогичен коду конвертации файла TeX. Но есть несколько отличий.

Во-первых, здесь мы используем конфигурацию задания [TeXConfig.ObjectIniTeX](https://reference.aspose.com/tex/net/aspose.tex/texconfig/objectinitex/). Это специальная конфигурация, которая оставляет состояние движка «девственным», т. е. внутренние параметры имеют значения по умолчанию, а набор управляющих последовательностей совпадает с набором примитивов. В нашем примере набор примитивов расширен в смысле, упомянутом [здесь](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/#object-tex).

Далее мы настраиваем рабочие каталоги ввода и вывода как обычно. Входной рабочий каталог должен содержать исходный файл основного формата и все его зависимости.

И второе ключевое отличие — это то, как мы выполняем работу. На этот раз мы используем статический метод [CreateFormat()](https://reference.aspose.com/tex/net/aspose.tex/texjob/createformat/), который вместе с параметрами принимает имя основного исходного файла, которое должно совпадать с именем формата.

Очевидно, нам нужно как-то указать формат. Прежде всего, нам нужно создать экземпляр класса [FormatProvider](https://reference.aspose.com/tex/net/aspose.tex.resourceproviders/formatprovider/). Затем в конструкторе параметров мы используем конфигурацию [TeXConfig.ObjectTeX()](https://reference.aspose.com/tex/net/aspose.tex/texconfig/objecttex/), которая принимает нашего поставщика формата в качестве аргумента и загружает формат поверх «девственного» состояния движка.

Остальная часть кода должна быть вам знакома. Он использует функции, обсуждавшиеся ранее в этом [руководстве](/tex/{{lang.url-fragment}}net/conversion/).

## Набор текста файла TeX в формате Plain TeX

Если мы выкинем поставщика формата из только что продемонстрированного кода, движок загрузит формат по умолчанию, то есть [Object TeX](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/) в четвертом смысле. Таким образом, если у вас есть файл TeX, написанный в формате Plain TeX, вы можете преобразовать его в любой поддерживаемый целевой формат.
