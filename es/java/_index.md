**Bienvenido a Aspose.TeX para Java**

Aspose.TeX es una biblioteca Java para la composición tipográfica de archivos TeX. Puede presentar entradas TeX en varios formatos gráficos como XPS, PDF, PNG, JPEG, TIFF y BMP. También genera información de rastreo como lo hace cualquier otro motor TeX. La API proporciona varias formas de pasar entradas TeX y obtener resultados. Y, como característica avanzada, le permite crear su propio formato TeX si desea componer una serie de documentos diseñados de manera uniforme.
