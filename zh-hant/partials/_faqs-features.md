{{<section faq-createcustomtex>}}
---
h2: 常問問題
Q1: "什麼是 LaTeX 模板？"
A1: "模板是一組保存的屬性、設置或結構，可以應用於新創建的文檔以節省時間。對於 LaTeX，它可以是一個包含頁面格式、字體、文檔類、包含的包等信息的文件。"
Q2: "如何使用 LaTeX 模板？"
A2: "如果您不使用任何其他軟件並且模板只是一個 .tex 文件，只需打開它並開始工作。請記住，您不會直接保存本文檔中的更改，而是使用另存為選項。"
Q3: "如何設置LaTeX文檔的類型？"
A3: '要在 LaTeX 中指定文檔類型，例如文章、書籍或演示文稿，請使用命令 `\documentclass{article}`。'
Q4: "如何創建自定義 TeX 格式？"
A4: "要使用 Aspose.TeX API 解決方案創建自定義 TeX 格式，您需要創建 TeX 引擎選項。然後為輸入和輸出指定文件系統工作目錄，並使用 *TeXJob.CreateFormat()* 方法創建格式。"

{{<section faq-custominput>}}
---
h2: 常問問題
Q1: "我如何輸入 TeX？"
A1: '要向 TeX 文件輸入任何內容，請使用 `\input` 和 `\include` 命令。例如，`\input<file name>` 命令將具有指定名稱的文件添加到 TeX 文件中。'
Q2: "如何製作 TeX 文件？"
A2: "為此，使用 *TeXOptions Class* 的 *ConsoleAppOptions()* 方法在 *ObjectTeX* 引擎擴展上創建無格式的 TeX 引擎選項。"
Q3: "如何處理 TeX 文件的輸入？"
A3: "要使用 Aspose.TeX API 解決方案操作 TeX 的輸入，請使用 [*Aspose.TeX.IO*](https://reference.aspose.com/tex/net/aspose.tex.io/) 的輸入類命名空間。"
Q4: "如何自定義 TeX 文件的輸入？"
A4: "要使用此 API 解決方案自定義 TeX 文件的輸入，您需要創建 TeX 引擎選項。然後使用 *InputFileSystemDirectory* 類為輸入指定一個文件系統工作目錄。"
