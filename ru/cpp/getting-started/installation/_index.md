## Установка Aspose.TeX для C++

### Ручная установка

Вы можете скачать [Aspose.TeX for C++](https://www.nuget.org/packages/Aspose.TeX.Cpp) из галереи NuGet, щелкнув ссылку «Загрузить пакет» в разделе «Информация». Офлайн-документацию по API также можно найти в загруженном ZIP-архиве.

Пожалуйста, выполните следующие шаги, чтобы использовать Aspose.TeX для C++ в ваших приложениях:

1. [Загрузить](https://www.nuget.org/packages/Aspose.TeX.Cpp) последние файлы.
2. Разархивируйте папку в рабочую среду.
3. Чтобы использовать Aspose.TeX для C++, обратитесь к папкам Include и lib в вашем проекте.

### Использование диспетчера пакетов Nuget

Чтобы обратиться к компоненту с помощью консоли менеджера пакетов:

1. В диспетчере пакетов NuGet найдите Aspose.TeX.
2. Выберите пакет Aspose.TeX.Cpp в результатах поиска.
3. Выберите необходимые проекты из списка проектов решения и нажмите кнопку **Установить**, чтобы установить пакет.
