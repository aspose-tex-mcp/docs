LaTexドキュメントを書いているとき、ドキュメントを構成するために使用されるマークアップタグは、適切なフォントを自動的に選択します。たとえば、セクションの見出しの場合、大きなサイズと太字としてのそのようなフォント属性は、ドキュメントクラスによって定義され、「\ section」コマンドが使用されると適用されます。したがって、フォント属性を直接指定する必要はほとんどありません。

しかし、時にはそれが必要です。たとえば、メインテキストの別のフォントファミリー(または別の全体的なフォント属性)を選択することをお勧めします。このような変更は、適切なパッケージを指定するだけで、多くの場合、単純に行うことができます。

もう1つのケースは、ドキュメントの特定の部分を特別なものとしてマークしたい場合です。例えば、頭字語、例、会社名などを示す場合などです。これらの部分にサンセリフフォントを使用する場合は、会社名を `\textsf{...}` で囲むことで実現できます。しかし、より適切な方法は、この目的のために新しいコマンド（例えば `\Company`）を定義することです。論理的に異なるものに対して個別のコマンドを定義することで、後で一貫した方法で書式設定を変更しやすくなります。

また、ページに収まるようにテーブルを小さいサイズのテーブルに入力することもできます。ドキュメントクラスはドキュメントをある程度のみ自動的にフォーマットできるため、この欲求は合法です。そのため、最終バージョンを作成するには、ページブレイクの挿入のように手作業でフォーマットすることができます。残念ながら、明示的なフォーマットにより、ドキュメントをさらに使用して困難でエラーが発生しやすくなります。したがって、ドキュメント内のフォント変更コマンドを直接使用することを最小限に抑える必要があります。これは、すべての視覚的なフォーマットコマンドにも当てはまります。


## 3.1。標準のラテックスでフォントコマンドを使用する方法

ドキュメントのメインテキストに使用されるフォントは、 *メインフォント *、 *ボディフォント *、または *通常のフォント *と呼ばれます。ドキュメントの先頭と脚注や図などの特定のコンストラクトで自動的に選択されます。セクションの見出しやその他の論理マークアップタグは、ドキュメントクラスに応じて、別の書体またはサイズに自動的に切り替わります。したがって、正しい論理マークアップを導入することは、著者に必要な唯一のアクションです。ただし、適切な書体を選択して、テキストの特定の部分を手動で強調表示することが望ましい場合があります。これは、以下で説明するコマンドで行われます。

ほとんどのフォント変更コマンドには2つの形式があります。1つは引数を1つ取るコマンド（`\textbf{...}` など）で、もう1つは宣言（`\bfseries` など）です。宣言形式は引数を取らず、LaTeX に、これ以降（現在の括弧または環境のグループの終わりまで）特別な動作をするように指示します。つまり、`\bfseries{...}` のような記述は避けるべきです。なぜなら、この時点から現在の環境の終わりまで、すべてが太字になってしまうからです。

ドキュメント内の個々の単語または短いフレーズのフォントを変更するために、1つの引数でフォントコマンドを使用することをお勧めします。より長い断片の場合、以下の例に示すように、宣言の環境形式を使用する必要があります。

```tex
Some words in this sentence are \begin{bfseries}typeset in bold letters.
The bold typeface\end{bfseries} continues here. 
```

![\ bfseriesの環境形式](/tex/images/java/tutorial/latex-font-selection-3-1.png)

宣言形式自体は、多くの場合、新しい環境またはコマンドの定義において優れています。

> 1 つの引数を持つフォント コマンドでは、引数内で段落区切りが許可されないことも重要です。

### メインドキュメントフォント

コマンド「\ textnormal」または宣言「\ normalfont」を使用して、メインドキュメントフォントに切り替えることができます。それらは通常、周囲の条件に関係なく、常に同じフォントを整形する方法を定義することが重要な場合にのみ、コマンドまたは環境の定義でのみ発生します。たとえば、Latexコマンド名をTampetset To TapeSetのコマンドは次のように見えます。

```tex
\newcommand\Lcs[1]{{\normalfont\ttfamily\textbackslash#1}%}
```

`\ remormfont`を使用すると、イタリックのテキストタイプセット内であっても、イタリック体でコマンド名が出てくるのを防ぎます。

### 標準のフォントファミリ

デフォルトでは、Latexは3つのフォントファミリを維持します。コマンド「\ textrm」でアクセスされるセリフ化されたテキストフォント。 「\ textsf」によってアクセスされたsans serifテキストフォント。および「\ textt」によってアクセスされるタイプライター(モノスパース)フォント。これらのコマンドの宣言フォームは、それぞれ`\ rmfamily`、 `\ sffamily`、および「\ ttfamily」です。

これらのコマンドでアクセスされる外部フォントファミリの正確な名前は、ドキュメントクラスに依存しますが、前文またはパッケージで変更できます。インストールのデフォルトとして、セリフ化されたフォントファミリは**コンピューターモダンローマ**、sans serifファミリは**コンピューターモダンなsans**であり、タイプライターファミリーは**コンピューターモダンなタイプライター**です。別のセットアップを使用する場合は、これらのデフォルトのフォントファミリを定義して、視覚的な衝突なしでフォントを混合できるように注意する必要があります。また、ターゲット出力デバイスの正しい解像度で外部フォントが利用可能であることを確認することも重要です。

ほとんどのドキュメントクラスは、ドキュメントのメインフォントとして「\ textrm」によってアクセスされるセリフ化されたフォントを設定するため、コマンド「\ textrm」は頻繁に使用されません。しかし、ドキュメントデザイナーがメインの書体としてSANSセリフフォントを選択した場合、「\ textrm」は代替セリフ化されたフォントファミリになります。

### 標準フォントシリーズ

ラテックスでは、 *シリーズ *は、幅と重量(太字)の2つの属性の組み合わせです。 LaTexを使用すると、2つのコマンドでシリーズを変更できます： `\ textmd`と` \ textBf`。対応する宣言は、それぞれ「\ mdseries」と「\ bfseries」です。最初のコマンドは、幅と重量の中程度の値を持つフォントを選択し、後者はより大胆なシリーズに切り替えます。繰り返しますが、実際の値はドキュメントクラスとそのオプションまたはその後のパッケージに依存します。デフォルトのセットアップでは、 `\ textBf`は現在の書体の太字の拡張バージョンに切り替わり、「\ textMd」は現在の書体の中幅と中重量バージョンに戻ります。

### 標準のフォント形状

現在の書体の *形状 *は、他のものとは独立して変更される可能性のある3番目のフォント属性です。ほとんどのドキュメントのデフォルトの形状は直立形状で、必要に応じて「\ textup」コマンドまたは「\ upshape」宣言でアクセスできます。

最も一般的に使用されるコマンドは、それぞれ「\ textit」と「\ textSc」であるように見えます。これは、それぞれイタリックまたは小さなキャップフォントの形状に切り替わります。対応する宣言は「\ itshape」と「\ scshape」です。

`\ textsl`コマンド(その宣言フォームは「\ slshape」です)は、傾斜した形状に切り替えます。コンピューターモダンローマには両方が含まれていますが、フォントファミリにはイタリック体または傾斜した形のみが含まれています。

斜めから直立した状態に切り替える時点で、特に最後の傾斜したキャラクターがascenderを持っている場合、キャラクターは通常、近づきすぎます。この境界に追加する必要がある適切な量の余分なスペースは、**イタリック補正**と呼ばれます。このスペースの正確な幅は個々の文字に依存し、 `.tfm`ファイルに保存されます。引数を使用したフォントコマンドは、斜体補正を自動的に追加しますが、宣言が使用される場合は、 `\/`を使用して手動で挿入する必要があります。直立したフォントの場合、文字の斜体補正は通常ゼロまたは非常に小さいですが、いくつかの例外があります。次の例は、斜めの形状に切り替える形状を変える宣言を正しく使用する方法を示しています。

```tex
\raggedright
When switching back from {\itshape italic\/} or {\slshape slanted\/} shapes to an upright font one
should add the {\itshape italic correction}, except when a small punctuation character follows.
```

![斜体補正](/tex/images/java/tutorial/latex-font-selection-3-2.png)

小さなキャップは、見出しや名前のフォーマットに使用される場合があります。後者の場合、たとえば、次のようにコマンド「\ name」を定義できます。

```tex
\newcommand\name[1]{\textsc{#1}}
```

または、2つの宣言を使用できます。

```tex
\newcommand\name[1]{{\normalfont\scshape #1}}
```

最初のコマンドは単に小さなキャップの形状に切り替えますが、2番目のフォームは最初にすべてのフォント属性をデフォルトにリセットします。選択するオプションは、使用可能なフォントとドキュメントのタイプに依存します。コンピューターモダンでは、ローマとタイプライターファミリのみが小さなキャップの形状を含むため、「\ sffamily」のコンテキストでも小さなキャップ(ただし、セリフ化されていますが)を使用するため、特定のアプリケーションで2番目の定義が好ましい場合があります。最初のコマンドは、コンピューターモダンなサンズファミリーの中程度のシリーズ、小さなキャップ、形状のフォントを要求します。このフォントは使用できないため、LaTexは最初にShape属性をデフォルトに変更することにより、代替品を見つけようとします。その結果、小さなキャップを取得できません。


LaTeXのもう一つの特殊な形状コマンドは`\emph`コマンドで、これは通常のテキストの一部を強調します。その宣言形式は`\em`です。伝統的に、テキスト内の強調された単語は斜体で設定されますが、既に斜体になっているテキストの一部を強調したい場合は、通常、直立フォントに戻します。`\emph`コマンドはこの慣例をサポートしており、現在のフォントが直立している場合は`\itshape`形状に切り替え、現在のフォントが既に傾斜している場合（つまり、形状が`\itshape`または`\slshape`の場合）は`\upshape`形状に切り替えます。そのため、ユーザーは`\emph`コマンドまたは`\em`宣言を使用する際に、テキストの現在の状態を気にする必要はありません。

```tex
{\em Nevertheless, one has to be careful about the\/ {\em proper\/} use of italic corrections
on both ends of the emphasized text}. It is therefore better to use the \verb=\emph= command,
which \emph{automatically} takes care of the italic correction on both sides.
```

![テキストの断片を強調します](/tex/images/java/tutorial/latex-font-selection-3-3.png)

### 標準のフォントサイズ

ラテックスには10のサイズを変えるコマンドがあります。フォントサイズの変更は通常、コマンドの定義でのみ使用されるため、これらのコマンドには対応するコマンドフォームが1つの引数にありません。

![標準のフォントサイズ](/tex/images/java/tutorial/latex-font-selection-3-4.png)

これらのコマンドで選択されたサイズは、ドキュメントクラスの設定と、それで指定されたオプション( `11pt`など)に依存します。一般に、 `\ normalsize`はドキュメントのメインサイズに対応し、サイズを変えるコマンドは、最小の「\ tiny」から始まり、最大サイズとして「\ gage」に上がる順序付けされたシーケンスを形成します。複数のコマンドが同じサイズを指すことが起こります。たとえば、「\ normalsize」が選択されている場合、「\ gage」は「\ gage」と同じになります。しかし、注文は常に尊重されます。

メインテキストサイズのサイズを変更するコマンド(つまり、「\ normalsize」、 `\ small`、および` \ footnotesize`)のコマンドは通常、リストとディスプレイの周りの間隔に影響します。したがって、動作を変更するには、「class.dtx」で文書化されているように、「\ fontsize」への呼び出しに定義を単純に置き換えるだけでなく、元の定義から開始すべきです。

## 3.2。標準フォントコマンドを結合する方法

すでに示されているように、標準のフォントを変更するコマンドと宣言を組み合わせることができ、フォント属性の組み合わせに一致する書体の選択をもたらすことができます。以下の例を参照してください。

```tex
One can typeset a text {\sffamily\bfseries\large in a large sans serif
bold typeface} but note the unchanged leading! \LaTeX{} uses the value
in force at the \emph{end} of the paragraph!
```

![ラテックスフォントコマンドの組み合わせ](/tex/images/java/tutorial/latex-font-selection-3-5.png)

内部的には、「\ sffamily」コマンドはSans Serifデフォルトファミリに切り替え、「\ bfseries」はこのファミリのデフォルトの太字シリーズに切り替え、最後に「大きなサイズを選択しますが、他のすべての属性が変更されません。 「\ arger」の範囲が段落の終わりの前に終わるため、先頭は変わらないように見えます。これらのフォントが使用されていなくても、フォントメトリックファイルはすべての中間書体に対してロードされます。上記の例では、それらは「\ sffamily」の後に「セリフ中程度の10pt」になり、「sans serif boldが10ptが10ptを拡張しました」と「\ bfseries」の後、最後に、「sans serif boldが14ptを拡張しました」。したがって、このような高レベルのコマンドは、使用されないフォントを不必要にロードするようにラテックスのフォント選択を強制することができます。特定の組み合わせが初めて使用される場合、処理速度のわずかな損失しかありません。ただし、このタイプの多くの異なる組み合わせがある場合は、[原始的なフォントを変える宣言]に関してそれらを定義することをよりよく検討する必要があります(6)。

## 3.3。フォントコマンドと宣言の比較

引数付きのフォント変更コマンドはすべて「\text...」で始まります（「\emph」を除く）。これは、通常のテキストで使用することを強調するためです。宣言型の代わりにこれらのコマンドを使用すると、他のLaTeX構文との一貫性を維持できるという利点があります。これらのコマンドは、特定のファミリー、シリーズ、または図形内の短いテキストを組版することを目的としています。次の表は、これらのコマンドの効果を示しています。

![コマンドと宣言](/tex/images/java/tutorial/latex-font-selection-3-6.png)

これらのコマンドのもう1つの利点は、議論の両側に必要な斜体補正を自動的に挿入することです。したがって、フォントを変更する際にイタリックの補正がないことを心配する必要はありません。

ごくわずかな状況では、自動的に挿入された斜体補正は間違っています。通常、小さな句読点(コンマまたはピリオド)がフォントの変更に直接従う場合、斜体補正を省略することをお勧めします。イタリック補正を抑制する場合を定義できます。これは、リスト「\ nocorrlist」に先行する斜体補正をキャンセルするキャラクターを指定することによって行われます。このコマンドのデフォルトの定義は次のとおりです

```tex
\newcommand{\nocorrlist}{,.}
```

個々のインスタンスでイタリック補正を抑制することもできます。そのためには、`\nocorr` コマンドが提供されています。`\text...` コマンドの引数内では、イタリック補正を抑制する必要があるテキストの左端または右端に `\nocorr` を配置する必要があることに注意してください。

```tex
\emph{When using the \LaTeX{} high-level font commands, the \emph{proper} use of
italic corrections is automatically taken care of}. Only \emph{sometimes} one has
to help \LaTeX{} by adding a \verb=\nocorr= command.
```

![斜体補正](/tex/images/java/tutorial/latex-font-selection-3-7.png)

対照的に、宣言フォームは、多くの場合、独自のコマンドや環境を定義するためにより適しています。

```tex
% Part of the preamble
\newenvironment{bfitemize}{\begin{itemize}%
  \normalfont\bfseries\raggedright}{\end{itemize}}
-----------------------------------------------
\begin{bfitemize}
\item This environment produces boldface items.
\item It is defined in terms of \LaTeX's
\texttt{itemize} environment and NFSS declarations.
\end{bfitemize}
```

![Boldfaceアイテムを備えたリスト](/tex/images/java/tutorial/latex-font-selection-3-8.png)

## 3.4。フォントのすべての文字にアクセスする方法

キャラクターがフォントに存在していても、キーボードから入力することが不可能な場合もあります。多くの有用なキャラクターは、「\ ss」や `\ ae`などのコマンドからアクセスできます。一部の文字は、「FFI」の字系を生成する「FFI」のような文字のシーケンスから暗黙的に生成できます。

さらに、 `\ symbol`コマンドを使用すると、現在のエンコードスキームで数字を10進数、octal(` '`の前)、またはヘキサデシマル(` "` `` `の前)として数字を与えることにより、フォント内の任意の文字にアクセスできます。

```tex
\fontencoding{T1}\selectfont
-----------------------------------------------
In the font encoding (\texttt{T1}), characters like \symbol{"DE},
symbol{'237}, and \symbol{32} are included and can be accessed with
the \verb=\symbol= command.
```

![\ symbolコマンド](/tex/images/java/tutorial/latex-font-selection-3-9.png)

## 3.5。デフォルトのテキストフォントを変更する方法

ドキュメントの全体的な外観を簡単に変更する場合は、前述の高レベルのフォント変更コマンドの動作を変更するLaTexの組み込みフックを使用できます。これらのフックの値は、 `\ renewcommand`を使用して、パッケージファイルまたはドキュメントの前文で設定できます。これがフックのリストです：

![高レベルのフォントを変更するためのフック](/tex/images/java/tutorial/latex-font-selection-3-10.png)

たとえば、前文で書く場合
```tex
\renewcommand\familydefault{cmss}
```

この再定義は、ラテックスが使用するメインフォントのフォントファミリーを変更するため、コンピューターモダンなサンズでドキュメント全体が出てきます。詳細には、メインドキュメントフォントは、`\ encodingDefault`、 `\ familydefault`、` \ seriesdefault`、および `\ shapedefault`の値によって決定されます。これは、これらのコマンドが、それらの組み合わせがLaTexの内部テーブルの既存のフォント形状を指すような方法で定義されていることを確認する必要があることを意味します。

`\ encodingDefault`(` ot1`)のデフォルト値は、実際に互換性を提供します。これは、LaTexがほとんどのフォントが元のエンコードを使用することを想定していることを意味します。ほとんどの場合、「OT1」で利用できない多くの追加のグリフが含まれており、アクセント付き文字のある単語の適切なハイフネーションを可能にする「T1」エンコードを使用する方が良いです。現在、一部のフォントは「T1」で使用するように設計されているため、「OT1」をまったくサポートしていません。

すべてのフォントをドキュメントエンコードデフォルトとして使用できるわけではないことを覚えておくことが重要です。前提条件は、エンコードには、標準的な位置に目に見えるASCII文字のほとんどを含める必要があることです。 「fontenc」パッケージに1つ以上のオプションをロードすることで、 `\ encodingDefault`を変更できます。

`\ familydefault`の初期設定は、「\ rmdefault」を変更すると、「familydefault」が「\ familydefault」の特別な設定が定義されていない限り、「\ familydefault」を新しい値に変更することを意味します。しかし、「familydefault」が変更された場合、「\ rmdefault」は影響を受けません。
