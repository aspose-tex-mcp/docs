## Огляд

Інструмент [Aspose.TeX Convert](https://www.nuget.org/packages/Aspose.TeX.Convert) — це потужна програма CLI, яка полегшує перетворення документів TeX і LaTeX у різні формати. Цей інструмент дозволяє розробникам і дизайнерам створювати документи, які бездоганно працюють на різних платформах і пристроях.

## Ключові характеристики
- **Підтримувані формати введення**: TeX, LaTeX.
- **Підтримувані вихідні формати**: PDF, XPS, PNG, JPEG, BMP, TIFF, SVG.
- **Гнучке використання**: можна використовувати як за допомогою простих команд командного рядка, так і програмно у вашому коді C#, сумісному з .NET 6.0/7.0.

## Переваги

Використання інструменту Aspose.TeX Convert забезпечує кілька переваг:

- **Ефективність**: швидко конвертуйте документи TeX/LaTeX у різні формати без потреби у складному програмному забезпеченні.
- **Автоматизація**: інтегруйте перетворення документів у свої автоматизовані робочі процеси та сценарії.
- **Гнучкість**: робота з різними форматами документів для забезпечення сумісності з різними системами та програмами.

## Ліцензування

Хоча сама програма Aspose.TeX Convert є безкоштовною для використання, для конвертації документів потрібна дійсна [ліцензія] Aspose.TeX (2). Ви можете придбати ліцензію або використовувати Aspose.TeX у пробному режимі для ознайомлення.

## Як встановити конвертер командного рядка TeX?

Інструмент Aspose.TeX Convert можна встановити глобально або локально, залежно від потреб вашого проекту. Рекомендується використовувати локальну інсталяцію для конкретного проекту, щоб уникнути конфліктів версій.

### Глобальна інсталяція

Щоб інсталювати Aspose.TeX Convert глобально на вашій машині, скористайтеся такою командою:


```bash
dotnet tool install --global Aspose.TeX.Convert
```

Укажіть опцію `--version`, якщо вам потрібна конкретна версія інструменту.

### Локальна установка

Для локального встановлення в межах конкретного проекту спочатку перейдіть до кореневого каталогу вашого проекту. Потім виконайте наступні команди:

1. Створіть інструмент-маніфест, якщо його ще немає:

   ```bash
   dotnet новий інструмент-маніфест
   ```

2. Встановіть Aspose.TeX Convert локально:

   ```bash
   інструмент dotnet встановити Aspose.TeX.Convert --local
   ```



Знову ж таки, ви можете вказати опцію `--version` для певної версії.

### Оновлення TeX CLI Converter

Щоб оновити інструмент Aspose.TeX Convert до останньої версії, скористайтеся командою `dotnet tool update` з `--global` або `--local`, що відповідає вашому типу встановлення.

### Видалення TeX CLI Converter

Якщо вам потрібно видалити інструмент, скористайтеся командою `dotnet tool uninstall` з `--global` або `--local`, залежно від способу встановлення інструменту.

## Використання

### Командний рядок

Перетворюйте документи за допомогою аргументів командного рядка. Ось доступні параметри:

- `-i, --input [обов'язково]`: шлях до вхідного документа TeX або LaTeX.
  - Приклад: `--input input.tex`
- `-o, --output [обов'язково]`: шлях до перетвореного документа.
  - Приклад: `--output output.pdf`
- `-f, --format [необов'язковий]`: вихідний формат документа.
  - Підтримувані формати: PDF, XPS, PNG, JPEG, BMP, TIFF, SVG.
  - Приклад: `--format pdf`
- `-l, --license [необов'язково]`: шлях до файлу ліцензії Aspose.TeX .NET.
  - Приклад: `--license path_to_license.lic`
- `-v, --verbose [необов'язковий]`: увімкнути докладний вивід.
  - Приклад: `--verbose`



Приклад використання командного рядка:


```bash
Aspose.TeX.Convert --input input.tex --output output.pdf --format pdf
```

### Як інтегрувати CLI LaTeX Converter у проекти C#?

Програму Aspose.TeX Convert також можна інтегрувати безпосередньо у ваші проекти .NET за допомогою командного рядка, забезпечуючи програмний доступ до можливостей перетворення TeX у вашому коді C#.
**Додавання конвертера командного рядка LaTeX до вашого проекту:**

Щоб додати інструмент Aspose.TeX Convert до проекту Visual Studio, перейдіть до кореневого каталогу проекту та виконайте таку команду:


```bash
dotnet Aspose.TeX.Convert add
```

Ця команда додає функціональність Aspose.TeX Convert безпосередньо у ваш проект, дозволяючи вам використовувати методи та властивості бібліотеки через ваш код. Це особливо корисно для розробників, які хочуть реалізувати налаштовані процеси перетворення TeX безпосередньо у своїх програмах.

### Використовуйте з коду

Ось приклад програмного використання інструментів Aspose.TeX CLI у вашому коді C#:


```csharp
using Aspose.TeX.MicroApps.Convert;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // Initialize convert options
        var options = new ConvertOptions
        {
            // Required: Specify the input document path
            InputDocument = "input.tex",
            
            // Required: Specify the output document path
            OutputFilePath = "output.pdf",
            
            // Optional: Specify the output format
            ToFormat = "pdf"
        };

        // Conditional: Apply license if you have one
        if (isLicensed)
        {
            options.LicenseFile = "path_to_license.lic";
        }

        // Execute the conversion task
        await ConvertTasks.Create(options).Execute();
    }
}
```
