**Bienvenue sur Aspose.TeX pour Java**

Aspose.TeX est une bibliothèque Java pour la composition de fichiers TeX. Il peut présenter des fichiers TeX dans différents formats graphiques comme XPS, PDF, PNG, JPEG, TIFF et BMP. Il génère également des informations de traçage comme n’importe quel autre moteur TeX. L'API propose différentes manières d'alimenter les entrées et d'obtenir la sortie. Et, en tant que fonctionnalité avancée, il vous permet de créer votre propre format TeX si vous souhaitez composer un certain nombre de documents conçus de manière uniforme.

## Assistance technique

Aspose fournit une assistance technique gratuite et illimitée pour tous ses produits. Le support est disponible pour tous les utilisateurs, y compris l'évaluation.

Si vous avez besoin d'aide avec Aspose.TeX pour Java, [**visitez Aspose.Forums**](https://forum.aspose.com/). Postez votre question sur le forum Aspose.TeX pour Java et vous recevrez une réponse dans quelques heures. L'équipe de support Aspose.TeX pour Java répond directement aux questions.

Lorsque vous attendez une réponse sur les forums, veuillez tenir compte des différences de fuseau horaire.

Si vous rencontrez un problème avec Aspose.TeX pour Java, suivez ces étapes simples pour vous assurer qu'il est résolu de la manière la plus efficace :

- Assurez-vous d'utiliser la dernière version d'Aspose.TeX pour Java avant de signaler le problème. Reportez-vous à la [Page de téléchargement d'Aspose.TeX pour Java](https://releases.aspose.com/tex/java) pour connaître la dernière version.
- Consultez les forums, cette documentation, le wiki et la [Référence API](https://reference.aspose.com/tex/java) pour trouver des solutions avant de signaler le problème. Votre question a peut-être déjà une réponse.
- Lorsque vous signalez un problème, veuillez inclure le document original et éventuellement un fragment du code à l'origine du problème. Si vous devez joindre plusieurs fichiers, compressez-les en un seul. Vous pouvez joindre vos documents en toute sécurité dans Aspose.Forums puisque seuls vous et les développeurs Aspose aurez accès aux fichiers joints.
- Veuillez essayer de signaler un problème par fil de discussion. Si vous rencontrez un autre problème, signalez-le dans un fil de discussion séparé.
