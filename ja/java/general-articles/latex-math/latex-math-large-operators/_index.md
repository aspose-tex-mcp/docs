{{<section overview>}}

数学には、たとえば「合計」または「統合」操作を示すシンボルがあります。それらは「大規模なオペレーター」と呼ばれ、通常のシンボルと文字を入力するときと同じように入力します。違いは、Texがテキストスタイルよりもディスプレイスタイルで大規模な演算子の大きなシンボルを選択することです。

![スーパー/サブスクリプトなしの合計と統合](/tex/images/java/tutorial/latex-math-6-1.png)

表示された「\ sum`」は通常、「制限」、つまりその上と下に表示されるサブフォーミュラで発生します。制限は、それらが添え字と上付き文字であるかのように入力する必要があります。
`$$ \ sum_ {n = 1}^m $$`または `$$ \ sum^m_ {n = 1} $$`両方の農産物

![制限付きの合計](/tex/images/java/tutorial/latex-math-6-2.png)

数学的タイプセットの通常の慣習は、上記の式をに変更する必要があると推測しています

![制限のない合計](/tex/images/java/tutorial/latex-math-6-3.png)

(つまり、制限なし)ディスプレイではなくテキストで発生した場合。そして、テックスはこれらの慣習に従います。

統合サインの上付き文字と添え字は、ディスプレイスタイルでも制限として設定されていません。

![テキストとディスプレイへの統合](/tex/images/java/tutorial/latex-math-6-4.png)

サブフォーミュラが複雑な場合、下付き文字と上付き文字を制限として設定すると、ページ上のスペースが増えますが、より良い外観が得られます。 Texに、サブフォーマラでどのスタイルが使用されても、「\ int」、または`\ sum`、または他の演算子の直後に「\ limits」を入力することにより、この方法で式を処理させることができます。一方、表示された合計標識の制限は、望ましくない場合があります。大規模なオペレーターの直後に「\ nolimits」と入力することで、Texの慣習を変更できます。

![強制制限と合計と統合の制限なし](/tex/images/java/tutorial/latex-math-6-5.png)

「\ nolimits \ limits」(たとえば、「\ int」などのマクロが「\ nolimits」を指定)と言うと、最後のコマンドが優先されます。 `\ displaylimits`コマンドを使用して、Texの通常の慣習に切り替えることができます。つまり、制限はスタイル *d*および *d '*にのみ表示されます。

大規模なオペレーターの下に複数の制限を設置する必要がある場合は、「\ atop」でそれを行うことができます。次の式を入力する正しい方法は次のとおりです 

```tex
$$\sum_{\scriptstyle0\le i\le m\atop\scriptstyle0<j<n}P(i,j)$$.
```

![合計標識の下でのマルチロー制限](/tex/images/java/tutorial/latex-math-6-6.png)

ここでは「\ ScriptStyle」コマンドが必要です。そうしないと、制限の両方の行はScriptScriptサイズであったでしょう。これは、Texのスタイルのルールをオーバーライドする必要があるもう1つのまれなケースです。
