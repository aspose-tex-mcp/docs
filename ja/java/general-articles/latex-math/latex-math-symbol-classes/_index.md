数式で文字 *i* と *j* にアクセント記号が付く場合は、ドットなしの記号基数である `\imath` と `\jmath` を使用する必要があります。したがって、アクセント記号付きの i と j を使用する論文は、次のような定義で始まるでしょう。

数式中で文字 *i* と *j* にアクセントを付ける場合、点のない記号基底 `\imath` と `\jmath` を使用すべきです。そのため、ハット付き i と j を使用する文書は次の定義から始めることがあります。

```tex
\def\ihat{{\hat\imath}}
\def\jhat{{\hat\jmath}}
```
