## 软件要求

在下载和运行示例之前，请确保您符合以下要求。

1. Visual Studio 2015或更高

## 从Github下载

C ++的Aspose.TeX的所有示例均在[GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP)上托管。

- 您可以使用您喜欢的GitHub客户端克隆存储库，也可以从[此处](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP/archive/master.zip)下载zip文件。
- 将zip文件的内容提取到计算机上的任何文件夹。所有示例都位于**示例**文件夹中。
- **示例**文件夹中的C ++有一个Visual Studio解决方案文件。
- 在Visual Studio中打开解决方案文件并构建项目。
- 安装库包用于解决方案。 [如何安装。](/tex/{{lang.url-fragment}}cpp/installation/)将自动安装依赖的编码库。
- 在项目属性上检查**Windows SDK版本**，以适用于已安装的Windows SDK方向。
- **示例/输入**包含示例使用的输入文件。
- **示例/输出**应该存在文件夹。它是由示例使用的。
- 打开**source/RunExamples.cpp**;所有示例都是从这里调用的。
- 取消注释您想从项目中运行的示例。

如果您有任何设置或运行示例的问题，请随时使用我们的论坛联系。
