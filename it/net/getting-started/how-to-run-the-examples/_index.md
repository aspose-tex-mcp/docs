## Requisiti del software

Assicurati di soddisfare i seguenti requisiti prima di scaricare e eseguire gli esempi.

1. Visual Studio 2010 o superiore

## Scarica da GitHub

Tutti gli esempi di Aspose.TeX per .NET sono ospitati su [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET).

- Puoi clonare il repository utilizzando il tuo client GitHub preferito o scaricare il file Zip da [qui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-.NET/archive/master.zip).
- Estrai il contenuto del file zip in qualsiasi cartella sul tuo computer. Tutti gli esempi si trovano nella cartella **aspose.tex.examples**.
- Esiste un file di soluzione Visual Studio per C#.
- Il progetto è creato in Visual Studio 2019, ma il file di soluzione è compatibile con Visual Studio 2010 SP1 e superiore.
- Apri il file di soluzione in Visual Studio e crea il progetto.
- Scarica la libreria da [asppose.tex per la pagina di download .NET](https://releases.aspose.com/tex/net).
- Posiziona apose.tex.dll in **aspose.tex.examples/libs** cartella.
- **Aspose.TeX.examples/input** contiene file di input che utilizzano gli esempi. È necessario scaricare la cartella **Input** insieme al progetto Esempi.
- Aperto **runExamples.cs**; Tutti gli esempi sono chiamati da qui.
- Rimuovere gli esempi che si desidera eseguire all'interno del progetto.

Sentiti libero di contattare utilizzando i nostri forum se hai problemi a impostare o eseguire gli esempi.

## Contribuire

Se ti piace aggiungere o migliorare un esempio, ti incoraggiamo a contribuire al progetto. Tutti gli esempi e mostrano progetti in questo repository sono open-source e possono essere utilizzati liberamente nelle proprie applicazioni.

Per contribuire, è possibile forconare il repository, modificare il codice sorgente e creare una richiesta pull. Esamineremo le modifiche e le includeremo nel repository se trovati utili.
