## Операционные системы

Поддерживаемые операционные системы включают:

* Рабочий стол Microsoft Windows (7, 8, 10)
* Серверные операционные системы (2008, 2012) и др.
* Системы Linux (Ubuntu-16.04 или новее)


Aspose.TeX для C++ также поддерживает 32-битные операционные системы.  

Операционные системы, которые не поддерживаются:

* Старые версии ОС (XP, Vista и Server 2003)

## Среды разработки

Вы можете использовать Aspose.TeX for C++ для разработки приложений в любой среде разработки, поддерживающей C++, но явно поддерживаются следующие среды:

* Microsoft Visual Studio 2015 или новее.
