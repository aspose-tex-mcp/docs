**Bem -vindo ao Aspose.TeX para C ++**

Aspose.TeX é uma biblioteca C ++ para digitar os arquivos Tex. Ele pode apresentar arquivos TEX em vários formatos gráficos, como XPS, PDF, PNG, JPEG, TIFF e BMP. Ele também gera informações sobre rastreamento como qualquer outro mecanismo Tex. A API fornece várias maneiras de alimentar a entrada e obter saída. E, como um recurso avançado, ele permite criar seu próprio formato Tex se desejar compensar vários documentos projetados de maneira uniforme.

## Suporte técnico

A Aspose fornece suporte técnico gratuito ilimitado para todos os seus produtos. O suporte está disponível para todos os usuários, incluindo avaliação.

Se você precisar de ajuda com Aspose.TeX para C ++, [**Visite o Aspose.forums**](https://forum.aspose.com/). Publique sua pergunta no fórum Aspose.TeX para C ++ e ela será respondida dentro de algumas horas. As perguntas são respondidas diretamente pelo Aspose.TeX for C ++ Support Team.

Ao esperar uma resposta nos fóruns, permita as diferenças de fuso horário.

Se você tiver um problema com o Aspose.TeX para C ++, siga estas etapas simples para garantir que ele seja resolvido da maneira mais eficiente:

- Certifique -se de usar a versão mais recente do Aspose.TeX para C ++ antes de relatar o problema. Consulte a página [Aspose.TeX para C ++](https://www.nuget.org/packages/Aspose.TeX.Cpp/) para descobrir a versão mais recente.
- Dê uma olhada nos fóruns, esta documentação, Wiki e [API Reference](https://reference.aspose.com/tex/cpp/) para soluções antes de relatar o problema. Sua pergunta já pode ter uma resposta.
- Ao relatar um problema, inclua o documento original e possivelmente um fragmento do código que causa o problema. Se você precisar anexar vários arquivos, entre em contato com eles. É seguro anexar seus documentos no Aspose.forums, já que somente você e os desenvolvedores da Aspose terão acesso aos arquivos anexados.
- Por favor, tente relatar um problema por thread. Se você tiver outro problema, relate -o em um thread separado.
