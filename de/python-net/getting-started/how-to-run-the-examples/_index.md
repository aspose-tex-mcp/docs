## Voraussetzungen

Bevor Sie fortfahren, stellen Sie bitte sicher, dass der Ordner „Aspose.TeX-...“ nach der [Installation des Aspose.TeX-Pakets]() im Ordner „[PYTHON_PATH]\Lib\site-packages\“ erscheint. Wenn Sie Python 3.11 installiert haben, kann Aspose.TeX im Ordner „[PYTHON_PATH]\site-packages\“ installiert werden. In diesem Fall sollten Sie den Aspose.TeX-Ordner in den Ordner „[PYTHON_PATH]\Lib\site-packages\“ kopieren, da **PyCharm** (mindestens Version 23.1) genau an diesem Ort nach installierten Paketen sucht.

## Von GitHub herunterladen

Alle Beispiele von Aspose.TeX für Python sind auf [GitHub](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET) verfügbar. Sie haben zwei Möglichkeiten, auf die Beispiele zuzugreifen: Sie können entweder das Repository mit Ihrem bevorzugten GitHub-Client klonen oder Sie können die ZIP-Datei von [hier](https://GitHub.com/aspose-TeX/Aspose.TeX-for-Python-.NET/archive/master.zip) herunterladen. Extrahieren Sie den Inhalt der ZIP-Datei in einen beliebigen Ordner auf Ihrem Computer. Sie finden alle Beispiele im Ordner „Aspose.TeX.Examples“. Im Folgenden zeigen wir, wie Sie die Beispiele mithilfe gängiger IDEs erstellen und ausführen.

Sollten beim Einrichten oder Ausführen der Beispiele Probleme auftreten, können Sie sich gerne über unsere Foren an uns wenden.

## PyCharm

Gehen Sie zum Menü ***Datei*** und wählen Sie ***Öffnen***. Wählen Sie den Beispielprojektordner aus und klicken Sie auf die Schaltfläche ***OK***. Das Projekt wird geöffnet. Gehen Sie dann zum Menü ***Ausführen*** und wählen Sie ***Konfigurationen bearbeiten***. Fügen Sie im linken Bereich eine neue Python-Konfiguration hinzu. Legen Sie im rechten Bereich den Namen der Konfiguration fest (z. B. „run_examples“). Geben Sie den absoluten Pfad zu „run_examples.py“ im Feld ***Skriptpfad*** und den absoluten Pfad zum Projektordner im Feld ***Arbeitsverzeichnis*** an.

Um ein Beispiel auszuführen, gehen Sie einfach zum Menü ***Ausführen*** und wählen Sie ***Run 'run_examples'*** aus oder verwenden Sie die Tastenkombination „Umschalt+F10“. Das Beispiel wird ausgeführt und die Ausgabe wird im Konsolenfenster von PyCharm angezeigt. Die während der Ausführung der Beispiele generierten Ausgabedateien finden Sie im Ordner „output“.

## Microsoft Visual Studio

Stellen Sie sicher, dass die Funktion **Python-Entwicklung** in Visual Studio installiert ist. Öffnen Sie Visual Studio und klicken Sie auf der rechten Seite des Elements ***Lokalen Ordner öffnen***. Navigieren Sie dann zum Projektordner „Aspose.TeX-Beispiele“. Visual Studio erkennt es als Python-Projekt und öffnet die Python-IDE. Sobald der Ordner geöffnet ist, klicken Sie im Projektmappen-Explorer mit der rechten Maustaste auf „run_examples“ und wählen Sie „Als Startelement festlegen“ aus.

Um Beispiele auszuführen, klicken Sie einfach auf die Schaltfläche ***run_examples.py*** mit dem grünen Pfeil in der Symbolleiste des Visual Studio-Fensters.
