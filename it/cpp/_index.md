**Benvenuti in Aspose.TeX per C ++**

Aspose.Tex è una libreria C ++ per i file TEX. Può presentare l'input di TEX in vari formati grafici come XPS, PDF, PNG, JPEG, TIFF e BMP. Output anche le informazioni di tracciamento come fa qualsiasi altro motore Tex. L'API fornisce vari modi per passare input di Tex e ottenere output. E, come caratteristica avanzata, ti consente di creare il tuo formato tex se si desidera scrivere una serie di documenti progettati in modo uniforme.
