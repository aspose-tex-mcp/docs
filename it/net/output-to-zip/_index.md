p1: "TeX è conosciuto come uno dei linguaggi di markup dei dati. È il nucleo principale del sistema di pubblicazione (composizione computerizzata). È discutibile considerare [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) come un formato di file, perché è un linguaggio di programmazione. E d'altra parte, è un motore di interprete che comprende questa lingua. Ad ogni modo, in breve, il suo scopo principale è quello di aiutare nella creazione di testi matematici o tecnici. Ma quando il file è già stato creato e non desideri ulteriori manipolazioni su di esso, potresti voler convertirlo in un formato diverso, più popolare."
p2: "La soluzione API Aspose.TeX tra le diverse altre funzionalità consente la conversione di file TeX e quindi il salvataggio del risultato come archivio ZIP. Qui troverai uno snippet di codice su come convertire TeX in PDF e salvare l'output del risultato in zip. Il convertitore API trasforma TeX utilizzando qualsiasi linguaggio supportato da C#. L'API che vedi qui può essere utilizzata anche per creare la tua applicazione multipiattaforma o essere integrata nel tuo progetto .NET. Tali [*convertitori multipiattaforma*](https://products.aspose.app/tex/conversion/tex) sono presenti anche nell'ecosistema Aspose. Ma per eseguire gli esempi abbiamo bisogno di:"
p3: "Aspose.TeX per .NET API che è un'API di conversione e manipolazione dei documenti ricca di funzionalità, potente e facile da usare per la piattaforma C#."
p4: "Apri il gestore di pacchetti NuGet e cerca Aspose.TeX e installa. È inoltre possibile utilizzare il seguente comando dalla Console di gestione pacchetti."

title: Passaggi per utilizzare le directory ZIP per l'output del file TeX C#.
h3: "Codice C# per l'utilizzo delle directory ZIP per l'output"
item1: "Crea l'istanza della [*TeXOptions Class*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/)."
item2: "Specificare una directory di lavoro dell'archivio ZIP per l'output utilizzando la proprietà [*OutputWorkingDirectory*](https://reference.aspose.com/tex/net/aspose.tex/texoptions/outputworkingdirectory/)."
item3: "Specificare la console come terminale di output utilizzando la classe [*OutputConsoleTerminal*](https://reference.aspose.com/tex/net/aspose.tex.io/outputconsoleterminal/)."
item4: "Definire le opzioni per il salvataggio utilizzando la classe [*PdfSaveOptions*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfsaveoptions/)."
item5: "Eseguire la conversione utilizzando il metodo [*TeXJob()*](https://reference.aspose.com/tex/net/aspose.tex/texjob/) per [*PdfDevice*](https://reference.aspose.com/tex/net/aspose.tex.presentation.pdf/pdfdevice/)"
item6: Perfeziona l'output.
item7: "Per finalizzare l'archivio ZIP di output, utilizzare la classe [*OutputZipDirectory*](https://reference.aspose.com/tex/net/aspose.tex.io/outputzipdirectory/)."
