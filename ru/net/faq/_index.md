**В: Какова основная функциональность решения Aspose.TeX API?**

**О:** Aspose.TeX — это комплексное API-решение для набора текстов TeX и Latex, которое позволяет создавать уравнения LaTeX, а также создавать и конвертировать файлы TeX. Это эффективное управление документами TeX и создание формул.
<br><br>

**В: Какие форматы поддерживает Aspose.TeX?**

**О:** Aspose.TeX поддерживает TeX и LaTeX в качестве входных данных и форматы XPS, PDF, PNG, JPEG, TIFF, SVG и BMP в качестве выходных.
<br><br>

**В: Как конвертировать TeX?**

**О:** Это очень просто. Вам нужно сделать всего несколько шагов! 
1. Запустите класс [TeXOptions](https://reference.aspose.com/tex/net/aspose.tex/texoptions/).
2. Укажите рабочий каталог файловой системы для вывода, задав свойство [OutputWorkingDirectory](https://reference.aspose.com/tex/net/aspose.tex/texoptions/outputworkingdirectory/).
3. Инициализируйте параметры сохранения для выходного формата, используя класс (формат файла) SaveOptions.
4. Преобразуйте TeX, используя метод [Run()](https://reference.aspose.com/tex/net/aspose.tex/texjob/run/).


Дополнительные примеры можно найти в руководствах по [Конвертации](/tex/{{lang.url-fragment}}net/conversion/).
<br><br>

**В: Как верстать файлы TeX?**

**О:** Это очень просто. Вам нужно сделать всего несколько шагов! 
1. Создайте настройки преобразования, адаптированные к формату Object TeX или Object LaTeX.
2. Укажите каталог в файловой системе для результирующего вывода.
3. Создайте экземпляр класса TeXJob и инициируйте операцию набора текста, вызвав метод *TeXJob.Run*().
<br><br>

**Вопрос: Как визуализировать формулы LaTeX с помощью Aspose.TeX?**

**О:** Библиотека математического рендеринга Aspose.TeX позволяет создать изображение SVG или PNG, содержащее математическую формулу, всего за несколько шагов:

1. Создайте объект класса *(формат файла)MathRendererOptions*.
2. При необходимости укажите цвет фона, используя свойство BackgroundColor параметров.
3. Настройте поток памяти для захвата выходных данных журнала, созданных в процессе рендеринга, с помощью свойства *LogStream*.
4. Создайте поток файлов для сохранения выходного изображения.
5. Создайте объект класса *(формат файла)MathRenderer* и запустите отрисовку формулы, вызвав метод *Render()*. 

Дополнительные примеры можно найти в руководствах [рендеринг математических формул LaTeX](/tex/{{lang.url-fragment}}net/latex-math-formula-rendering/).
