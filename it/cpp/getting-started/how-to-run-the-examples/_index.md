## Requisiti del software

Assicurati di soddisfare i seguenti requisiti prima di scaricare e eseguire gli esempi.

1. Visual Studio 2015 o superiore

## Scarica da GitHub

Tutti gli esempi di Asposi.Tex per C ++ sono ospitati su [github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP).

- Puoi clonare il repository utilizzando il tuo client GitHub preferito o scaricare il file Zip da [qui](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP/archive/master.zip).
- Estrai il contenuto del file zip in qualsiasi cartella sul tuo computer. Tutti gli esempi si trovano nella cartella **Esempi**.
- Esiste un file di soluzione Visual Studio per C ++ nella cartella **Esempio**.
- Apri il file di soluzione in Visual Studio e crea il progetto.
- Installa il pacchetto libreria per la soluzione. [Come installare.](/tex/{{lang.url-fragment}}cpp/installation/) La libreria di codePorting dipendente verrà installata automaticamente.
- Controllare **Versione SDK di Windows** Sulle proprietà del progetto per le verioni di Windows SDK installate.
- **Esempio/Input** contiene file di input che utilizzano gli esempi.
- **Esempio/output** La cartella dovrebbe presentare. Sta usando per esempi.
- Apri **Source/runExamples.cpp**; Tutti gli esempi sono chiamati da qui.
- Rimuovere gli esempi che si desidera eseguire all'interno del progetto.

Sentiti libero di contattare utilizzando i nostri forum se hai problemi a impostare o eseguire gli esempi.

## Contribuire

Se ti piace aggiungere o migliorare un esempio, ti incoraggiamo a contribuire al progetto. Tutti gli esempi e mostrano progetti in questo repository sono open-source e possono essere utilizzati liberamente nelle proprie applicazioni.

Per contribuire, è possibile forconare il repository, modificare il codice sorgente e creare una richiesta pull. Esamineremo le modifiche e le includeremo nel repository se trovati utili.
