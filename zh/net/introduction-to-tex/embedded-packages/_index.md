## 内置 LaTeX 宏包列表

开发人员经常会问：哪些宏包是直接内置在 Aspose.TeX 引擎环境中的，而哪些又需要手动引入？Aspose.TeX 库中内置了若干 LaTeX 宏包，具体列表如下：


| **宏包 (Package)** | **版本 (Version)** |
| :- | :- |
| `amsmath` | v2.17j 2021/04/20 |
| `colortbl` | v1.0f 2022/06/20 |
| `eurosym` | v1.1 1998/08/06 |
| `geometry` | 适配版本，相当于 v5.9 2020/01/02 |
| `graphics` | 适配版本，相当于 v1.4d 2021/03/04（包含 `graphicx` v1.2c 2020/12/05，`color` v1.0j 2005/11/14） |
| `hyperref` | 适配版本，相当于 v6.83m 2012/11/06 |
| `lipsum` | v2.7 2021/09/20 |
| `multirow` | v2.8 2021/03/15 |
| `pgf` | v3.1.9a 2021/05/15 |
| `pict2e` | 适配版本，相当于 v0.4b 2020/09/30 |
| `setspace` | v6.7b 2022/12/04 |
| `url` | v3.4 2013/09/16 |
| `wasysym` | v2.0 2003/10/30. |
| `xcolor` | v2.12 2016/05/11. |

### `latex-tools` 宏包集：

`afterpage`, `array`, `bm`, `calc`, `dcolumn`, `delarray`, `enumerate`, `fileerr`, `fontsmpl`, `ftnright`, `hhline`, `indentfirst`, `layout`, `longtable`, `multicol`, `rawfonts`, `showkeys`, `somedefs`, `tabularx`, `theorem`, `trace`, `varioref`, `verbatim`, `xr` 以及 `xspace`。

**了解更多：**

- [TeX 输入/输出 (tex-io)](/tex/{{lang.url-fragment}}net/tex-io/)：了解 `IInputWorkingDirectory` 和 `IOutputWorkingDirectory` 如何处理流资源与磁盘资源。
- [什么是 LaTeX](/tex/{{lang.url-fragment}}net/what-is-latex/)
- [Aspose.TeX 与 Object TeX](/tex/{{lang.url-fragment}}net/aspose-tex-and-object-tex/)：深入理解底层的托管对象模型。

在企业文档处理中，往往需要使用引擎中未预置的专用或第三方 `.sty`/`.cls` 文件。Aspose 也支持[使用外部 LaTeX 宏包](/tex/{{lang.url-fragment}}net/external-latex-packages/)。
