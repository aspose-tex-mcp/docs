**Bienvenido a Aspose.TeX para .NET**

Aspose.TeX es una biblioteca .NET para composición tipográfica de archivos TeX. Puede presentar entradas TeX en varios formatos gráficos como XPS, PDF, PNG, JPEG, TIFF y BMP. También genera información de rastreo como lo hace cualquier otro motor TeX. La API proporciona varias formas de pasar entradas TeX y obtener resultados. Y, como característica avanzada, le permite crear su propio formato TeX si desea componer una serie de documentos diseñados de manera uniforme.

**Bienvenido a Aspose.TeX para Java**

Aspose.TeX es una biblioteca Java diseñada para administrar archivos TeX. Incluye funciones como renderizar entradas TeX en una variedad de formatos gráficos como XPS, PDF, PNG, JPEG, TIFF y BMP. Además, proporciona información de seguimiento similar a otros motores TeX. La solución API ofrece múltiples métodos para ingresar contenido TeX y recuperar resultados. También le permite crear formatos TeX personalizados para una composición tipográfica coherente en varios documentos.
