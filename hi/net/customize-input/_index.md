p1: "टीएक्स को टाइपसेटिंग भाषा के रूप में जाना जाता है। इसका मतलब है कि आप दस्तावेज़ में अपने पाठ को प्रारूपित नहीं करते हैं, लेकिन आदेशों के साथ सादा पाठ दर्ज करें। जैसा कि दस्तावेज़ीकरण के लेख [*TeX I/O*](https://docs.aspose.com/tex/net/tex-io/) में वर्णित है, TeX जॉब स्पष्ट रूप से निर्दिष्ट TeX फ़ाइल पर चलता है। इसलिए, हम इस फ़ाइल को एक निश्चित TeX कार्य के इनपुट में शामिल करते हैं।"
p2: "इस पृष्ठ पर आपको एक कोड उदाहरण मिलेगा जिसमें बताया गया है कि टीएक्स स्रोत फ़ाइलों के इनपुट को कैसे अनुकूलित किया जाए, इस बात को ध्यान में रखते हुए कि इनपुट को टीएक्स सिंटैक्स का पालन करना चाहिए और आदर्श रूप से, इंजन के लिए ज्ञात केवल आदेश शामिल हैं।"
p3: ".tex फ़ाइल इनपुट को अनुकूलित करने के लिए हमें चाहिए:"
p4: ".NET API के लिए Aspose.TeX जो C# प्लेटफॉर्म के लिए एक सुविधा संपन्न, शक्तिशाली और उपयोग में आसान दस्तावेज़ हेरफेर और रूपांतरण API है।"
p5: "NuGet पैकेज मैनेजर खोलें, और Aspose.TeX खोजें और इंस्टॉल करें। आप पैकेज मैनेजर कंसोल से निम्न कमांड का भी उपयोग कर सकते हैं।"
