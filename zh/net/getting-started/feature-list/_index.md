## 丰富的功能

**支持的操作**

- TeX输入排版
- 定制TeX格式创建
- TeX/LaTeX 转换
- 在 LaTeX 文件中嵌入图形
- 在 LaTeX 文件中绘制图形和复杂的数学公式
- LaTeX 文件的验证、结构化和修复

**支持各种输出文件格式**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**支持阅读输入和写入输出的方式**

- 文件系统目录
- ZIP归档
- 主TeX文件也可以通过流传递

{{% alert color="primary" %}}

与传统的命令行 TeX 工具不同，.NET 版 Aspose.TeX 是一个 100% 托管的独立库。它不需要在本地安装 TeX Live、MiKTeX 或任何底层的原生可执行文件。

{{% /alert %}}
