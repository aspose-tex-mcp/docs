## Funciones ricas

**Operaciones admitidas**

- Composición tipográfica de entrada TeX
- Creación de formato TeX personalizado

**Soporte para varios formatos de archivos de salida**

- XPS
- PDF
- PNG
- JPEG
- TIFF
- BMP

**Formas admitidas de leer entradas y escribir salidas**

- Directorio del sistema de archivos
- archivo ZIP
- El archivo TeX principal también se puede pasar a través de una secuencia
