*AMS*-LATEX версии 1.0 была выпущена в 1990 году и представляла собой первоначальное преобразование в LaTeX математических возможностей *AMS*-TEX Майкла Спивака Фрэнка Миттельбаха и Райнера Шопфа, которые работали консультантами *AMS*, при содействии Майкл Даунс из технического персонала *AMS*. В 1994 году дальнейшая работа была проделана с Дэвидом М. Джонсом.

Пакет *Amsmath* принимает несколько опций, которые в основном влияют на расположение *ограничений* различных математических операторов или расположение тегов уравнений.

## Доступные варианты пакета *amsmath*

Следующие три параметра могут использоваться как глобальные параметры документа (указанные в команде `\documentclass`) или как параметры пакета *amsmath*, когда он загружается с помощью команды `\usepackage`.

|||
|---|---|
| `reqno` **(по умолчанию)** | Размещать номера уравнений (теги) справа. |
| `leqno` | Размещать номера уравнений (теги) слева (по умолчанию при использовании классов документов *AMS*-LATEX). |
| `fleqn` | Размещать уравнения с фиксированным отступом от левого поля, а не по центру текстового столбца. |

## Доступные субпакеты

В дистрибутиве *AMS*-LATEX вы также можете найти компоненты, которые можно загрузить независимо с помощью команды `\usepackage`. Следующие меньшие пакеты предоставляют некоторые возможности пакета *amsmath*:

|||
|---|---|
| `amsopn` | Предоставляет `\DeclareMathOperator` для определения новых имен операторов, таких как `\Ker` и `\esssup`. |
| `amstext` | Предоставляет команду `\text` для набора фрагмента текста правильным размером шрифта. |

## Пакеты расширений

Перечисленные ниже пакеты предоставляют дополнительные функции и должны быть загружены явно.
|||
|---|---|
| `amscd` | Определяет некоторые команды, упрощающие создание коммутативных диаграмм. |
| `amsthm` | Предоставляет метод для объявления структур, подобных теоремам, и предлагает среду `proof`. |
| `amsxtra` | Предоставляет некоторые ненужные вещи, необходимые для исторической совместимости, такие как `\fracwithdelims`, `\accentedsymbol` и команды для размещения надстрочных знаков в виде надстрочных индексов. |
| `upref` | Заставляет `\ref` печатать перекрестные ссылки прямым/римским шрифтом независимо от контекста. |
