## Systèmes d'exploitation

Les systèmes d'exploitation pris en charge incluent :

* Bureau Microsoft Windows (7, 8, 10)
* Systèmes d'exploitation serveur (2008, 2012), etc.
* Systèmes Linux (Ubuntu-16.04 ou version ultérieure)

Aspose.TeX pour C++ prend également en charge les systèmes d'exploitation 32 bits.  

Systèmes d'exploitation non pris en charge :

* Anciennes versions du système d'exploitation (XP, Vista et Server 2003)

## Environnements de développement

Vous pouvez utiliser Aspose.TeX pour C++ pour développer des applications dans n'importe quel environnement de développement prenant en charge C++, mais les environnements suivants sont explicitement pris en charge :

* Microsoft Visual Studio 2015 ou version ultérieure
