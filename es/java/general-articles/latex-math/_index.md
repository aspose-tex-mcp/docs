TeX está diseñado para que pueda manejar expresiones matemáticas complejas. También es importante que esté diseñado de tal manera que la mayoría de estas expresiones sean fáciles de ingresar. La idea general es componer una fórmula complicada a partir de fórmulas menos complicadas juntándolas de una manera sencilla. La complejidad de tales combinaciones disminuye a medida que la fórmula se descompone hasta llegar a algunos elementos atómicos de la fórmula. Desde el punto de vista del mecanógrafo, si puede escribir fórmulas simples y combinarlas en otras más grandes, podrá manejar cualquier fórmula. Y LaTeX, al ser una macro extensión de TeX, hace que sea aún más fácil hacer ciertas cosas. Comenzaremos con fórmulas simples.
