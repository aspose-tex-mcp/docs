## Installation d'Aspose.TeX pour C++

### Installation manuelle

Vous pouvez télécharger [Aspose.TeX for C++](https://www.nuget.org/packages/Aspose.TeX.Cpp) depuis NuGet Gallery, en cliquant sur le lien « Télécharger le package » dans la section Informations. La documentation de l'API hors ligne peut également être trouvée dans le package ZIP téléchargé.

Veuillez effectuer les étapes suivantes afin d'utiliser Aspose.TeX pour C++ dans vos applications :

1. [Télécharger](https://www.nuget.org/packages/Aspose.TeX.Cpp) les derniers fichiers.
2. Décompressez le dossier dans l'environnement de production.
3. Pour utiliser Aspose.TeX pour C++, référencez les dossiers Include et lib dans votre projet.

### Utilisation du gestionnaire de packages Nuget

Pour référencer le composant à l'aide de la console du gestionnaire de packages :

1. Dans NuGet Package Manager, recherchez Aspose.TeX
2. Sélectionnez le package Aspose.TeX.Cpp dans les résultats de recherche
3. Sélectionnez les projets nécessaires dans la liste des projets de solutions et appuyez sur le bouton **Installer** pour installer le package.
