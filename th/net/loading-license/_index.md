---
p1: "TeX เป็นที่รู้จักว่าเป็นหนึ่งในภาษามาร์กอัปข้อมูล เป็นแกนหลักของระบบชุดสิ่งพิมพ์ (การเรียงพิมพ์ด้วยคอมพิวเตอร์) การพิจารณา [*TeX*](https://docs.aspose.com/tex/net/what-is-tex/) เป็นรูปแบบไฟล์ที่น่าสงสัย เนื่องจากเป็นภาษาโปรแกรม และในทางกลับกัน มันเป็นเครื่องมือล่ามที่เข้าใจภาษานี้ อย่างไรก็ตาม ในระยะสั้น จุดประสงค์หลักของมันคือเพื่อช่วยในการสร้างการเขียนข้อความทางคณิตศาสตร์หรือทางเทคนิค"
p2: "การใช้ Aspose.TeX API ในโครงการของคุณเองอย่าลืมอัปโหลดใบอนุญาตเพื่อไม่ให้ละเมิดลิขสิทธิ์ ที่นี่คุณจะพบข้อมูลโค้ดที่อธิบายวิธีโหลดจากสตรีมและจากไฟล์ ในการรันตัวอย่างเราต้องการ:"
p3: "Aspose.TeX สำหรับ .NET API ซึ่งเป็น API การจัดการและการแปลงเอกสารที่มีคุณลักษณะหลากหลาย มีประสิทธิภาพ และใช้งานง่ายสำหรับแพลตฟอร์ม C#"
p4: "เปิดตัวจัดการแพ็คเกจ NuGet และค้นหา Aspose.TeX และติดตั้ง คุณสามารถใช้คำสั่งต่อไปนี้จาก Package Manager Console"
