p1: "TeX 是一種編程語言，您可能會發現它被稱為數據標記語言。同時，TeX 是一個理解這種語言的解釋器引擎，也是一個整體的排版系統。"

p3: Aspose.TeX for .NET 是一個靈活且易於使用的庫，用於排版 TeX 和 LaTeX 文件。 API 支持多種輸出格式，如 XPS、PDF、PNG、JPEG、TIFF、SVG 和 BMP。這意味著使用這個庫的功能，您可以將 TeX 和 LaTeX 文件轉換為任何輸出格式。使用該解決方案，如果您想創建和/或排版一堆統一設計的文檔，您可以創建自定義 TeX 格式。
