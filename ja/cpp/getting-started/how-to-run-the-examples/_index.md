## ソフトウェア要件

例をダウンロードして実行する前に、次の要件を満たしていることを確認してください。

1. Visual Studio 2015以上

## Githubからダウンロードしてください

C ++のAspose.TeXのすべての例は、[github](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP)でホストされています。

- お気に入りのGithubクライアントを使用してリポジトリをクローンするか、[こちら](https://GitHub.com/aspose-TeX/Aspose.TeX-for-CPP/archive/master.zip)からzipファイルをダウンロードできます。
- zipファイルの内容をコンピューター上の任意のフォルダーに抽出します。すべての例は、**例**フォルダーにあります。
- **例**フォルダーには、C ++用のVisual Studioソリューションファイルが1つあります。
- Visual Studioでソリューションファイルを開き、プロジェクトを構築します。
- ソリューション用のライブラリパッケージをインストールします。 [インストール方法](/tex/{{lang.url-fragment}}cpp/installation/)依存するコードポートライブラリが自動的にインストールされます。
- **Windows SDKバージョン**プロジェクトプロパティで、インストールされたWindows SDK Verionsを確認します。
- **例/入力**は、例を使用する入力ファイルが含まれています。
- **例/出力**フォルダーが表示されます。例で使用しています。
- Open **Source/runexamples.cpp**;すべての例はここから呼び出されます。
- プロジェクト内から実行したい例を解除します。

例のセットアップまたは実行に問題がある場合は、フォーラムを使用してお気軽にご連絡ください。

## 貢献する

例を追加または改善したい場合は、プロジェクトに貢献することをお勧めします。このリポジトリのすべての例とショーケースプロジェクトはオープンソースであり、独自のアプリケーションで自由に使用できます。

貢献するには、リポジトリをフォークし、ソースコードを編集し、プルリクエストを作成できます。変更を確認し、役立つ場合はリポジトリに含めます。
