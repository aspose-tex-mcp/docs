Під час обробки вихідного документа система верстки LaTeX не має багато знань про шрифт, який вона використовує. Він просто обчислює положення персонажів, не знаючи форм. Найважливішою інформацією, яка йому потрібна, є *чорні ящики* символів, які визначаються їх шириною, висотою та глибиною. Ці розміри зберігаються в окремому зовнішньому файлі, відомому як файл метрики шрифту TeX (`.tfm`) для кожного шрифту.

Зміни персонажів вступають у гру пізніше. Якщо система LaTeX створює файл `.dvi`, програма *драйвер* поєднує дані про розміщення символів із файлу `.dvi` з інформацією про форми символів із файлу `.pk` або з описів структури (наприклад, PostScript), щоб створити зображення символу на носії виводу. Однак інші системи LaTeX, такі як **PDF TeX** або **VTEX**, обходять створення файлу `.dvi` і замість цього безпосередньо генерують вихід **PDF** або **PostScript**. У цьому випадку форми символів вбудовуються, коли відповідний форматувальник створює остаточний результат.
