## Descargar desde GitHub

Todos los ejemplos de Aspose.TeX para Java están alojados en GitHub. Puedes clonar el repositorio usando tu cliente GitHub favorito o descargar el archivo ZIP desde aquí.

Extraiga el contenido del archivo ZIP a cualquier carpeta de su computadora. Todos los ejemplos se encuentran en la carpeta Ejemplos. El proyecto utiliza el sistema de construcción Maven. Cualquier IDE moderno puede abrir o importar fácilmente el proyecto y sus dependencias. A continuación, le mostramos cómo utilizar IDE populares para crear y ejecutar los ejemplos.

## IDEA IntelliJ

Haga clic en el menú Archivo y elija Abrir. Busque la carpeta del proyecto y seleccione el archivo pom.xml.

Abrirá el proyecto y descargará las dependencias automáticamente. Desde la pestaña Proyecto, busque los ejemplos en la carpeta src/main/java.

Para ejecutar un ejemplo, simplemente haga clic derecho en el archivo y elija "Ejecutar...", el ejemplo se ejecutará y el resultado se mostrará en la ventana de resultados integrada de la consola.

## Eclipse

Haga clic en el menú Archivo y elija Importar. Seleccione Maven: proyectos Maven existentes. Busque la carpeta que clonó o descargó de GitHub y seleccione el archivo pom.xml.

Abrirá el proyecto y descargará las dependencias automáticamente. Desde la pestaña Explorador de paquetes, busque los ejemplos en la carpeta src/main/java. Para ejecutar un ejemplo, simplemente haga clic derecho en el archivo y elija Ejecutar como - Aplicación Java, el ejemplo se ejecutará y el resultado se mostrará en la ventana de resultados de la consola integrada.

## NetBean

Haga clic en el menú Archivo y elija Abrir proyecto. Busque la carpeta que clonó o descargó de GitHub. El icono de la carpeta Ejemplos mostrará que es un proyecto Maven. Seleccione Ejemplos y ábralo.

Abrirá el proyecto y descargará las dependencias automáticamente. Desde la pestaña Proyectos, explore los ejemplos en los paquetes fuente. Para ejecutar un ejemplo, simplemente haga clic derecho en el archivo y elija Ejecutar archivo, el ejemplo se ejecutará y el resultado se mostrará en la ventana de resultados de la consola integrada.

## Contribuir

Si desea agregar o mejorar un ejemplo, lo animamos a contribuir al proyecto. Todos los ejemplos y proyectos de exhibición en este repositorio son de código abierto y pueden usarse libremente en sus propias aplicaciones.

Para contribuir, puedes bifurcar el repositorio, editar el código fuente y crear una solicitud de extracción. Revisaremos los cambios y los incluiremos en el repositorio si los consideramos útiles.
