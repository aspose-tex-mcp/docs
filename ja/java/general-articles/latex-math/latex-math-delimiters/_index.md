大規模な数学の式が何であれ、テックスは、適切な外観を持つのに十分な大きさのシンボルを作る方法を知っています。たとえば、タイピングの結果

```tex
$$\sqrt{1+\sqrt{1+\sqrt{1+
            \sqrt{1+\sqrt{1+\sqrt{1+\sqrt{1+x}}}}}}}$$
```

さまざまな利用可能なラジカル、または平方根の標識を示します。

![さまざまなサイズのラジカル](/tex/images/java/tutorial/latex-math-7-1.png)

ここでの3つの最大の兆候は、必要なサイズに到達するために必要な数回繰り返される垂直セグメントを除いて同じです。同時に、小さな標識は、Texの数学フォントから撮影された明確な文字です。

同様のことは、括弧や他のいわゆる「区切り文字」記号で起こります。このようなシンボルは、複雑な表現の根底にある構造に視覚的な手がかりを与えるため、数学では重要です。言い換えれば、それらは個々のサブホルムの境界を制限します。これは、LaTexが提供する22の基本的な区切り文字のリストです。

![ラテックスで定義された22の基本デリミター](/tex/images/java/tutorial/latex-math-7-2.png)

これらのシンボルのいずれかのわずかに大きなバージョンを取得するには、それぞれデリミターを開閉するために`\ bigl`または `\ bigr`を入力します。これにより、ネストされた区切り文字を備えた式が読みやすくなります。

![\ Big Delimitersを使用する例](/tex/images/java/tutorial/latex-math-7-3.png)

`\ big`の区切り文字は普通のものよりも十分に大きいため、違いに気付くことができますが、段落のテキストで使用するのに十分なほど小さいです。

![\大きな区切り文字と比較した\大きな区切り文字](/tex/images/java/tutorial/latex-math-7-4.png)

`\ bigl`と `\ bigr`の代わりに`\ bigl`と`\ bigr`を入力すると、ディスプレイに適したもう1つのステップの大きなシンボルを取得できます。

![\ Big Delimiters](/tex/images/java/tutorial/latex-math-7-5.png)

これらは、前のステップのバージョンよりも50％高くなっています。表示された式は、さらに背の高い区切り文字(`\ big`の2倍)を使用します。 `\ biggl`と `\ biggr`を入力することでそれらを取得できます。

![\ biggデリミター](/tex/images/java/tutorial/latex-math-7-6.png)

最後に、`\ biggl`バージョンと「\ biggr」バージョンを入力できます。

![\ biggデリミター](/tex/images/java/tutorial/latex-math-7-7.png)

LaTexは、`\ bigm`、 `\ bigm`、` \ biggm`、および `\ biggm`コマンドも提供して、フォーミュラの中央で使用できる区切り文字を作成します。そのような区切り文字は関係のように機能するため、テックスはその両側に少しのスペースを置きます。

![フォーミュラの中央の区切り文字](/tex/images/java/tutorial/latex-math-7-8.png)

また、`\ big`、 `\ bigg`、または`\ bigg`と言うことも可能です。これらのコマンドは、主にスラッシュとバックスラッシュで使用されます。

![ビッグ普通のシンボル](/tex/images/java/tutorial/latex-math-7-9.png)

Texは、特定のサブフォーマラを囲むために、デリミターのペアの高さを把握するアルゴリズムを実装しています。デリミッターが`\ big`または `\ bigg`などがあるかどうかを決定する代わりに、それを使用できます。言ってください


```tex
\left<delim1><subformula>\right<delim2>
```

また、Texはサブフォーミュラをタイプセットし、指定された区切り文字を左側と右側に配置します。デリミターのサイズは、サブフォーミュラをカバーするのに十分な大きさです。

![\左および\右コマンドによって設定された区切り文字](/tex/images/java/tutorial/latex-math-7-10.png)

`\left` と `\right` を使用する場合は、括弧とグループをペアにするように、これらをペアにする必要があります。ある部分式に `\left` を使用し、別の部分式に `\right` を使用することはできません。また、`\left(...{...\right...}` や `\left(...\begingroup...\right)...\endgroup` のような記述もできません。これは、TeX が区切り文字のサイズを決定する前に、`\left` と `\right` の間にある部分式をタイプセットする必要があるためです。`\left` と `\right` を使用していない場合は、括弧と角括弧を一致させる必要はありません。したがって、`$[0,1)$` や `$)($`、さらには `$)$` のような記述も許可されます。また、`\left` と `\right` を使用する場合でも、特定のシンボルを一致させる必要はないため、`\left)` または `\right(` はエラーを引き起こしません。

しかし、Texが`\ left`と `\ right`のサイズを自動的に計算できるのに、なぜ`\ bigl`と`\ bigr`などについて学ぶことを気にするのでしょうか？適切なデリミッターサイズを選択する際に自分で決定したいと思う少なくとも3つのケースがあります。

(1)次の2つの式を比較するだけです。

![\左と\右vs. \ biglと\ bigrが垂直バーと](/tex/images/java/tutorial/latex-math-7-11.png)

確かに、`\ left`と `\ right`を使用することは賢明な選択ではありませんでした。

(2)一方、`\ left`と `\ right`が必要以上に大きな区切り文字を選択することもあります。これは、主にディスプレイに大規模なオペレーターを囲むときに起こります。

![\左と\右vs. \ biglと\ bigrが合計](/tex/images/java/tutorial/latex-math-7-12.png)

Texのアルゴリズムは、`\ left`と `\ right`を引き起こします。`\ sum`を制限とともに囲みますが、このような特別な場合は、制限が少しぶらぶらする方が良いようです。したがって、「\ bigg`デリミターがここで優れています。

(3)巨大な表示された式を入力する必要がある場合、2つ以上の行に分割する必要があります。そして、あなたは、そのオープニングとクロージングの区切り文字が同じサイズであることを確認したいと思います。ただし、`\ left`と `\ right`がペアで発生する必要があるため、最初の行で` \ left`を使用したり、最後に `\ right`を使用することはできません。唯一の解決策は、最初の行で`\ biggl`(たとえば)を使用し、最後に `\ biggr`を使用することです。

> `\left` と `\right` は通常、任意の大きさの区切り文字を作成できますが、スラッシュと山括弧には最大サイズがあります。これらの記号の非常に大きなバージョンを要求すると、利用可能な最大のサイズが返されます。

また、いわゆるnull(blank)delimiterを生成するトリックを使用することもできます。 1つの大きなデリミターのみを視覚的に含む式を入力する必要がある場合、そのような区切り文字が必要になります。例えば、

![ケースのヌルリミター](/tex/images/java/tutorial/latex-math-7-13.png)

'{'しかし '}'があります。フォームの構造によって生成できます


```tex
$$|x|=\left\{ ... \right.$$ 
```

ここで、 `\ right.`は右のnullデリミタを生成します。

LaTeXには、22種類の基本セットには含まれていない、特殊な区切り文字がいくつか用意されています。`\arrowvert`、`\Arrowvert`、`\bracevert`コマンドは、それぞれ縦矢印、二重縦矢印、大括弧の繰り返し部分から、矢印の先端や括弧の波型部分を除いた区切り文字を生成します。これらのコマンドは`\vert`や`\Vert`と似た結果を生成しますが、囲む空白が多く、太さも異なります。また、`\lgroup`と`\rgroup`は中括弧の中間部分を除いた部分から構成され、`\lmoustache`と`\rmoustache`は大括弧の上半分と下半分を生成します。以下は、`\vert`、`\Vert`の`\Big`バージョンと`\bigg`バージョン、そしてこれら7つの特殊区切り文字を使用した表示例です。

![ラテックスが提供する追加の区切り者](/tex/images/java/tutorial/latex-math-7-14.png)

「\ lgroup」と `\ rgroup`は、角で鋭い曲がりがある大胆な括弧のようなものであることがわかります。これにより、特定の大きなディスプレイにとって魅力的になります。括弧と同じように使用できないことに注意してください。なぜなら、それらはサイズ「\ big`などでのみ利用可能であるためです。
